# 本地视频工作台

浏览器打开 `http://127.0.0.1:7865` 后可使用两个页面：

1. `文生图`：基于本机 Flux2-Klein 生成图片。参考图可不传；传入一张时会自动作为 Flux2 的参考条件，辅助保持主体、服装、风格或场景特征。
2. `首帧与视频`：保留原有的三图参考首帧生成和 LTX 2.3 图生视频链路。

所有结果保存在 `results`。ComfyUI 必须先运行在 `http://127.0.0.1:8188`。

启动 `启动本地视频工作台.bat` 后，浏览器打开 `http://127.0.0.1:7865`。

页面调用的本机 ComfyUI 工作流：

1. 图片提示词 + （可选）一张参考图 -> Flux2-Klein 文生图 / 参考图生图
2. 三张参考图 -> Flux2-Klein 首帧
3. 首帧 -> LTX 2.3 图生视频

详细节点映射、性能数据和后续扩展方式见 `功能说明与扩展指南.md`。
