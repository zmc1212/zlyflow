# 导演台生成过程视图重构：折叠卡片堆叠 → 直播工作区

## 根因（代码分析结论）

| 用户抱怨 | 根因 |
|---|---|
| 折叠面板奇怪、数据展示不完整 | `DirectorScriptStreamPanel.tsx:763` 手写折叠卡片：运行中已完成环节自动缩成一行摘要（刚看的内容消失），历史回放又全部展开堆成一面墙；且历史回放重建（`:173-200`）漏掉 `research|notes|`，前端 `RecipeProject` 模型也没声明 `researchNotes`（后端 `director_agents.py:1646` 有写入）——截图里"研究"块展开却是空的 |
| 不会自动滚动 | `:307-311` 滚动只挂在部分状态依赖上，用户上滚超 48px 后永久停止跟随，没有"回到底部"入口；环节折叠/展开导致高度突变时会跳位 |
| 不知道当前 agent 在生成什么 | 运行中的环节卡片淹没在一堆折叠卡片中间，与顶部任务列表脱节 |

## 目标交互（已与你确认）

- **运行中**：主区域时间线 = 用户创意气泡 → 已完成环节压缩为**单行完成条目**（`✓ 研究 · 摘要` + "查看"）→ **当前运行环节全宽直播**（无折叠、无 chevron，流式内容 + 光标）→ 全部完成后出现完成卡 + 成稿文档。点击"查看"用 **antd Drawer** 看该环节完整产出。
- **完成后/重新打开工程**：成稿文档 + 完成卡为主，过程记录以单行条目呈现，抽屉可查（修复数据缺失）。
- **自动滚动**：始终跟随直播尾部；用户上滚后停止跟随并浮现"回到底部"按钮；**新环节开始时强制回到跟随**。

## 实施步骤

1. **官方源码对照**（AGENTS.md 视觉规范硬性要求）：拉取 `TurboKach/ai-native-react-components` 相关组件源码与 `globals.css` token 块，确定完成条目行、直播卡片、回到底部按钮的官方尺寸/圆角/阴影/动效，再动手写样式。
2. **`frontend/src/director/recipe-model.ts`**：`RecipeProject` 增加 `researchNotes?: string`（API payload 原样透传，仅补类型）。
3. **`frontend/src/director/components/DirectorScriptStreamPanel.tsx`（核心）**：
   - 删除 `manualExpanded`/`blockPreview`/chevron 折叠逻辑；`renderBlockBody` 保留并复用于 Drawer。
   - pipeline 时间线改为：completed → 单行完成条目（含失败态红 pill + 重试入口）；running → 完整直播卡片（保留 `is-running` 高亮）；pending 不渲染。
   - 新增 `viewingAgent` 状态 + antd Drawer（右侧 480px、移动端全屏，title=环节名，body=renderBlockBody）。
   - 滚动健壮化：跟随阈值保持 48px；依赖补全 + ResizeObserver 兜底内容高度变化；`runningAgent.id` 变化强制恢复跟随；`!following` 时显示"回到底部"悬浮按钮（antd FloatButton）。
   - 历史回放 seeding 补 `research|notes|` ← `recipe.researchNotes`；historyMode 渲染为"全部环节单行条目（可开 Drawer）→ 完成卡 → 成稿文档"。
4. **`frontend/src/director/components/DirectorTaskRows.tsx`**：completed/failed 行支持点击（打开对应环节 Drawer），视觉沿用官方胶囊语法。
5. **`frontend/src/director/guided-flow.css`**：新增 `.director-done-row` 等样式（全部 `--director-*` token + 官方动效曲线）；Drawer 挂载在 body 下拿不到 `.is-chat` 作用域 token，需在 `.director-agent-drawer` 上成对配置浅色/暗色官方 token；清理废弃折叠样式。
6. **文档**：`功能说明与扩展指南.md` 末尾加带日期变更章节；`README.md` 同步用户可见行为；`docs/ARCHITECTURE.md` 导演台小节补一句展示层结构变化。
