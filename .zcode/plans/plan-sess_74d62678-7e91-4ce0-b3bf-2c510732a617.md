# 导演台 Agent 对话式界面重构计划

## 设计（已确认：双模式 / 垂直 Task Rows / 画风卡+弹层）

**双模式**：`script` 阶段 = 全屏 Agent 对话创作室（无侧栏、无 Tabs、无阶段头，输入在底部 Prompt Bar）；其他阶段（分镜/素材/镜头/声音/成片）= 现有编辑工作台（保留左侧导航，侧栏点「剧本」即回对话）。

**对话模式布局**：
```
┌ 顶栏：← 工程库  工程名·已保存   ☾ 串播 更多 ┐   ← 移除「任务活动」「取消生成」
├──────────────────────────────────────┤
│ 对话流（滚动）                          │
│  ├ 用户创意气泡                         │
│  ├ ◇ 生成任务面板（垂直 Task Rows）      │   ← beautifului 风格
│  ├ AI 澄清问题卡                        │
│  ├ 各 Agent 产出块（卡片化）             │
│  │   └ 分镜块：镜头行逐字流式打印▌        │   ← 修复活跃镜头渲染
│  ├ 画风卡 [更换画风]（弹层选择器）        │
│  ├ 成稿剧本卡 [编辑]                     │
│  └ ✅ 完成卡 + 下一步 chips              │   ← 进入分镜设计/重新生成
├──────────────────────────────────────┤
│ Prompt Bar（已有）                      │
└──────────────────────────────────────┘
```

## 改动清单（纯前端）

1. **新组件 `components/DirectorTaskRows.tsx`**（beautifului Task Rows 形态）：
   - 垂直面板：标题行（「生成任务 · N 项 · 已进行 mm:ss」+ 总进度条 completed/total）
   - 每行：状态图标（spinner 旋转/绿勾/红叉/空心圈）+ 任务名 + 实时 message + 迷你进度指示；运行中行左侧主色竖线高亮
   - 全部终态后面板折叠为一行摘要（点击展开回看）；运行中常驻展开
   - props：rows（status/message 合并后）、elapsed、running

2. **`DirectorScriptStreamPanel` 重构**：
   - 用 DirectorTaskRows 替换现有水平 chips 行
   - 产出块卡片化（圆角卡片 + agent 图标头）
   - **分镜流式修复（根因：活跃镜头无渲染载体）**：新增 `activeIndex` 跟踪（每个 agent|field 记录最新 delta 序号）；镜头渲染 = 已闭合条目 + 活跃行（镜 N，title/description/dialogue 用打字机 shown 值 + 闪烁光标，title 未到时骨架行）；活跃场景标题同理
   - 画风卡：art_style 完成后显示画风名称卡 + 「更换画风」按钮（onOpenPicker 回调）
   - **完成卡 + 下一步 chips**：plan_pipeline 终态后渲染「创作方案已完成 · N 镜」卡（含失败 Agent 警告）+ chips [进入分镜设计][重新生成]，onNext(stage) 回调 studio
   - 新 props：`onOpenPicker`、`onNextStage`、`completion`（studio 从 operation 终态计算传入）

3. **`DirectorRecipeStudio.tsx`**：
   - script 阶段（scriptRoomActive）：不渲染 rail、剧本|画风 Tabs、DirectorTaskHeader；layout 加 `is-chat` 单列 class
   - 顶栏：script 阶段隐藏「任务活动」与「取消生成」（任务活动入口移入「更多」菜单）
   - 画风弹层：`artStylePickerOpen` state + Modal 内嵌现有 `ArtStyleCatalogPicker`，选择后 updateRecipe + 提示可重新生成
   - panel 新 props 接线（completion 由 operationQuery 终态 + flattenRecipeShots 计算）

4. **CSS（guided-flow.css）**：TaskRows 面板、块卡片、完成卡、chips、画风卡、活跃镜头行、`.director-recipe-layout.is-chat` 单列；移动端断点（对话全宽、面板折叠、chips 横滑）；双主题 `--studio-*`；清理 `.director-agent-tasks` 水平行旧样式。

5. **文案（action-copy.ts）**：完成卡/下一步/画风卡/任务面板标题等。

6. **文档**：三份主文档追加变更章节。

## 验证
- `npx tsc --noEmit` + `npm run build`；后端不动但跑 director 测试确认无回归。
- 人工回归：对话全流程（气泡→任务面板→澄清→各块流式→分镜逐字打印→画风弹层→完成卡→进入分镜设计→侧栏点剧本回对话）；生成中取消/失败；刷新恢复；桌面+移动端、双主题。

## 兼容与回滚
不改 API/后端（分镜 delta 事件已存在，本次是前端渲染修复）；阶段切换仍走 `?stage=` URL，工作台阶段行为不变。回滚：还原本次提交即恢复 Tabs + 侧栏布局。
