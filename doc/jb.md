# 《牛大穿越：公主幕僚的生钱之路》——AI视频详细分镜版

## 视频定位
- 类型：古装 / 穿越 / 商业逆袭 / 爽文
- 世界观：架空“大晟王朝”
- 总时长：约30分钟（30集）
- 单集：约60秒
- 每集：6个镜头，每镜头约10秒
- 主线：现代销售牛大成交后酒局骤停 → 穿越侯府庶子被赶出门 → 偶遇私下经商屡败的公主淼淼 → 入幕献计 → 木质风扇起家 → 奶茶、羊脂皂、冰饮等可在古代落地的商品层层铺开 → 国库由虚转盈

## 一、主要人物固定设定

### 牛大（牛昊）——男主
现代身份：28岁一线销售，外号“牛大”；利落短发、深色衬衫、略带风尘的笑；擅长把复杂事讲成人话。
古代身份：安侯府庶子牛昊，24岁；清瘦结实；剑眉、眼底精明；黑色长发束冠；被赶出时穿洗旧的青灰直裰、旧布靴，腰间只剩空荷包。气质市井但不油滑，遇事先算账。固定道具：半截炭笔、碎纸算草、后期木质手摇风扇样品。

### 淼淼——女主 / 公主
20岁；眉眼清亮；乌发高髻，日常微服时改梳简单发髻；微服青裙布衣，宫中才着淡粉宫装。聪明、嘴硬、心软，经商屡败却不肯认怂。固定道具：记账木牌、空钱袋、公主私印（藏袖中）。

### 大晟皇帝——国王
48岁；微霜两鬓；深青常服多于龙袍；眼神疲倦但不昏聩。国库见底，边饷拖欠，只得默许女儿私下生钱。固定道具：空账册、玉玺、冷掉的茶。

### 安侯嫡子牛铮——家族压力
26岁；锦袍玉带；面白唇薄。嫌庶弟丢人，主导将其扫地出门。固定道具：折扇、家法戒尺。

### 作坊师傅老木——执行层
50岁；花白短须；粗布短打；手上全是木刺茧。认死理，一旦服气就拼命做活。固定道具：墨斗、锯子、刨子。

### 茶铺娘子阿枝——市井盟友
30岁；利落发髻；蓝布围裙。懂茶不懂营销，后成奶茶铺掌柜。固定道具：陶壶、茶碗、竹秤。

### 奸商钱百万——对手
40岁；肥胖；绛色锦袍金链；笑里藏刀。垄断京城夏货与茶叶。固定道具：金算盘、打手。

## 二、统一视觉风格
> 中国古代架空王朝，大晟朝。写实古装电影风格，真实人物皮肤质感，真实布料纹理。现代戏：城市夜景、暖黄街灯、浅景深。古代戏：青砖黛瓦、宋式审美、低饱和古典色调、柔和自然光、浅景深、电影构图。人物面部稳定，服装保持一致，写实而非动漫。

禁止（古代戏）：汽车、电线杆、手机、手表、拉链、现代家具、现代发型、西式建筑、塑料、不锈钢、电灯。
允许（现代戏）：手机、酒杯、轿车倒影、霓虹，但穿越白光后全部消失。

# 五、镜头衔接规则（防跳动）

1. 每集镜头6的场景、道具或视线，必须在下一集镜头1里被接住（门、账、匣、巷、城门、白光、房梁等）。
2. 同一集内用“因果”推进：看见问题→提出方法→动手→失败或受阻→修正→结果。
3. 时空跳跃只用明确过渡物：白气（热→冰窖）、雪落风扇叶（夏→冬）、换衣包袱（宫→市）、车轮（城内→出城）。
4. 人物服装：牛大被逐后始终青灰直裰，勿突然锦袍；淼淼进宫才换宫装，出宫必先换青裙。
5. 商品必须能在古代完成：木质曲柄风扇、茶+牛乳/杏仁+麦芽糖、羊脂草木灰皂、冰窖碎冰梅汤、炒米糖、陶暖炉碎炭。禁止塑料、电力、玻璃工业、辣椒（若需辣味用花椒，本季不用）。

# 六、视频制作建议

每个镜头控制在10秒左右。建议“1个镜头=1条视频”，生成后再按集剪成约60秒。人物、服装、清风巷铺面、木质风扇造型必须锁定参考图。现代戏与古代戏分开批次生成，穿越白光作为唯一转场特效。
