# ZLY AI Studio 导演台 UI 审计与方向说明

## 当前主要问题

- 时间轴、故事板卡片和镜头 Drawer 同时承担编辑职责，用户难以判断当前主操作区。
- 主体参考、首尾帧、镜头提示词和编译结果相距较远，`<Picture n>` 对应关系不够直观。
- 单镜生成、整段生成、批量接龙、成片预览和导出入口缺少明确的主次层级。
- 运行状态分散在镜头卡片、任务状态和弹层中，当前镜头与下一步操作不够突出。
- 桌面布局没有形成稳定的“镜头导航—工作区—属性检视器”结构。

## 不变边界

- 保留浅色、高对比度视觉和 Ant Design 组件体系。
- 保留现有 H3 T2V、I2V、R2V 路由及 `<Picture n>` 编译协议。
- 保留 AI 拆分剧本、主体参考、首尾帧、单镜生成、批量接龙、成片预览和剪映导出。
- 不显示采样步数、模型文件、LoRA、GPU 指标等内部参数。
- 不安装或依赖第三方 ComfyUI 导演节点。

## 方向 A：故事板审片台

- 选中镜头占据视觉中心，相邻镜头作为审片证明页并排展示。
- 适合以镜头卡片为主要工作对象的普通创作者。
- 右侧常驻镜头检视器集中首尾帧、主体引用、提示词、机位与编译预览。
- 优点：上手快、镜头选择明确、画面结果优先。
- 风险：长项目的整体连续性和轨道关系不如时间轴方案直观。

## 方向 B：时间轴工作台

- 上半区为当前镜头预览和属性检视器，下半区为真实多轨时间轴。
- 视频镜头、主体参考、首尾帧与生成状态按时间对齐。
- 适合多镜头、接龙续拍和需要控制连续性的创作者。
- 优点：专业感更强，批量接龙和参考素材覆盖关系清晰。
- 风险：首次使用的信息密度更高，需要设计良好的空状态与引导。

## 已确认方向：融合版

采用方向 B 的时间轴工作台作为桌面端主结构，并吸收方向 A 的故事板浏览能力：

- 桌面端维持稳定的“全局导航—镜头列表—当前镜头—属性检视器—多轨时间轴”结构。
- 当前镜头上方提供“预览 / 故事板”切换，只替换中央上半区，不移动右侧检视器和底部时间轴。
- 批量接龙是全局主操作，单镜生成是当前镜头主操作；成片预览与导出保持次级层级。
- 移动端不压缩桌面布局，改为横向镜头条、单列预览、折叠连续性摘要和底部固定主操作。

## 设计冻结范围

冻结后第一阶段只实现以下内容，不在开发阶段临时扩展产品范围：

1. 桌面端五区布局、镜头选择、预览 / 故事板切换与多轨时间轴。
2. 右侧检视器中的首尾帧、主体引用、镜头提示词、机位语义标签和编译预览。
3. 单镜生成、批量接龙、定格续接、成片预览、保存全部视频和剪映导出。
4. 空工程、生成中、等待上一镜尾帧、可恢复失败和禁用状态。
5. 移动端 390px 基线布局、可触控目标、底部固定操作和设置面板。

明确不进入本轮：新增 ComfyUI 实例、第三方导演节点、模型/采样器/GPU 等内部控件、新导出格式、工作流节点 ID 变更。

## 开发与验收计划

1. 建立页面骨架与设计 token，优先复用 Ant Design，不复制已有业务组件。
2. 接入现有导演台状态和 `<Picture n>` 编译协议，保持 H3 T2V / I2V / R2V 行为兼容。
3. 实现预览 / 故事板、镜头检视器、时间轴和移动端适配。
4. 接入批量接龙、可恢复错误和四类关键弹窗。
5. 执行现有导演台测试、前端构建、1440×900 桌面回归和 390×844 移动端回归。

设计验收标准：主要流程不依赖悬停；状态同时使用图标与文字；普通操作触控目标不小于 40px，移动端核心操作不小于 44px；不暴露内部模型参数；主次操作在桌面与移动端保持一致；错误恢复不丢失提示词、参考图和有效参数快照。
