### 导台2 渲染重生成与视频参数

- **功能模块**：导台2 剧集工坊镜头页
- **修改原因**：渲染图生成后无法按草图方式重跑；视频缺少 LightX2V 多参考及时长 / MP / 分辨率 / 部署。
- **实现思路**：
  1. 精绘有图后按钮改为「重新生成」，请求始终 `force: true`。
  2. `generate-video` 接受 I2V/R2V 工作流 ID；默认 LightX2V 多参考；R2V 以渲染图为 `<Picture 1>` 并追加角色/场景。
  3. 头部控件从 `GET /api/modes` 的 option schema 读取，把 `duration`/`quality`/`speed` 写入任务 options。

### 导台2 镜头草图/渲染图/视频

- **功能模块**：导台2 剧集工坊镜头页
- **修改原因**：草图被画成写实成片，精绘渲染和生成视频只有 toast，与 DramaClaw 虾镜三级产线不是同一件事。
- **实现思路**：
  1. 草图提示词改为白纸色块分镜草稿，参考图只带场景正反面；角色用稳定 marker 色。
  2. `POST .../generate-render` 以草图为第一张参考图上色写实并锁角色身份。
  3. `POST .../generate-video` 用渲染图作首帧，走官方 H3 I2V；`xiaji_beats` 增加 render/video 字段（启动时 `ensure_column`）。

  2. 内容库分析结果中的角色、场景、道具直接转入 `xiaji_assets`。导入成功后自动转入；分析区有「转入资产库」；资产库为空时打开也会自动转入。图片与声线仍在资产库生成。

### 导台2 资产库 GRS 生图

- **功能模块**：导台2 资产库

### 资产库生成参考图卡住

- **功能模块**：导台2 资产库
- **修改原因**：`POST .../generate-image` 一直 pending，页面按钮转圈。
- **实现思路**：
  1. `POST .../generate-image` 返回 **202** 与 `job_id`，用 FastAPI `BackgroundTasks` 入队，请求协程不 `create_task(execute_image)`。
  2. 前端入队成功即结束 mutation，再轮询 `GET /api/jobs/{job_id}`，按钮 loading 绑资产 `generating`。
  3. 生成中不把 `image_url` 指到尚不存在的 job download。

### GET /api/jobs 一直 pending

- **功能模块**：任务列表、导台2
- **修改原因**：在导台2 生成参考图时，全局 `App` 仍以 `user_id=all` 每 1.6 秒拉最近 100 条任务；每条任务再查 rounds/items，长事务堵住 worker 更新，后续 HTTP 全部卡住。
- **实现思路**：
  1. 仅在「生成」工作区启用 `/api/jobs` 轮询。
  2. `JobStore.list_jobs` 用 `IN` 批量加载 round 与 generation_item，缩短读事务。

### 结构化数据迁 MySQL，媒体迁七牛云

- **功能模块**：后端存储、任务/认证/导演工程持久化、七牛云媒体
- **修改原因**：本地 SQLite 无法多工作站共享；需要把现有结构化数据放到线上 MySQL，媒体放到七牛云。
- **实现思路**：
  1. 新增 `backend/app/db.py`，从 `docs/存储配置.md` 读取 MySQL 连接（可用 `ZLY_MYSQL_*` 覆盖），生产用 PyMySQL 连接池；应用层 SQL 仍写 `?`，适配层转 `%s` / `INSERT IGNORE`。
  2. DDL 以 `sql/001_init_mysql.sql` 为准，启动时对 MySQL 执行该文件；unittest 与 `data_dir_override` 继续走 SQLite，避免污染线上库。
  3. 一次性脚本 `migrate_sqlite_to_mysql.py` 把 `data/zly-ai-video-studio.db` 导入 `ai-media`；`migrate_media_to_qiniu.py` 按管理设置中的七牛凭证上传本地文件并回写对象键后启用七牛。
  4. 解密 AK/SK 仍使用本机 `data/credential.key`。Redis 只记录在存储配置中，本次未接入。

### 报错修复

| 错误 | 原因 | 修复 |
