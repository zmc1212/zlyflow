### 用画风目录替换视觉风格

- **功能模块**：导台2 家页 / 内容库 / 资产库
- **修改原因**：改风格后重新生成会回退；需要单独管理导演台画分并传入生图。
- **实现思路**：
  1. `/director2/art-styles` 浏览目录并保存用户默认画风。
  2. 内容库用画风替换六项视觉风格下拉。
  3. 资产生图按请求 → 资产 → 项目解析 `art_style_id`，写入 `promptPrefix` 并回写资产。

### 资产视觉风格跟随内容库

- **功能模块**：导台2 资产库
- **修改原因**：内容库选动漫后，部分角色下拉为空，生图不带该风格。
- **实现思路**：
  1. 风格按请求 → 资产字段 → 项目 settings 补空。
  2. 新建与 sync 只给空字段写入导入/项目风格。
  3. 角色表单按资产 id 重置，并回退项目风格。

### 造型图对齐 sourceXd 身份锁定

- **功能模块**：导台2 资产库
- **修改原因**：生成造型图不传肖像、画幅 4:3，与 sourceXd 身份图合同不一致。
- **实现思路**：
  1. 无肖像或无外观描述时 422；界面禁用「生成造型图」。
  2. 把肖像作为第 1 张参考图（身份锚点）。
  3. options 改为 16:9 / 1K；提示词改为四面板 Identity Lock。

- **功能模块**：导台2 剧集工坊
- **修改原因**：内容库和资产库完成后，需要把剧集规划落成可编辑脚本，并按 Beat 出草图。
- **实现思路**：
  1. 新增 `xiaji_episodes` / `xiaji_episode_links` / `xiaji_beats`。
  2. 「从规划生成剧集」读取内容库分析结果；「生成脚本」走已配置 LLM；镜头草图复用 GRS 入队协议（202 + job_id）。
  3. 合成页占位。删除项目时级联删除剧集。

### 镜头工作台参考图

- **功能模块**：导台2 剧集工坊
- **修改原因**：镜头页要对齐虾镜工作台，用资产库场景正反面和角色图作为草图参考。
- **实现思路**：
  1. 左侧 Beat 网格 + 分割条 + 右侧文案/单帧/视频占位。
  2. `PATCH` 单条 Beat 绑定身份、场景、道具；生成草图按 `scene_view` 带入参考图。
  3. 支持上传草图。不复制 DramaClaw 源码，不做 3D 导演世界和视频出片。

### 场景正面/背面/360 分视角生图

- **功能模块**：导台2 资产库
- **修改原因**：正面、背面、全景图生成结果相同，未按虾塘场景页的分视角提示词入队。
- **实现思路**：
  1. `scene_view=master|reverse|panorama` 使用不同提示词（正面源图、180° 背面、2:1 等距柱状全景）。
  2. 背面/全景任务写在 `definition.scene_jobs`，不覆盖正面 `image_job_id`。
  3. 场景编辑页三个按钮分别入队并轮询对应任务。

### 道具主视图/转面/特写分视角生图

- **功能模块**：导台2 资产库
- **修改原因**：主视图、转面四视图、细节特写生成结果相同，未按虾塘道具产品摄影合同入队。
- **实现思路**：
  1. `prop_view=master|turnaround|detail` 使用不同提示词（单张主视图、2x2 四视图、材质微距特写）。
  2. 转面/特写任务写在 `definition.prop_jobs`，不覆盖主视图 `image_job_id`。
  3. 道具编辑页三个按钮分别入队并轮询对应任务。

### 内容库支持粘贴文本

- **功能模块**：导台2 内容库
- **修改原因**：导入不应只靠文件，还要能直接复制粘贴小说/剧本。
- **实现思路**：新增 `POST /api/xiaji/documents/paste`（JSON `text` + 可选 `title`），与文件上传共用规则切章；左侧增加粘贴标题、正文和「导入粘贴文本」。
