# Source note

Timing doctrine adapted for MiniMax H3 director studio from public Seedance / storyboard-to-video guidance:

- Assign one primary action or camera beat per ~2–3 seconds.
- Do not stack dialogue, complex motion, and camera change into the same second without enough duration.
- Use explicit timeline markers so the generative model paces audio and motion together.

This vendored skill is for **MiniMax H3** (`durationSec`, `At 00:03.000`, `<d>` tags), not Seedance API prompts (`[0s]` markers).
