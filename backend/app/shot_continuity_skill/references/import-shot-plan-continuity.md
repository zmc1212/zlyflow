# 导演台导入分镜衔接合同（shot_plan JSON）

本参考只给内容库导入后的 `shot_plan` 使用。字段用中文：`opening_state`、`closing_state`、`transition_note`。
禁止写旧 Recipe 的英文 `continuityIn` / `continuityOut`（会和 H3 TTS 约束缠在一起）。
每一镜仍是独立 R2V，本地时间从 00:00 起；文字衔接必须把姿势锁死，不能指望模型自己猜。

## 先判切型，再写动作

同场、同一人物、因果连续（坐着研究 → 书掉 → 伸手接）→ **动作匹配切**：下一镜 00:00 必须继承上一镜落幅的姿势、左右、持物、灯光。
只换景别（全景坐着 → 近景手接书）→ 仍是匹配切，**禁止换成站姿**。
换场 / 换时 / 换人 → **硬切换场**，才允许姿势重置。

`transition_note` 只能用短中文之一：动作匹配切 / 视线匹配切 / 方向匹配切 / 声音桥 / 硬切换场。

## 姿势合同

1. 原文没写的姿势变化，禁止发明。没写「站起」就保持坐；没写「走到书架」就还在书桌。
2. `action` 必须可独立出片，但带边界：开头写开场站位（坐/站/走、朝向、手在哪），结尾写落幅，让下一镜能抄。
3. 必须把开场姿势写进 `action` 正文，例如「开场：仍坐在书桌前。… 收束：古籍滑到桌沿。」不要只写在新字段里。
4. `opening_state` = 本镜第一帧可见事实；`closing_state` = 最后一帧，供下一镜抄。不要写成剧情摘要。
5. 能一镜拍完的因果链优先合并（仍受 5–15 秒约束）。拆镜只为换机位看清，或超 15 秒。
6. 不要为了圆谎发明桥接剧情（例如凭空加「猛地站起来」）。缺口用「仍保持上一镜姿势，然后做本镜新动作」补，不补新情节。

## 图书馆正反例（沈砚接书）

剧本：沈砚坐在大学图书馆书桌前翻古籍；书从手中滑落；他伸手去接，白光淹没。

**正确**

- 镜 1 落幅：仍坐书桌前，古籍滑向桌沿（或刚开始侧目），没有站起来。
- 镜 2 开场：承接坐姿，上身前倾伸手接书，再被白光淹没。
- 切型：动作匹配切。`opening_state` 含「仍坐」，`action` 以「开场：仍坐在书桌前」起句。
- 若两拍加起来不超过 15 秒，更优是合成一镜。

**错误**

- 把「伸手接书」理解成站立接球、走到桌边或猛地站起来。
- 镜 2 开场写成站在书桌旁伸手。
- 为了圆站姿，发明「他猛地站起来去接」——原文没有站起。
- 因为导入稿带 `### 镜头` 就原样照抄成两段互不继承的独立戏。
