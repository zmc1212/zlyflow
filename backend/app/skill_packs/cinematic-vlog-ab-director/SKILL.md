# 电影感 Vlog 双轨视听导演（cinematic-vlog-ab-director）

> 移植自 MiniMax Hub 社区 Skill `vlog-ab-director`（v1.0.0，见 `SOURCE.md`）。作为导演台「制作配方」时，整条 Vlog 视为**一个 Beat**：工坊「生成 H3 提示词」按本配方产出带 A/B 双轨、2.5 秒黄金节拍器与地道口语台词的 MiniMax H3 多参考（Ref2VA）六段稿，一次出一条 Vlog 单片。

专为生成**高质量、高完播率、抗畸变的电影感生活 Vlog** 提示词（MiniMax H3 Ref2VA 全参考 / T2VA）而设计的导演配方。以「主观自拍（A 镜）+ 客观电影拍摄（B 镜）」交替为核心语法，通过右手专职持机法则、硬切省略哲学、道具守恒定律、2.5 秒黄金节拍器，以及自动代写地道口语台词，解决 AI 视频人物穿模、手部多指变形、道具瞬移及语速失控等痛点。

## 核心视听哲学：A 镜与 B 镜

| 维度 | A 镜：主观自拍 Vlog 视角 | B 镜：客观电影拍摄视角 |
| :--- | :--- | :--- |
| 机位本质 | 主角右手持机自拍，相机在画面外，无镜像翻转 | 专业外部摄影机第三人称，机位客观稳定或电影平移跟拍 |
| 视听心理 | 亲密感与陪伴感（面对面交流、眼神对视） | 审美感与纵深感（人物在环境中的身姿、动态与光影） |
| 景别偏好 | 胸部以上近景、微俯拍自拍、脸颊微距特写 | 全身大景别、低角度仰拍、环境全景、侧颜与背影轮廓 |
| 动态语言 | 真实有机的手持呼吸微晃（handheld shake slightly） | 电影级横移、低角跟拍、航拍后拉、稳定光栅景深 |
| 核心表达 | 眼神直视镜头、挑眉浅笑、被逗乐笑场、亲昵互动 | 身材比例、衣服流动质感、光影雕刻、从容步伐与动作定格 |

## 五大抗畸变铁律

1. 右手持机唯一性：`<Subject 1>` 右手专职持机（A 镜举起自拍，B 镜自然垂于身侧），左手专职与环境道具互动，杜绝双手逻辑混乱与多指变形。
2. 硬切省略哲学（Cut Ellipsis）：脱鞋、穿鞋、装包、推门、掏口袋等繁琐动作统一在切镜瞬间省略，切入即为「已完成」状态，避免肢体穿模。
3. 道具守恒与场景锚点：关键道具遵循「引入→使用→收纳→复现」完整物理链；脱下的鞋、放下的包、插在伞桶的雨伞固定在场景同一位置作为背景参照物。
4. 单段任务资产紧凑编号：每个出片任务按**实际上传的参考图**从 1 开始顺序匹配 `<Picture 1>`、`<Picture 2>`…，禁止出现未上传的空编号（如跳写 `<Picture 3>`），杜绝 `Unresolved Reference Label`。
5. 画面防字幕与防 UI 负向：在 `detailed_description` 结尾强制注入【禁止项】与【强制声明】负向块，避免画面烧录字幕、乱码水印与虚假 UI。

## 黄金节拍器与台词代写

- 2.5 秒黄金节拍器：把确认的单片时长按 2.500 秒恒定均分为若干镜（15 秒=6 镜，10 秒=4 镜，8 秒≈3-4 镜），严格递增时间戳 `0.00–02.500 / At 00:02.500 / At 00:05.000 …`，A/B 交替。
- 台词预算：单镜中文台词严格控制在 6~12 个汉字（英文 4~8 词）；整片仅安排 2~3 镜说话，其余保留呼吸、欢笑与环境音。
- 出镜直言（A 镜）：直视镜头说话、嘴唇同步，生活感强。
- 闭嘴画外音（B 镜）：标注 `says in an off-screen voiceover: <d>…</d> while … lips remain completely closed.`。
- 跨镜延续（L-Cut）：前半句在 A 镜说完，B 镜画面切走而声音不中断。

## 标准化六段输出（英文 Ref2VA）

`subject_definitions:` → `summary:` → `retention_analysis:` → `detailed_description:`（含 `[Shot n]` A/B 交替、时间码、`<d>` 台词、持机/硬切/道具守恒、结尾防字幕负向块）→ `overall_soundscape:` → `non_diegetic_music:`。
