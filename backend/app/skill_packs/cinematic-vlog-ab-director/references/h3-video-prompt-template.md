# H3 视频提示词模板（电影感 Vlog 双轨 / 单片）

工作台：参考图标签使用 `<Picture n>`，与 R2V 上传顺序一致——`<Picture 1>` 为主角人物设定板，`<Picture 2>` 为本片场景卡。本工作台不为 Vlog 单片生成三联关键帧，禁止虚构未上传的 `<Picture n>`。角色 `<Picture 1>` 是单人多视图设定板：只锁身份、五官、发型与关键服装，禁止把分格、白底、重复小人带进镜头。场景卡提供环境空间但不锁站位。成片始终单一确认画幅（跟随项目设置），禁止分栏。

## 用途

把一个完整电影感 Vlog 单片写成一个镜头（一个 Beat）：内部按 **2.5 秒黄金节拍器**恒定均分为多镜，A 镜主观自拍与 B 镜客观电影镜头交替。只写这一条 Vlog，时间码一律从 `00:00` 开始，覆盖到确认的单片总时长。

## 使用原则

- 先锁定这条 Vlog 的情绪主线（如「雨夜造访黑胶店的心流」），再按节拍器切镜。
- 按 A/B 机位交替切镜，不写「第一段/第二段」这种抽象阶段名；B 镜切换写成「硬切至第三人称/切回手持自拍」等具体机位动作。
- 右手持机唯一性：A 镜主角右手举机自拍、直视镜头；B 镜右手自然垂于身侧、左手与环境道具互动；全程不出现双手同时持物或多指变形。
- 硬切省略：推门、脱鞋、装包、掏口袋等繁琐动作在切镜瞬间省略，切入即为已完成态。
- 道具守恒：关键道具遵循「引入→使用→收纳→复现」；门口伞桶、收银台木箱等锚点固定在背景同一位置。
- 台词预算：整片只安排 2~3 镜说话，单镜中文 6~12 字；开口句（A 镜）嘴唇同步，闭嘴画外音（B 镜）标注 off-screen voiceover 且 lips remain completely closed；无第三人称旁白时「旁白」写「本镜无第三人称旁白」，不要用内心或开口句充数。

## 填写模板

```text
镜头【编号】，总时长【X】秒，内部时间从00:00开始，按 2.5 秒节拍器切为【N】镜，A/B 机位交替。
镜头目的：【这条 Vlog 要传达的情绪与心流主线】。

参考素材：
- <Picture 1> 主角人物设定板（单人多视图），只锁身份/五官/发型/服装，不要把分格、白底、重复小人抄进镜头
- <Picture 2> 【场景】环境卡，提供空间与光影，不锁站位
- 关键道具：【道具名】遵循「引入→使用→收纳→复现」；场景锚点：【门口伞桶/收银台木箱等固定位置】

必须出现的视觉内容：
- 【右手持机 A 镜自拍近景】
- 【B 镜客观电影全身/低角跟拍与环境光影】
- 【与道具互动的动作闭环】

按旁白和画面内容切镜（A/B 机位与 2.5 秒节拍器，时间码覆盖到总时长）：
- 00:00–00:02.500【A 镜】：【手持微晃自拍近景，直视镜头，画面内容】。
- 00:02.500–00:05.000【B 镜】：【硬切第三人称，低角横移/全景，画面内容，推门等动作已省略】。
- 00:05.000–00:07.500【A 镜】：【切回自拍，脸颊微距特写，展示道具】。
- 00:07.500–00:【…】.500【B 镜】：【电影级侧颜跟拍/环境纵深】。
- ……（按总时长每 2.5 秒一镜，A/B 交替直到收束）

对白（只 2~3 镜说话，中文 6~12 字，逐字原文）：
- 【主角】在【00:00–00:02.500 A 镜】说：“【逐字台词】”
- 【主角】在【某 B 镜】闭嘴，画外音：“【逐字台词】”（若使用）
- 其余镜头不说话，嘴唇闭合，保留呼吸与环境音

旁白：
- 本镜无第三人称旁白。角色内心写在对白里，标（内心）。

画面要求：
- A 镜 handheld shake slightly 呼吸微晃；B 镜电影级横移/低角跟拍/光栅景深
- 右手专职持机（A 镜举起、B 镜垂下），左手专职互动；禁止双手同时持物、多指变形
- 单一 {画幅} 满幅，无分栏；关键道具与场景锚点跨镜连续，不得瞬移
- 结尾注入防字幕/防 UI 负向：文字/UI/水印/Logo/角标/可读文字/真实UI；无背景音乐仅环境音与人声

负向约束：
- 不要字幕、文字、水印、Logo、虚假 UI、插画、CG、美颜滤镜、反射重影、人物消失、道具瞬移、肢体穿模、多指变形
```

## 示例骨架

```text
镜头01，总时长15秒，内部时间从00:00开始，按 2.5 秒节拍器切为6镜，A/B 机位交替。
镜头目的：一位年轻男子雨夜造访复古黑胶唱片店，记录翻找、试听、夹臂带走唱片的心流时刻。

参考素材：
- <Picture 1> 男主角人物设定板（单人多视图），只锁身份外形，不要把分格/白底/重复小人抄进镜头
- <Picture 2> 雨夜街角复古黑胶唱片店内景卡，提供暖光唱片墙与试听台空间
- 关键道具：黑胶唱片遵循「翻找→举起展示→夹臂带走」；场景锚点：门口伞桶滴水雨伞、收银台旁旧木箱固定背景

必须出现的视觉内容：
- A 镜右手持机自拍近景与眼神对视
- B 镜低角跟拍唱片墙翻找与试听台俯身聆听
- 唱片道具完整物理链与雨夜霓虹湿地反光

按旁白和画面内容切镜（A/B 机位与 2.5 秒节拍器）：
- 00:00–00:02.500【A 镜】：手持微晃自拍，雨夜暖光打脸，挑眉浅笑。
- 00:02.500–00:05.000【B 镜】：硬切第三人称低角横移，左手逐张翻找唱片，右手垂于身侧，推门进店已省略。
- 00:05.000–00:07.500【A 镜】：切回自拍脸颊微距，左手举起一张唱片展示给镜头。
- 00:07.500–00:10.000【B 镜】：电影级侧颜跟拍，把唱片放到试听台唱机俯身聆听，收银台木箱在背景同一位置。
- 00:10.000–00:12.500【A 镜】：手持自拍，左手拿起唱片夹到左臂下方，被逗乐轻笑。
- 00:12.500–00:15.000【B 镜】：低角全景后拉定格，左臂夹唱片从容转身朝店门走去，湿漉霓虹反光，伞桶锚点收束。

对白：
- 男主角在 00:00–00:02.500 说：“躲个雨，顺便淘张片。”
- 男主角在 00:05.000–00:07.500 说：“这张一响就上头。”
- 男主角在 00:10.000–00:12.500 说：“夹走，回家慢慢听。”
- 其余镜头不说话，嘴唇闭合

旁白：
- 本镜无第三人称旁白。角色内心写在对白里，标（内心）。

画面要求：
- A 镜 handheld shake slightly；B 镜低角跟拍与光栅景深，单一画幅满幅无分栏
- 右手专职持机、左手专职互动，唱片道具与伞桶/木箱锚点跨镜连续不瞬移
- 结尾注入：文字/UI/水印/Logo/角标/可读文字/真实UI；无背景音乐仅环境音与人声

负向约束：
- 不要字幕、文字、水印、Logo、虚假 UI、插画、CG、反射重影、人物消失、道具瞬移、肢体穿模、多指变形
```
