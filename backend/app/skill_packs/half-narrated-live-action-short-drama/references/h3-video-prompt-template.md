# H3 视频提示词模板（短剧 / 单镜头）

工作台：参考图标签使用 `<Picture n>`，与最终 R2V 上传顺序一致。写稿可以看场景卡、整张 16:9 三联和三张裁切格来写环境、起幅、主动作与落幅；这些图不是 Picture 槽位。最终 R2V 只上传本镜角色卡与绑定道具设定板，场景卡、三联母图及三张裁切格不上传，必须转写为文字。无权威参考时使用 T2V。成片始终单一确认画幅，禁止分栏，禁止把三格同时摆进画面。角色 `<Picture n>` 是单人多视图设定板：只锁身份、发型、服装；禁止把分格、白底、重复小人带进镜头。有绑定道具时上传道具设定板：只锁外形与材质，禁止把分格、白底或重复小物件带进镜头；台灯、电脑、书籍、笔记本等桌面/手持物以外形以道具卡为准，不要用场景卡里的陈设顶替。三联构图只用于文字调度；衣服和五官与角色卡冲突时跟角色卡。

## 用途

用于生成单个 H3 视频镜头的最终提示词。只写一个镜头，不写整片分镜；时间码一律从 `00:00` 开始。

## 使用原则

- 先锁定镜头目的，再写画面内容。
- 按旁白、对白、画面内容来切镜，不写“第一段/第二段/第三段”这种抽象阶段名。
- 如果同一镜头内部需要变化，就写成“切到……/转到……/揭示……”等具体画面动作。
- 角色/道具 Picture、场景文字、三联文字调度、旁白、对白、负向约束都必须明确写出来；场景卡和三联不能写成 Picture。
- 开口和角色内心都写在「对白」里；内心标「（内心）」。内心挂在触发它的画面时段（如下摇看衣服），不要因为起幅能看见衣服就在 00:00 先念。本镜没有第三人称/第一人称旁白时，「旁白」写「本镜无第三人称旁白」，不要用角色内心或开口句充数。
- 只服务于同一个已确认镜头，不改变镜头编号和总时长。

## 填写模板

```text
镜头【编号】，总时长【X】秒，内部时间从00:00开始。
镜头目的：【这个镜头在剧情里要完成什么】。

参考素材：
- 【Picture 1..N 角色/道具设定板】提供身份或道具外形；场景与三联只在正文写成环境、起幅、主动作、落幅文字

必须出现的视觉内容：
- 【内容点1】
- 【内容点2】
- 【内容点3】

按旁白和画面内容切镜：
- 00:00–00:【a】：画面要看到【具体画面内容】，镜头动作【固定/轻推/切入/揭示/移焦】。
- 00:【a】–00:【b】：画面要补出【具体画面内容】，镜头动作【具体动作】。
- 00:【b】–00:【c】：画面收束到【具体画面内容】，保持【连续性/情绪/站位】。

对白：
- 【角色名】在【时间段】说：“【逐字台词】”
- 【角色名】不说话，嘴唇闭合

旁白：
- 若本镜无第三人称/第一人称旁白，只写：「本镜无第三人称旁白。角色内心写在对白里，标（内心）。」不要用内心或开口句充数。
- 仅当 user 给出旁白原文时，才写成：【时间段】第一人称/第三人称旁白：“【逐字旁白】”

画面要求：
- 【景别/运镜/空间关系/动作/情绪】
- 【门内外/前景中景背景/站位关系】
- 【连续性要求】

负向约束：
- 不要【插画/CG/文字/水印/美颜滤镜/反射重影/人物消失/瞬移等】
```

## 示例骨架

```text
镜头03，总时长10秒，内部时间从00:00开始。
镜头目的：张凡隔门求情，林晨隔门识破。

参考素材：
- <Picture 1> 林晨角色卡（多视图设定板），只锁身份外形，不要把分格/白底/重复小人抄进镜头
- <Picture 2> 林月角色卡（多视图设定板），只锁身份外形，不要把分格/白底/重复小人抄进镜头
- <Picture 3> 张凡角色卡（多视图设定板），只锁身份外形，不要把分格/白底/重复小人抄进镜头
- 场景文字：洪灾仓库门内外空间、卷帘门、积水与雨幕；场景卡仅供写稿，不上传
- 三联文字：00:00 门外建立、主动作段张凡弯腰求情、落幅门内阴影收束；三联格仅供写稿，不上传

必须出现的视觉内容：
- 门外暴雨、积水、仓库卷帘门
- 林月和张凡在门外的站位关系
- 林晨在门内阴影中的观察状态

按旁白和画面内容切镜：
- 00:00–00:03：建立门外空间，林月靠近卷帘门，张凡站在她身后半步，林晨只在门缝后出现。
- 00:03–00:07：张凡弯腰讨好、双手请求，林月保持压抑和不安，门缝后林晨冷眼识破。
- 00:07–00:10：门内阴影收束，张凡恐惧露出，林晨保持冷静警惕。

对白：
- 张凡在 00:03–00:05 说：“林月，让你哥让我们进去。我们是一家人啊！”
- 其他人物不说话，嘴唇闭合

旁白：
- 00:05–00:10 第一人称旁白：“张凡，一个油嘴滑舌的废物，末日来之前靠我妹妹养着，末日来了就想着蹭我的安全屋。”

画面要求：
- 真实剧情片摄影，门内外轴线稳定，湿衣和雨幕连续
- 林晨不能离开门内，张凡不能瞬移进仓库
- 画面中不能出现反射重影、字幕、文字、水印

负向约束：
- 不要插画、CG、文字、水印、美颜滤镜、人物消失、瞬移、反射重影
```
