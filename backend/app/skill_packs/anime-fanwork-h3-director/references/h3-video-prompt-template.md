# H3 视频提示词模板（二创动漫 / 单镜头）

工作台：参考图标签使用 `<Picture n>`，与 R2V 上传顺序一致。本工作台不为单镜生成三联关键帧，R2V 只上传**角色设定板**与**场景主视角**；`<Picture n>` 只能引用实际上传的这几张，禁止虚构未上传的构图裁切或起幅／中格／落幅路标。角色卡是单人多视图设定板，只锁身份、发型、服装与标志物；禁止把分格、白底、重复小人带进镜头。场景卡只提供环境空间，不锁站位。成片始终单一 **16:9 横屏**，禁止分栏与画中画。

> **重要（维护说明，不进写稿提示词）**：`skill_packs.handlers._extract_official_fill_skeleton` 只把本文件**第一个 ```text 代码围栏里的内容**注入双稿作者的 system prompt；围栏外的说明不会被模型读到。因此所有硬性规则必须写在下方围栏内部。修改本文件后需重启后端（或调用 `reset_pack_cache()`）才会生效。

## 用途

用于生成单个 MiniMax H3 视频镜头的最终提示词。只写一个镜头，不写整片分镜；时间码一律从 `00:00` 开始，单镜 5–15 整数秒。

## 使用原则

- 先锁定镜头目的，再写画面内容；全片统一 2D 赛璐璐平涂、中粗黑描线、硬边两层阴影、高饱和大色块。
- 按旁白、对白、画面内容切镜，不写「第一段／第二段」这种抽象阶段名；切点严格递增，每次切换必须带来新信息。
- 每镜至少保留一处原作辨识锚点（草帽、红发、空袖、蓝色破边短裤、疤痕等），形态变化角色仍要认得出是同一个人。
- 参考图、角色卡、场景卡、旁白、对白、负向约束都必须明确写出；`<Picture n>` 只引用实际上传的卡。
- 开口、角色内心、第三人称旁白分三通道。内心标「（内心）」并写成画外音，所有可见角色嘴唇闭合；本镜没有旁白就写「本镜无第三人称旁白」，不要用内心或开口句充数。
- 不改变镜头编号与总时长；上一镜的服装、发型、标志物、伤口、光线方向必须继承。
- **语言锁**：台词与旁白是日语就逐字抄日语，`<d>` 标签内不翻译、不音译、不改写成中文或英文；英文段落只写画面与声音描述。中文字幕单独烧制，不写进 `<d>`，也不出现在画面要求里。

## 填写模板（围栏内全文会作为双稿作者的模板与硬规则）

```text
【本配方定位】IP 同人二创 2D 赛璐璐原作画风短剧，非真人实拍、非 3D CGI。system 里出现的「半解说真人短剧」只是工作台通用措辞，本镜画面要求一律按下面的 2D cel-shaded anime 条款写，禁止写真人实拍、电影柔光、胶片颗粒。

【写稿硬规则｜违反任意一条整篇作废】
1. 逐字：user「表演顺序」里每一句台词与画外音都必须逐字抄进中文八块与英文 <d>，禁止翻译、音译、概括、改写、截断；禁止把「！」「……」之类标点单独写成一句；禁止把两个说话人的台词合并进一条 <d>；禁止把开口句复制成内心。
2. 顺序：<d> 的条数与先后顺序必须严格等于「表演顺序」编号 1、2、3……，不得按画面时间码重排，不得漏句、增句、换序。中文「对白」块也必须按同一编号顺序逐条写。
3. 分秒落位：中文「按旁白和画面内容切镜」的每条时间段行要把它承载的那句台词原文逐字写进同一行；「对白」块每条也必须带时间段。不同台词必须落在不同 00:00–00:XX 时间段，禁止全部挤在同一段，禁止台词只出现在「对白」块而分秒段里没有。
4. 三通道：开口只进「对白」并标（开口）；画外音／角色内心只进「对白」并标（内心），注明该时段所有可见角色嘴唇闭合；没有第三人称旁白时「旁白」块整段照抄「本镜无第三人称旁白。角色内心写在对白里，标（内心）。」，禁止填入开口或内心原文。
5. 参考标签：user 列出的每个 <Picture n> 必须在中文「参考素材」以及英文 subject_definitions / retention_analysis / detailed_description 中**带尖括号逐字出现**；禁止写成 (Picture 1)、Picture 1、图片 1 或干脆省略；禁止虚构未列出的编号。
6. 英文六段：标题独占一行、带英文冒号、顺序为 subject_definitions: → summary: → retention_analysis: → detailed_description: → overall_soundscape: → non_diegetic_music:。detailed_description 以 [Shot 1] 起，时间码只用整秒。英文正文只描述画面与声音，唯一例外是 <d> 里的日语台词原文；不得出现中文说明句。
7. 对白标签：开口写 Name (Sn) says: <d>[Chinese] 日语原文</d>；画外音写 An off-screen inner voice (not produced by the on-screen mouth) says in an off-screen voiceover: <d>[Chinese] 日语原文</d> while all visible characters' lips remain completely closed.。「[Chinese]」只是工作台固定标签，它后面的文字必须是日语原文，不得改成中文；画外音禁止用 says: 或 thinks。
8. 画幅与时长：单一 16:9 横屏，时间码从 00:00 起覆盖到总时长，只用整秒 00:03 这类写法；禁止分栏、画中画、画面内文字、水印、Logo、原作漫画分镜或截图。
9. 抬头必须把占位符连方括号一起换成真数字：按 user 的「镜号」「时长」写成「镜头2，总时长9秒，内部时间从00:00开始，16:9 横屏。」这样的实际整数；禁止在成稿里留下任何【】或 N／X 占位符。
10. 一镜只有一个镜头：detailed_description 全段只允许出现一次 [Shot 1]，后续按时间码换行续写；禁止写 [Shot 2] / [Shot 3] 或把一条分秒当成第二个镜头。
11. 日语台词至少含一个汉字；不得把 user 给的台词改写成全假名，否则工作台按汉字片段做的逐字与分段校验会漏判。
12. 一镜一信息（最重要）：每一镜只承担一个观众必须看懂的信息——谁、在哪、什么关系、什么情绪。动作是为这个信息服务的，不是把剧本里的动词原样画出来。整镜只有一个动作主语、一个连续动作、一个结果；禁止「踢门→倒酒→擦脸→起身」这类多动作串联。动作必须写成「从 A 到 B」的过程句（「手从肩头抬到眼前」「身体从吧台边后仰到失衡」），禁止「他在擦脸」这种状态句。
13. 画面里必须有可读的动：主体在画面内的位置或姿态要有明显变化（站→半跪、画面下缘→画面上缘、起点格→终点格），位移至少跨越画面高度的 1/4 或宽度的 1/3；或者镜头有一次真实位移。二者至少占一个，但**优先让主体自己动**——角色在固定机位里演，比镜头推过去更有戏。动作幅度必须够大且写具体：把「轻微后仰」「微微侧头」「缓缓抬手」这类小幅度变化改写成真实位移（整条绳子被拽直、整条船被拖动、整个人被甩出去），落点写具体位置（落到船底、撞上木桩、退到栈桥边缘），禁止只写「略微／稍稍」。
14. 运镜是例外，不是标配（重要）：默认固定机位，写 `camera: <framing>, locked off`。只有当这一镜是情绪转折、或要强调一个关键细节时，才允许一次运镜，且必须同时满足：① 景别最多跨一档（中景→中近景可以，中景→大特写禁止）；② 落幅必须还能看清主体的脸、或双手在做什么；③ 推到位置就停，禁止继续推到只剩皮肤、布料、刀刃这类不可读的局部。全片固定机位与运镜的镜头数比例按 3:1 以上配。
15. 景别只有：大全景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写。运镜动词只用：推近、拉远、横移、跟移、升、降、摇、甩。禁止「镜头旋转」「环绕」「变焦爆发」这类高风险词。大特写只给「表情或关键道具本身就是信息」的镜头，且必须固定机位。
16. 英文 detailed_description 的每个时间码段都要写清两件事：① 镜头 `camera: <framing>, locked off`，或整镜唯一一次 `camera: <framing> to <framing>, <push in | pull out | pan left | pan right | tilt up | track>, landing by 00:0M then locked`；② 主体动 `the subject moves from <起点> to <终点>`，并用 by 00:0X 写死落地时刻。运镜整镜只写一次，禁止中途换向或折返，禁止写成 over the whole clip。
17. 情绪必须准：写动作的同时要写清表情和视线方向（「咧嘴笑，眼睛睁大」「眉头拧起，视线躲开」「咬牙，下巴绷紧」）。禁止让角色在本该疼痛、惊恐、愤怒的镜头里笑；表情与本镜情绪不符等于废镜。
18. 让观众看得懂：禁止把落幅停在无法辨认的局部（只剩一只耳朵、一片布料、一个刀尖）。每一段的收尾画面都要能看出「这是谁、他在做什么」。
19. 节奏（反慢动作硬规则，违反整镜作废）：5 秒镜头按「起手 → 动作落地 → 余韵」三拍写，不是把动作均匀铺成慢放。动作主体段必须在 00:00 到总时长前 1/2 内完成并落到终点，后半段只写结果、受伤/受力反应与余韵（对手被带动的姿态、道具回弹、水面涟漪、衣摆回落、呼吸起伏）。禁止慢动作、时间拉伸、全程匀速、几乎静止；中文与英文都禁止出现「匀速」「缓慢推进」「缓缓」「slow motion」「slow-motion」「time-stretched」「near-static」「evenly over the whole clip」。英文动作句用 fast, snappy, weighty 写速度与力度，并写死落地时刻（by 00:0X the action has landed）。
20. 跨镜承接（防跳戏）：除第 1 镜外，首段必须从「上一镜结束时的可见状态」起手——站位、朝向、镜头侧、光线方向、道具与伤口位置、人物之间的相对距离都要接上；换机位只改变构图，不允许重置站位、让已发生的动作倒退，或让人物凭空换位置。首段写 continues from the previous shot's final state: <可见状态>；若 user 提供「上一镜承接」，必须逐项落实。

镜头【编号】，总时长【X】秒，内部时间从00:00开始，16:9 横屏。

镜头目的：
【这个镜头在剧情里要完成什么，只写一个动作核心】。

参考素材：
- <Picture 1>【角色设定板 / 角色名】提供【身份、发型、服装、标志物】
- <Picture 2>【角色设定板 / 角色名】提供【身份、形态特征】
- <Picture 3>【场景主视角 / 场景名】提供【环境、光色、空间关系】

必须出现的视觉内容：
- 【原作辨识锚点，至少一处】

按旁白和画面内容切镜（每段都要写出主体从哪到哪，禁止只写状态；机位默认固定）：
- 00:00–00:【a】（前 1/3，动作爆发）：【主体】从【起点位置/姿态】起手，执行【唯一一个动作动词】，动作要快、要有力度，本段末必须已到【终点位置/姿态】的 70%；机位【固定 <景别>】或【一次推近/横移/跟移，起幅<景别>→落幅<景别>，跨度不超过一档，00:0【a】 前到位】。本段台词原文【逐字抄入，若本段无台词写「本段无台词」】。
```

## 英文六段 Ref2VA 顺序

`subject_definitions` → `summary` → `retention_analysis` → `detailed_description`（`[Shot 1]` 起，含时间码、speaker id、`<d>` 对白）→ `overall_soundscape` → `non_diegetic_music`。字段名、顺序、参考标签保持原样；对白、歌词与画面文字保留原语言。`detailed_description` 里写明 `2D cel-shaded anime, consistent with the supplied character sheet`，并显式排除 `photoreal, live-action, 3D CGI, comic panel screenshots, text, watermark, identity drift`。
