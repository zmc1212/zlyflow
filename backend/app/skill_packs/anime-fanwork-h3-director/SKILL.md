# 二创动漫·原作风锁定导演

适用场景：已有原作 IP 的世界观、人物与画风，要写一段新的同人剧情并生成短剧镜头。目标是「一眼认得出是哪个作品、哪个人物」，同时不直接复制原作画面。不适用场景：真人实拍、写实电影感、3D CG、纯影视解说、纯剪辑混剪。

## 1. 灵感与故事与剧本

- 一句话写明「把原作哪个设定／伏笔，回填到哪一段剧情」，以及这是**粉丝推测／非官方二创**，不冒充原作设定。
- 剧本对白与画面说明必须分成两条通道：动作段只写看得见的表演与调度，台词单独成行；不要把整段台词粘进动作，也不要用旁白复述画面已经演出来的信息。
- 每一集只完成一个信息动作（埋破绽／揭真相／留钩子），单集 5–15 秒的镜头里不塞两个转折。
- 角色沿用原作辨识度：大眼、简化鼻口、分缕高光发、瘦长四肢与夸张关节；人物标志物（草帽、红发、空袖、蓝色破边短裤、疤痕）在每镜至少出现一处。
- 台词短、留白多；解释交给画面与旁白，不写大段设定说明。
- **配音语言**：原作是日漫时，角色开口台词与第三人称旁白一律写成日语，按原作角色口吻（少年用「おれ」「〜だよ」、船长用沉稳简体、山贼用粗暴语尾）；字幕保留中文，单独烧制，不写进生图提示词。角色名前缀仍用剧本里的中文名，用于绑定资产，只把引号内的台词换成日语。

## 2. 分集与故事与剧本

- 分集按「信息揭晓顺序」切，不按场景数量切；相邻集之间要有可对齐的机位或音效，便于观众自己拼时间线。
- 每集给出镜数、总时长、单镜时长（整数 5–15 秒）与画幅；同一集内画幅唯一，禁止分栏、画中画、分屏。
- 分集结构里标明本集出现的形态变化节点（例如「普通形态 → 觉醒失败形态 → 被按回」），并写清形态切换发生在第几镜，避免跨镜形象漂移。

## 3. 角色卡与场景卡·定妆

- 角色卡是**单人多视图设定板**：纯白底，正面／侧面／背面三视图 + 头部表情特写；只锁身份、发型、服装、标志物与配色，不锁站位、不锁构图。
- 场景卡是**无人主视角广角**：只提供环境、光色与空间关系，不锁人物站位。
- 全片所有卡统一 2D 赛璐璐平涂、中粗黑描线收边、硬边两层阴影、高饱和大色块、干净线稿。禁止写实照片质感、3D CGI、皮肤毛孔、胶片颗粒、渐变柔光、电影柔焦。
- 形态变化角色（如觉醒失败体）必须与常态角色共用一套辨识锚点：仍看得出是同一个人——同样的草帽、短裤、瘦长四肢与面部比例，只是整体染黑／兽化；绝不能画成另一个物种的怪物。
- 卡面禁止出现文字、水印、原作漫画分镜或截图、多余手指与肢体。

## 4. 分镜与镜头合同

- 每镜写成可执行的镜头合同：镜号、总时长、镜头目的、出场角色卡、场景卡、动作、运镜、对白、音效、画面要求、负向约束。
- 运镜写「类型 + 幅度 + 速度」（低机位小幅慢推／大幅快甩），不写「很有电影感」这类形容词。硬切用「切到／转到／揭示」，不写无依据的溶解。
- 时间码从本镜 `00:00` 起，切点严格递增且落在总时长内；每次切换必须带来新信息（主体、空间、状态、视点或时间），只是距离变化就改用运镜而不是切镜。
- 跨镜连续性：上一镜的服装／发型／标志物／伤口／光线方向，下一镜必须继承；形态变化只在标定的那一镜发生，其余镜保持同一形态。
- 关键反转镜允许只给局部（剪影、獠牙高光、瞳孔反光、齿痕特写），但**仍要留下至少一个能认出人物的标志物轮廓**，不要靠全黑遮掉身份。

## 8. 视频生成与提示词

每个镜头一次写出「中文八块分秒稿」+「英文六段 Ref2VA」，不要按一句对白重排运镜，也不要把整集合并成一段。

**语言锁**：剧本里已经是日语的台词与旁白必须逐字保留，中文八块里的「对白／旁白」原样抄日语，`<d>` 标签内也用日语原文；英文六段的结构说明用英文，但绝不把日语台词翻译、音译成中文或英文，也不要改成「角色用日语说……」这种间接引语。字幕中文只作为烧制清单，不进入 `<d>`。H3 原生支持日语对白，无需额外配音标注。

中文八块：镜头目的 / 参考素材 / 必须出现的视觉内容 / 按旁白与画面内容切镜（带时间码）/ 对白 / 旁白 / 画面要求 / 负向约束。开口、角色内心、第三人称旁白分三通道写；本镜没有旁白就写「本镜无第三人称旁白」，不要用内心或开口句充数。角色内心写成画外音，所有可见角色嘴唇闭合。

英文六段严格按官方顺序与字段名：

1. `subject_definitions` — 逐个定义 `<Picture n>` 对应的是哪张角色卡／场景卡，以及要保留的辨识特征。
2. `summary` — 本镜一句话摘要，含画风锚点（2D cel-shaded anime, clean black outlines, flat saturated colors）。
3. `retention_analysis` — 逐张说明参考图保留什么、丢弃什么（保留身份发型服装标志物，丢弃白底、分格、重复小人）。
4. `detailed_description` — `[Shot 1] ...`，按时间码写画面、动作、运镜、对白与音效；对白用稳定 speaker id 与 `<d>` 标签，中文台词原样保留。
5. `overall_soundscape` — 1–4 句环境声与动作声，不重复对白。
6. `non_diegetic_music` — 1–3 句配乐编制／节奏／力度，不写情绪形容词。

参考标签在所有段落保持一致；`<Picture n>` 只引用实际上传的卡。英文正文里必须写明 `2D cel-shaded anime, consistent with the supplied character sheet`，并在负向处显式排除 `photoreal, live-action, 3D CGI, realistic skin texture, film grain, comic panel screenshots, text, watermark, extra limbs, identity drift`。

**写稿校验硬约束**（工作台会逐条硬校验，任一不满足整镜作废）：

- `<d>` 的条数与顺序必须严格等于 user 给出的「表演顺序」编号，不得按画面时间码重排；中文「对白」块同样按编号顺序写。日语原文逐字保留，禁止截断、禁止把标点单独成句、禁止两个说话人合并进一条 `<d>`。
- 中文「按旁白和画面内容切镜」的每条时间段行要把该段台词原文逐字写进同一行；不同台词必须落在不同的 `00:00–00:XX` 时间段，禁止全部挤在同一段。
- user 列出的每个 `<Picture n>` 必须在中文「参考素材」与英文 `subject_definitions` / `retention_analysis` / `detailed_description` 中**带尖括号逐字出现**；写成 `(Picture 1)` 或 `Picture 1` 一律判缺失。
- 第三人称旁白／画外音用 MiniMax 官方画外音句式并在 `</d>` 后写闭嘴，禁止 `says:` 口型同步；`[Chinese]` 只是工作台固定标签，标签后必须是日语原文。
- 详细规则以 `references/h3-video-prompt-template.md` 的代码围栏内容为准（该围栏是唯一会被注入双稿作者 system prompt 的部分）。

## 合规与标注

- 全片为**非官方同人二创／粉丝推测**，片尾字幕注明；不使用原作漫画分镜、截图、官方 LOGO，不宣称是官方剧情。
- 不生成过度血腥的断肢特写，用空袖管、断口齿痕、人物反应替代。
- 画面内不出现文字与水印（剧情字幕除外，且字幕单独烧制，不写进生图提示词）。
