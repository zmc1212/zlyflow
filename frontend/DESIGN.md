## 1. Creative Direction

**North star:** The Dual-Mode Conversation Studio（双主题会话式创作台）。

界面应像成熟的 AI 创作会话产品：暗色默认使用中性炭黑表面，浅色使用冷白画布；两者共享窄图标轨道、任务会话列与开放的中央创作区。重点落在提示词、运行状态和结果上，图片模式是现有视频制作台的同一产品面，不应像嵌入的第三方工具。

**Signature:** 76px 图标轨道、240px 任务会话列与主题表面色创作输入面板共同形成识别：空状态时输入面板跟随问候语居中排在文档流中，打开任务后停靠视口底部。任务行只显示一行截断标题，悬浮后才显示打开和再次生成操作。

**Avoid:** 暗色霓虹或无层次纯黑控制台、渐变文字、无意义玻璃卡片、每个区块都套卡、面向开发者的节点参数、过度圆润的玩具感。

主按钮使用实色靛蓝；禁用态降低对比并保留原因提示。状态颜色不单独承载含义，必须同时提供文字或图标。视频和图片预览画布可在两种主题下保持近黑色。

### Typography

- 使用系统无衬线栈：`Inter, "PingFang SC", "Microsoft YaHei", sans-serif`。
- 页面标题 18–22px / 600；区块标题 14–16px / 600；正文 13–14px；辅助信息 12px。
- 数字、任务 ID 与运行参数可使用等宽字体，但不用于大段正文。

### Spacing and shape

- 4px 基础网格；常用间距为 8、12、16、24、32px。
- 控件高度以 Ant Design 36–40px 为基线；可点击目标至少 40px，移动端至少 44px。
- 面板圆角 12px，输入与按钮 8px，缩略图 10px；避免多个不同大圆角竞争。
- 阴影只用于弹层与拖拽悬浮，必须同时包含垂直偏移和模糊；静态面板主要靠层级色与边框区分。

## 3. Layout

- 桌面端以 76px 图标轨道、240px 常驻任务会话列与弹性创作区构成三栏布局。
- 任务历史以常驻会话列承载：一行 36px、8px 圆角、活动项仅使用 5% 黑色覆盖层；移动端改为抽屉。
- 中央创作区为开放画布，输入面板最大宽度 1080px，使用当前主题表面色、24px 圆角和 1px 语义边框；空状态跟随问候语居中排在文档流中，打开任务后才贴近视口底部。
- 创作面板内部按“参考内容 / 提示词 / 参数工具栏”分层；首尾帧槽位保持 106px 高度，底部控件统一 36px，生成按钮保留明确的主操作视觉。
- `390×844` 下改为单列：媒介切换、编辑器、提交操作、结果依次排列；主要提交按钮可在安全区域内吸底。
- 轮次时间线控制信息密度；生成项使用响应式网格，1 张突出展示，2–4 张保持等权。

## 4. Component Conventions

- 生成类型切换使用创作面板中的 Ant Design `Select`，保持即梦式 36px 控件高度并提供“图片生成 / 视频生成”选项。
- 辅助文字必须使用当前主题的 `--studio-text-muted` 或 Ant Design 次级文本 token；传送到 `body` 的参数弹层也必须继承同一主题与可读性标准。视频模型触发器的桌面宽度至少容纳默认模型全称，不得依赖省略号。
- 任务会话行保持 36px 高度与 32px 封面缩略图；悬浮时显示 `Dropdown` 更多操作，支持置顶、重命名和删除。
- 业务输入、选择、数值、开关、页签、弹层和提示统一使用 Ant Design 原生组件。
- 参考图按上传顺序编号，支持拖拽排序和删除；编号同时用于提示词中的 `<Picture n>`。
- 参数按注册表的 `ui_group` 组织：`primary` 常显，`advanced` 放入“更多设置”，`internal` 永不出现在创建表单。
- 条件参数仅根据注册表返回的声明式条件判断；隐藏时不丢失后端默认值。
- 空状态必须说明下一步；错误状态给出可执行操作；加载态展示当前阶段而非只显示旋转图标。
- 图片项提供预览、保存、生成视频；失败项提供单项重试。视频项延续播放器、保存与失败重试。
- 破坏性操作使用危险色并二次确认；普通再次生成不弹确认。

## 5. Interaction and Motion

- 桌面顶栏提供快捷主题按钮；全工作区采用下述 2026-10-28 悬浮 Header，主题仍由根 Provider 驱动。移动端在账户菜单中提供切换，导演台自有移动顶栏也必须可达。浅色是首次访问默认值，选择只存于当前浏览器，不跟随系统自动变化。
- `index.html` 在 React 挂载前应用已保存主题，避免刷新闪烁；主题切换不得改变布局、滚动位置或正在编辑的内容。
- 动效服务于状态变化：面板切换 160–220ms，进度/上传反馈 180–260ms；尊重 `prefers-reduced-motion`。
- 不做持续漂浮或装饰性粒子。运行中的光带只出现于当前任务，并保持低亮度。
- 所有悬浮态必须有对应键盘焦点态；拖拽排序同时提供键盘可达的移动操作或菜单。

## 6. Content

- 用户文案使用简体中文和创作语义，例如“画面比例”“分辨率”“生成数量”“更多设置”。
- 不向普通用户显示 `remote_task_id`、采样节点、模型文件路径等内部概念。
- 配置锁定信息明确区分“GRS 未启用”“凭证主密钥不可用”“最近连接测试失败”，并给管理员下一步。
- 任务状态统一为排队中、生成中、部分完成、已完成、失败、中断；避免同一状态使用多种叫法。


## 2026-10-20 导演台助手 V2 表面约定

### Overview

**Creative North Star: "The Dual-Mode Conversation Studio（双主题会话式创作台）"**

助手是在既有导演工作台内完成的 Operate 表面扩展，功能组织参照用户提供的火龙工作流；没有新增品牌方向或独立 approved comp。以下规则仅适用于 `src/director2/assistant/`：在持续可操作的项目旁讨论、回答问题、阅读草稿，再明确决定采纳或执行。对话设计依据 beautifului 同源 MIT 项目 [ai-native-react-components](https://github.com/TurboKach/ai-native-react-components) 的 `globals.css`、`chat.tsx`、`prompt-bar.tsx`、`approval-card.tsx` 与 `tool-chips.tsx`，以实际构建的 `assistant.css` 为准。

**Key Characteristics:**

- 右侧非模态会话，消息独立滚动，输入与会话操作常驻。
- 中性表面与高对比正文，橙色 Skill、绿色专家和知识库以底色与图标区分选择。
- 问题、工具、引用、草稿和媒体卡连接真实状态，文字预览后采纳，媒体确认后执行。

### Colors

对话与助手 Tooltip 使用局部成对 `--director-*`；市场、知识库、草稿采纳与媒体确认弹层使用根级 `--studio-*` 和 Ant Design 主题。主题状态始终来自根 Provider。机器可读的局部 token 见[助手表面 brief](.impeccable/surfaces/assistant/brief.md) 的 frontmatter；[design.json](.impeccable/surfaces/assistant/design.json) 只扩展阴影、动效、组件预览与叙述，不替换本文件的全局规范。

**The Readable Selection Rule.** Skill、专家、知识库名称使用主正文 ink；橙色与绿色用于底色和图标，不能承担名称正文的对比。专家名称省略后通过 Tooltip 显示全名，知识库同时显示数量并在 Tooltip 列出完整库名。

**The Portal Theme Rule.** 助手 Tooltip 的独立 portal class 同时声明浅暗 token；浮层容器与箭头使用同一背景，文字与边框成对切换，不能依赖 Drawer 内的变量继承。

### Typography

沿用工作台无衬线字体栈，不引入展示字体。会话正文使用紧凑正文（13px，行高 1.8），问题与草稿标题（13px / 600），工具与来源等辅助信息（11.5–12px）。Markdown 标题按（22 / 18 / 15px）分层，表格和代码（12px）允许局部横向滚动，长正文保留换行。正文与卡片标题使用主 ink；说明、来源和工具过程使用次级 ink。

### Layout

右侧 Ant Design Drawer 默认宽（480px），可展开到（800px），展开上限保留视口侧边空间；无遮罩，背景工程继续可操作。顶部为标题、新对话、历史、宽度、主题与关闭，其下固定关联工程。消息流独立滚动，底部输入区不随长文滚走。消息区左右留白（18px），输入外沿（14px），卡片内部（14–16px）；工具栏保持紧凑。市场在桌面使用三列资源卡，知识库与采纳正文各自滚动。记录与验收范围为（1440×900）桌面浅暗两主题。

### Elevation & Depth

中性表面、inset 与细边框建立层次；问题卡、草稿卡和输入容器使用源码中的 `--director-shadow-card`，提交按钮使用 `--director-shadow-btn`。阴影随主题成对配置，市场与知识库继续使用工作台原有表面层级。消息只在到达时短暂淡入上移（300ms，`cubic-bezier(.23,1,.32,1)`），减少动态效果偏好下停用。

### Shapes

问题卡与草稿卡使用适度圆角（12px），输入容器（14px），Skill Tag 与工具按钮（6px），发送按钮（8px）。用户消息使用右下较小圆角的气泡；助手正文直接排在消息流中，只有问题、草稿或明确操作才形成容器。这些局部轮廓不替代全局控件规范。

### Components

- 输入区由 Ant Design `Input.TextArea`、`Tag`、`Button`、`Popover`、`Select` 和 `Tooltip` 组合；Enter 发送，Shift+Enter 换行，输入按内容增高。选中的 Skill 在框内显示可移除橙色 Tag，移除保留输入文字；专家在工具栏显示绿色选中底与图标，名称最大宽（68px）；知识库显示绿色选中底、图标和数量。运行期间锁定选择，发送操作切换为停止。
- 问题卡使用 Ant Design 单选、多选和自由输入，必须通过「提交」或「跳过」明确回应；回答后保留紧凑历史。工具轨迹显示真实结果，参考资料以可展开出处呈现原文片段。
- 草稿卡显示类型、版本和是否采纳；详情保留全文阅读、复制、导出、明确目标与变更预览。媒体卡保留目标、模型、数量及创作参数，并通过独立确认提交。两类操作不共用含糊的完成状态。
- 市场同时给内置与个人资源提供独立复制，个人资源另有编辑入口；复制创建副本，原资源保留。知识库使用真实解析状态、错误和重试，不以装饰性进度代替结果。

### Do's and Don'ts

- **Do** 使用 `assistant.css` 中已实现的双主题 token、Ant Design 业务组件及独立 Tooltip portal 主题；完整名称应可通过悬停读取。

## 2026-10-20 导演台智能剪辑表面约定

### Overview

智能剪辑按用户提供的 WorkRally 火龙漫剧截图组织素材、预览、属性与时间线，继承工作台已有视觉系统。以下约定仅适用于 `frontend/src/director2/smart-edit/`，不改变会话创作台和助手的布局。入口、真实文案与完整流程见[导演台流程与界面结构](../docs/导演台流程与界面结构.md#智能剪辑2026-10-20-新增)。

### Colors

页面、导航、面板、文字和弹层继续使用 `--studio-*` 与根级 Ant Design token。预览井在浅暗两主题下保持近黑色，控件与属性区域随根主题切换。局部 `--se-picture`、`--se-audio`、`--se-title`、`--se-playhead` 分别区分画面、音频、文字与播放头，浅暗值成对定义在 `smart-edit.css`；轨名、片段名称、图标和选中轮廓同时传达含义。

### Typography

沿用工作台系统无衬线字体栈。模块标题为紧凑标题（16px / 650），面板标题（12px / 600）、属性标签（12px）和素材名、说明（11px）按操作密度分层。播放时间码与尺标采用等宽字体和等宽数字，避免播放或缩放时数字跳动；这些局部字号不替换全局页面标题层级。

### Layout

上部常驻顶栏承载分集选择、保存状态、粗剪和导出（主题切换在全局悬浮页头，2026-10-28 起不再重复）。中部为左素材区、弹性预览和右属性列，下部常驻三轨时间线。左区含工具轨（44px），素材区总宽（280px）、属性列（250px）、时间线高（252px）；宽桌面（至少 1700px）分别增至 320px、280px、282px。区域之间使用紧凑间距（8px），素材、属性和时间线各自滚动，长属性表单不撑高预览。进入剪辑时项目菜单收为图标轨，右侧自动停靠本集智能剪辑助手；编辑区随助手宽度收窄，关闭助手恢复完整编辑宽度。

### Elevation & Depth

常驻面板以主题表面色与语义边框（1px）划分，不增加卡片阴影。尺标、轨名和交替轨面使用已有表面层级；近黑预览井承载媒体本身。片段选中与键盘焦点使用主色轮廓，拖动时通过透明度和叠放层级反馈位置。

### Shapes

编辑器面板使用适度圆角（8px），素材缩略图（6px）与时间线片段（4px）保持更紧凑的轮廓。缩略图裁切填充、主预览保留素材构图，裁切把手仅在悬浮或选中时强化。

### Components

- 业务选择、输入、数值、颜色、开关、页签、提示与确认均由 Ant Design 承载；左工具轨切换面板，右属性按所选片段类型展示画面、声音或文字控件。未选片段时给出下一步说明。
- 三轨固定为文字、画面、配音 / 音乐；选中片段与右侧属性、中央预览同步。磁吸、缩放、拖动和裁切服务于准确定位，快捷键在编辑器焦点内生效，输入及 Ant Design 控件保留自身键盘行为。
- 每集独立保存，顶栏以文字展示待保存、保存中、已保存或失败。失败与冲突提供重试、草稿 JSON 备份或重新加载操作。导出面板依次呈现成片和剪辑工程，并展示真实进度、结果与错误。

### Do's and Don'ts

- **Do** 使用真实素材代表帧比较色效；无法抽帧时给出明确示意。字幕预览和成片按相同显式断行规则排版，保留用户换行。
- **Do** 仅以本次桌面浅暗主题实测作为视觉基线（1440×900，素材、特效、文字与导出状态）；参考截图索引见流程文档。
- **Don't** 为本模块新增独立主题状态，或把其紧凑四区布局、工具按钮尺寸提升为全局组件规范。
- **Don't** 把结构验证写成外部剪辑客户端兼容承诺：OTIO 已由官方库解析，其他交换格式经过结构测试；剪映、Premiere、达芬奇客户端尚未实机验收。完整效果交付仍以 MP4 / JSON 为依据。
