创作页任务详情、导演台任务详情与工坊「视频版本」共用 Ant Design 业务确认面板。可切换一采/二采视频、下载，默认查看最新成功二采。导演台二采设置 auto_adopt=false，走已有工坊素材「采用此版」，不自动更新原采用清单。缓存失效显示明确提示和新建一采预览操作，不把 MP4 当成 latent。

导演二采的执行租约、检查点、取消标记与分组合成沿用当前服务。取消只中断对应 prompt；原片及成功分组保留。最终媒体尺寸来自实际 ffprobe，合成采用二采输出，避免把一采画布参数套到二采。

## API

创作页使用 `/api/jobs/{job_id}`；导演台使用 `/api/projects/{project_id}/jobs/{job_id}`：

- `POST .../refine`：JSON 只允许 refine_quality（1 或 2，默认 2）、source_revision、request_id；返回子任务 id/job_id。
- `GET .../refine`：源任务可确认状态、原片地址、子任务状态/进度/结果；不下发完整 graph 到轮询面板。
- `POST .../refine/preview`：明确新建一采预览，保留历史任务并生成新缓存。
- 创作页二采沿用 `POST .../cancel` 和 `POST .../retry`。
- 导演台二采取消为 `POST .../refine/cancel`，重试沿用 `POST .../retry`。

沿用会话和 CSRF。创作页确认、状态与新预览均执行任务属主检查；导演接口沿用项目 API 的鉴权模型，来源查询绑定 project_id。
