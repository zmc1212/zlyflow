# 画布渲染层统一方案（一期 + 三期）

> 目标：让「无限画布」`/canvas/:canvasId` 与「导演台资产画布」`/director/projects/:id/assets?view=canvas`
> 两个入口"看着像同一套"——同一画布内核、同一节点库、同一套交互与工具条，差异只落在宿主上下文。
>
> 本方案只覆盖渲染层，不改数据层：草稿 schema v2、`linked` 绑定、`canvas-generation` 提交管线、已接入工作流的节点 ID 全部不动。

---

## 0. 读码结论（本次新增认知）

### 0.1 数据层已共用

| 能力 | 唯一来源 |
|---|---|
| 画布实体 + linked 绑定 | `backend/app/canvas_store.py`（`get_or_create_linked`）、`POST /api/canvas/linked` |
| 草稿读写 | `frontend/src/canvas/canvas-api.ts`（`getCanvasProject` / `saveCanvasDraft`） |
| 草稿模型 | `frontend/src/canvas/canvas-model.ts`（schema v2）、`asset-canvas-sync.ts`（资产域投影/合并） |
| 生成提交 | `frontend/src/canvas/canvas-generation.ts`（`submitCanvasJob` / `canvasImageNodeFile`） |
| 保存队列 | `frontend/src/canvas/canvas-save.ts`（`createCanvasSaveQueue`） |

### 0.2 渲染层是两套**完整独立实现**（不是"换皮"）

| 维度 | 无限画布 | 资产画布 |
|---|---|---|
| 容器 | `canvas/CanvasWorkspace.tsx` + `canvas/CanvasEditor.tsx`（约 3450 行） | `director2/panes/AssetCreationCanvas.tsx`（866 行） |
| 节点库 | `canvas/CanvasNodes.tsx`（6 个组件：`Text/Image/Video/Artboard/Generator/Unknown`） | `director2/panes/AssetCanvasNodes.tsx`（`AssetGroupNode`/`AssetCreationNode`/`UniversalAssetNode`） |
| 顶栏 | `.canvas-editor-header`（面包屑 + 历史/图层/导出） | `.ac-header`（剧集 + 列表/画布 + 节点数 + 进入分镜） |
| 工具 | 左侧 `.canvas-rail` + 底部 `.canvas-bottombar` | 左侧 `.ac-library-panel` + 底部 `.ac-viewport-tools` + `.ac-bottom-tools` |
| 右键/端口菜单 | `CanvasEditor` 内置 | `.ac-context-menu` / `.ac-port-menu`（自带待连曲线 SVG） |
| 创作面板 | 挂在生成节点下方（`CanvasGeneratorComposer`，NodeToolbar） | 底部浮层 `.ac-composer` |
| 上下文 | `CanvasNodeActionsContext` + `CanvasGeneratorContext` + `CanvasMediaPreviewContext` | `AssetCanvasContext` |
| 历史 / 保存 / 轮询 / 生成 | `CanvasEditor` 内置 | `AssetCreationCanvas` 内置 |

### 0.3 两套节点是**两套设计语言**（这是"看着不像一套"的根因）

| 视觉要素 | 无限画布 | 资产画布 |
|---|---|---|
| 标题区 | 卡内 36px 标题行 `.canvas-node-title`（图标 + 标题 + 更多） | 浮在卡片**上方** 26px `.ac-node-heading`（`top:-33px`，卡外） |
| 卡片 | `border:1px var(--canvas-ui-border)`、`radius 11px`、`box-shadow` | `border:0`、`radius 10px`、`outline` 选中 |
| 选择态 | 边框变主色 + 1px 光晕 | `outline:1px var(--studio-text-secondary)`、`outline-offset:5px` |
| 端口 | `.canvas-handle` 细手柄（拖拽连线，`ConnectedHandle` 按上游类型着色） | `.ac-port` 26×26 圆形 `+`（**点击**开菜单） |
| 类型徽标 | `.canvas-node-type-icon` 21×21 彩底 | 无（用图标 + 文字） |
| 色调 token | `--canvas-text-tone` / `--canvas-image-tone` / `--canvas-video-tone` | `--studio-*` |

结论：**"让节点看着一套"必然要动资产画布的节点视觉**，而资产画布节点视觉已在 v006 设计确认（`docs/design-ref-director/jimeng-asset-canvas-20261105/`）。因此本期拆成"可安全落地"与"需拍板"两段。

## 1. 一期：共享节点层

### 1.1 目标

把"通用节点"（文本 / 图片 / 视频 / 生成器，以及无限画布特有的画板 / 未识别）收敛为**唯一来源**，两个入口 import 同一份；宿主域专属节点（资产卡、音频、剪辑工程）作为域节点注册进同一张表。

### 1.2 分两步

- **一期 A（本期落地，零像素变化）**：抽共享注册表契约 + 共享节点原语，两处 `nodeTypes` 改为经注册表组装。行为、外观完全不变，只是把"两处各写一份"收敛为"一处定义"。
- **一期 B（需拍板，见 §1.4）**：让资产画布的通用节点（`UniversalAssetNode` 的 text/image/video 分支）整体改用无限画布同款组件（含 `ConnectedHandle` / `NodeFloatingToolbar`）。这会给资产画布引入属性、下载、以此生成等能力与一条 host 适配层，属可见行为变化。

### 1.3 一期 A：新增文件与改造点（函数级）

#### 新增 `frontend/src/canvas/node-registry.ts`

```ts
import type { NodeTypes } from "@xyflow/react"
import {
  ArtboardCanvasNode, GeneratorCanvasNode, ImageCanvasNode,
  TextCanvasNode, UnknownCanvasNode, VideoCanvasNode,
} from "./CanvasNodes"

/** 通用节点注册表：无限画布与导演资产画布共用的唯一来源。 */
export const baseNodeTypes: NodeTypes = {
  text: TextCanvasNode,
  image: ImageCanvasNode,
  video: VideoCanvasNode,
  artboard: ArtboardCanvasNode,
  generator: GeneratorCanvasNode,
  unknown: UnknownCanvasNode,
}

/** 以通用节点为底叠加宿主域专属节点；同名以 domain 覆盖。 */
export function buildNodeTypes(domain: NodeTypes = {}): NodeTypes {
  return { ...baseNodeTypes, ...domain }
}
```

#### 新增 `frontend/src/canvas/node-primitives.tsx`

把 `CanvasNodes.tsx` 里的"非节点"部分抽为单一来源（节点组件反过来依赖它们）：

- `CanvasMediaPreview` 类型、`CanvasMediaPreviewContext`
- `CanvasGeneratorContextValue` 类型、`CanvasGeneratorContext`
- `CanvasNodeActions` 类型、`CanvasNodeActionsContext`
- `ConnectedHandle`（按上游节点类型着色的端口）
- `branchMenu`、`NodeFloatingToolbar`（节点悬浮工具条）
- `NODE_RESIZE_LINE` / `NODE_RESIZE_HANDLE` 常量（原 `resizeLine` / `resizeHandle`）

`CanvasNodes.tsx` 保留 `export { ... } from "./node-primitives"` 的**回传导出**，`CanvasEditor.tsx` / `CanvasGeneratorComposer.tsx` / `CanvasInspector.tsx` / `CanvasGeneratorInspector.tsx` / `CanvasSidePanel.tsx` / `CanvasNodes.test.tsx` 的既有 import 路径不变。

#### 改造 `frontend/src/canvas/CanvasNodes.tsx`

删除已迁出的定义，改为 `import` + 回传 `export`。节点组件的 DOM、类名、行为**一行不改**。

#### 改造 `frontend/src/canvas/CanvasEditor.tsx`

```ts
- const nodeTypes: NodeTypes = { text: ..., image: ..., ... }
+ import { baseNodeTypes } from "./node-registry"
+ // <ReactFlow nodeTypes={baseNodeTypes} … />（原 nodeTypes 常量删除）
```

#### 改造 `frontend/src/director2/panes/AssetCreationCanvas.tsx`

```ts
- const nodeTypes = { assetGroup: AssetGroupNode, assetCreation: AssetCreationNode,
-   generator: UniversalAssetNode, video: UniversalAssetNode, image: UniversalAssetNode,
-   text: UniversalAssetNode, audio: UniversalAssetNode, editor: UniversalAssetNode }
+ import { buildNodeTypes } from "../../canvas/node-registry"
+ const domainNodeTypes: NodeTypes = {
+   assetGroup: AssetGroupNode, assetCreation: AssetCreationNode,
+   generator: UniversalAssetNode, video: UniversalAssetNode, image: UniversalAssetNode,
+   text: UniversalAssetNode, audio: UniversalAssetNode, editor: UniversalAssetNode,
+ }
+ const nodeTypes = useMemo(() => buildNodeTypes(domainNodeTypes), [])
```

（映射与现状逐条相同，渲染结果不变；`buildNodeTypes` 只是把"通用节点清单"从一个地方来。）

### 1.4 一期 B：需拍板项（本期不落地）

把资产画布通用节点换成无限画布组件，需要新增一条 host 适配层：

- 在资产画布提供 `CanvasNodeActionsContext` + `CanvasMediaPreviewContext`，把操作映射到 `choose` / `chooseFile` / `duplicate` / `removeCanvasNode` / `createGeneratorFrom` / `actions.save`；
- `CanvasNodeActions` 增加**能力位**（`canInspect` / `canDownload` / `canBranch`），资产画布按能力关闭它没有的能力（如"节点属性"面板）；
- 资产画布的生成器保留其自带底部 `ac-composer`（与资产槽位强绑定），不换成 `CanvasGeneratorComposer`；
- 资产画布节点视觉随之切到无限画布语言（标题进卡内、边框选中、细手柄）——**这是可见变化，需确认是否接受覆盖 v006 节点视觉**。

## 2. 三期：节点样式分层

### 2.1 一期 A 已落地部分

- 新增 `frontend/src/canvas/node-tokens.css`：定义一组共享节点语义 token（卡片圆角 / 阴影 / 边框 / 标题行高 / 类型色调），作为两套 CSS 的**共同底座契约**。本期只被无限画布消费（数值与现状一致，零像素变化），资产画布仅 `@import` 该文件备用。

### 2.2 token 表（拟）

```css
:root {
  --canvas-node-radius: 11px;
  --canvas-node-shadow: var(--canvas-node-shadow);
  --canvas-node-border: var(--canvas-ui-border);
  --canvas-node-header-height: 36px;
  --canvas-node-tone-text: var(--canvas-text-tone);
  --canvas-node-tone-image: var(--canvas-image-tone);
  --canvas-node-tone-video: var(--canvas-video-tone);
}
```

### 2.3 需拍板项（本期不落地）

- 资产画布节点外壳是否改用共享 token（即 §1.4 的视觉对齐）；
- 若对齐，`asset-creation-canvas.css` / `asset-canvas-workspace.css` 中 `.ac-node` / `.ac-node-heading` / `.ac-port` 的规则需改成消费共享 token 或改为共享类。
