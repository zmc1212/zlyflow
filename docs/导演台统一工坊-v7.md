# 导演台统一工坊 v7

当前流程基线：2026-09-25。本文替代旧的 AI／手动双模式、制作方案 Tab 和镜头级 H3 工作区设计。旧 v4/v5/v6 文档仅解释历史任务，不再定义新入口。

### 界面保留原则（2026-09-25 用户纠正后）

流程收敛不等于重做 UI。复用既有 `content-library.css`、`episode-workshop.css` 和组件：内容库保留左侧文档列表、右侧剧本发展与详情；工坊首页保留分集卡片网格；镜头列表保留缩略图卡片；素材组的本镜人物、场景、道具使用照片墙和图片选择面板，不能改成下拉表单。更多视频设置继续使用 `Director2VideoSettingsPopover` 大浮层，参数由注册表驱动。资产库保留原卡片、分类统计与表单，仅在既有批量工具栏增加采纳稿提取入口，避免挤占标题栏。

只迁移重复功能的归属与数据读写；不要重新设计已经确认的布局、间距、卡片或双主题样式。对话创作区域沿用原组件，本次不改其设计 token。

## 用户流程与内容归属

创意／导入 → 内容库发展剧本并采纳 → 工坊规划镜头和分组 → 素材组准备参考、生成并采纳 H3 → 视频生成和采用 → 可选声音 → 合成导出。

| 区域 | 唯一编辑对象 | 下一步 |
| --- | --- | --- |
| 内容库 | 原始创意、策划、扩写稿、审稿与采纳版本 | 采纳自动建立／关联工坊分集 |
| 工坊／镜头／规划镜头 | 当前集镜头结构及相邻分组 | 确认候选后准备素材 |
| 资产库 | 跨镜复用的人物造型、场景、道具、参考音 | 由本镜与组引用 |
| 工坊／镜头／素材组 | 本镜资产引用、写稿参考、有效 H3 正文；组公共设定和有序视频参考 | 使用已保存快照生成视频 |
| 工坊／镜头／视频 | Take 预览、采用、超分 | 确认采用关系 |
| 工坊／声音 | 相关视频区间的可选补配 | 原声可直接进入合成 |
| 工坊／合成 | 采用清单、声音编排、导出历史 | 完整视频 |
| 全部任务 | 进度、错误、取消、按原输入重试、返回所属对象 | 不另存提示词或采用关系 |

项目导航仍为内容库、资产库、剧集工坊、全部任务。工坊主 Tab 只有镜头、声音、合成；镜头检查器为镜头内容、素材组、视频。取消全局模式切换。`mode=agent` 移除参数；`tab=plan`、`tab=script` 兼容进入镜头页。工坊的剧本预览只读，修改回到原内容库文档。

短视频批量、VACE 参考片转绘、Hypit 结构改编保留独立工作流和数据；统一任务表达，不并入本集规划。

## 规划、分组与候选

规划输入为采纳稿版本、画幅、目标时长、自动或指定目标镜头数、每组最多镜头数。默认每组 3 镜，合法上限来自工作流注册表；单镜工作流上限为 1。

规划只生成来源剧情、动作、对白归属、场景、景别、机位／运镜、预估时长和衔接。不会生成 H3，也不生成可编辑的 Part。镜头数无法兼顾剧情时显示建议数量，用户确认后才能生效。生成失败、取消、网络中断均不替换当前制作版本。

确认前展示完整镜头列表、新增／保留／删除数量和分组；候选支持拍摄参数调整。分组是程序操作，不调用 AI：保持相邻顺序，按场景、时间、镜数和容量分组；支持拆组与合并兼容相邻组。不同公共设定或参考编号不可静默合并。需要移动边界时先拆后合。

确认后镜头 ID、数量、顺序固定。写词和视频任务不拆镜；需要拆镜必须回到规划生成候选。重新规划只作用当前集。复用只依据明确身份和结构指纹，不按数组下标猜测。

## 素材与提示词

公共资产在资产库维护；同组最终视频参考由有序槽位定义 `<Picture n>`，组内各镜不能私自改变编号含义。改变公共设定或参考会使相关镜头正文待检查，历史视频保留。

写稿参考与视频参考分开保存。草图、三联关键帧、动作预演是可选参考准备工具。写稿可看图，但只有组视频槽位中的图片提交到视频工作流。

本镜、本组、本集写词调用同一个 `WorkshopService`。指导来自 H3 现用模板与 skill，直接形成最终正文候选，不先生成另一份 Director 完整稿。逐镜保存检查点，重试只处理失败镜头。AI 候选必须经采用才能替换正文；编辑已发生时旧候选不能覆盖。手工保存具有独立历史。

正文使用本镜局部时间，从零开始，到确认时长结束；可验证的对白遗漏、参考编号、时间范围、容量错误阻断提交。校验器不润色正文。公共部分在复制和提交时组装，本镜有效正文只有一份。

## 视频、声音、合成

视频入口只读取已保存的提示词和参考快照，不调用写作服务。工作流能力来自注册表；连续组按已确认分组编译，单镜使用兼容路由，无兼容能力时报错。运行中的重复范围阻止重复提交；整集批量跳过已采用组，返回阻断原因。

连续视频记录每镜的实际区间。合成把相邻同一 Take 的区间合为一次输入；单镜替换保留其他镜头区间。缺少可靠切点的历史整片不能伪造切点。首个视频只在所覆盖范围均未采用时自动采用，后续结果为候选。

声音默认保留原声，可直接跳过。采用其他视频后，相关补配需要重新对齐。合成只消费采用关系和声音；新导出成功前历史成片始终可查看。

## 持久化与兼容

继续使用现有 JSON 字段，不增加数据库表，不改 ComfyUI 节点 ID、部署方式或模型路径。

- `episode.beats`：唯一当前镜头结构；不写有效 H3 正文副本。
- `prompt_authoring.director_plan.schema_version = 7`：`revision`、`planning_revision`、来源指纹、工作流、画幅、目标、`groups`、`shot_prompts[beat_id]`、稿件历史与候选采用记录。
- `beat.h3_prompt`：读取时兼容投影；旧保存接口对 v7 委托唯一写入并要求版本号。
- `production.schema_version = 2`：当前采用关系统一投影到一个版本；旧 shot/director 容器仅保留历史，前端无模式选择。
- `parts/segments`：提交编译结果，只存在任务快照，不作为有效编辑对象。
- `workshop_history`：升级或重规划之前的镜头、原方案、剧本快照；`workshop_legacy_prompts` 保留每个相关 segment，绝不取第一个代替全部。

旧方案不会被 GET 自动升级。用户先预览并确认规划；能够验证的一对一视频映射才复用，歧义保留历史。新旧采用关系、音轨和导出均保留。内容库与工坊集数不一致时显示差异，多余集标记历史／未关联，不自动删除。

新 AI 整链创建接口返回 410。旧任务读取、恢复、快照结果保留；旧提示词预览和视频协议继续服务历史记录，v7 的写入不能降级成旧合同。

## API

前缀 `/api/projects/{project_id}/episodes/{episode_id}`。

| 方法／路径 | 输入／结果 |
| --- | --- |
| GET `/workshop` | 当前 v7、来源版本差异、历史稿与规划、任务检查点 |
| POST `/shot-plan` | `expected_revision`、`workflow_id`、`aspect_ratio`、`target_shot_count`（null 自动）、`target_duration_seconds`、`max_shots_per_group`、`reuse_existing`；返回 job_id |
| POST `/workshop/prompts` | `expected_revision`、可选 `beat_ids`；缺省本集，组范围传本组镜头 ID |
| PATCH `/workshop` | `expected_revision`；`groups` 或 `beat_id` 配 `h3_prompt`／`shot_updates`／`writing_reference_urls` |
| POST `/workshop/jobs/{job_id}/actions` | `action=cancel/retry/apply`；采用需 `expected_revision`，规划采用可传 `groups` 和按镜头 ID 索引的 `shot_updates` |

候选保存在 `ai_project_jobs`，类型 `workshop_planning`／`workshop_prompt`。任务重试保持原输入快照；正在执行的任务不能重复重试。新任务取消后晚到结果无法重新提交。重启将未完成任务标记为可从检查点恢复，不假报成功。
