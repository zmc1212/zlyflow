# 导演台设计图生图提示词（ChatGPT / gpt-image）

> **用法**：每张设计图 = 1 个「通用风格前缀」+ 1 个「分镜提示词」，在 ChatGPT（GPT-4o / gpt-image）中发送，并**同时附上对应参考截图**（`docs/design-ref-director/`，见 `docs/导演台流程与界面结构.md` 索引）。参考图用于锁定布局与信息密度，生成结果允许比现状更精致，但功能区块必须一一对应。
> **基线**：2026-09-12，与 `docs/导演台流程与界面结构.md` 同步。
> **暗色变体**：在提示词末尾追加一行：「改为暗色主题：画布 #0f1115、表面 #171a20、抬升表面 #1e2229、文本 #f3f5f7、次级文本 #9ba5b1、边框 rgba(255,255,255,.10)、主色 #435ce8；对话创作室页面底 #17181a、画布 #1c1d1f、卡片 #232427、强调色 #3d9aff。」

## 通用风格前缀（每条提示词都以它开头）

```text
你是一名资深 UI 设计师，为「ZLY AI 视频工作室」的导演台绘制高保真桌面端 UI 设计图。硬性要求：
- 16:9 横版完整界面设计图（不是插画、不是海报、不要浏览器窗口边框、不要手机壳样机）。
- 扁平现代风格，视觉品质对标 Linear / Vercel 官网级别：克制的色彩、清晰的层级、大量的留白与细边框。
- 浅色主题：画布 #f8f9fa，卡片表面 #ffffff，边框 rgba(15,23,42,.08)，主文本 #171a1f，次要文本 #65707c，品牌主色 #4d6bfe，主色柔光底 #eef1ff。媒体预览区允许近黑色。
- 对话创作室区域使用：页面底 #fafafb、内容画布 #f1f2f3、卡片 #ffffff、正文 #1f2124、次级 #62656b、弱化 #9a9da3、分隔线 #ecedef、强调色 #0285ff。
- 圆角体系：内容卡片 12–14px，对话输入条与任务行胶囊 22px，按钮/小控件 6–8px；卡片带很轻的投影。
- 界面文字全部为简体中文且清晰锐利，只使用我在提示词里给出的文案，不要发明大段新文字；图标为细线风格；字体为现代无衬线中文黑体。
- 信息密度与参考截图保持一致：区块位置、数量、比例必须对应，可以优化间距与细节质感。
```
