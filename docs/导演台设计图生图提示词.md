# 导演台设计图生图提示词 v2（电影感暗色 + 浅色对应版 · Agent 剧本创作模式）

> **双版本**：同一套功能区块与布局，两套设计语言——
> - **暗色版（本文件主体）**：Runway 式电影感暗色（画布 #0b0d12、蓝紫辉光渐变、玻璃拟态）。产物在 `docs/导演台设计图/`。
> - **浅色版**：同布局的白卡浅色语言（画布 #f8f9fa、白卡轻投影、品牌渐变 #4d6bfe→#7b5bff）。生成时在每条提示词前加「浅色设计语言替换段」（见 `dev-log/codex-prompts/light/`，已内置）。产物在 `docs/导演台设计图/浅色/`。
> **主题映射**：工作台暗色主题 → 暗色版设计；浅色主题 → 浅色版设计。代码实现对应 `guided-flow.css` 的 cinema 层（暗色作用域）与浅色增强层。
> **基线与增强原则（两版通用）**：参考截图只是「现状基线」，不是最终稿——设计稿 = 在现有代码的信息架构上做合理演进：除还原截图功能外，可实施标注**【增强】**的设计点（每一项都已核对代码数据模型字段，架构可支撑）；未标注处保持截图现状，禁止无数据支撑的发明。
> **用法**：每张图 = 1 个「通用风格前缀」+ 1 个「分镜提示词」，附上对应参考截图（`docs/design-ref-director/`，截图仅用于锁定功能区块与文案，不锁定视觉风格）。
> **编号规则**：提示词编号 = 参考截图编号（17–25 = agent 剧本创作模式全状态；01–11 其他页面暂缓，需要时按同样模板补写）。
> **版本**：v1 浅色基准稿已归档至 `docs/导演台设计图/v1-浅色基准/`。
> **暗色变体**：v2 本身即暗色；如需浅色概念稿，把前缀中的画布/表面/文本替换为浅色 token（画布 #f8f9fa、表面 #ffffff、文本 #171a1f、主色 #435ce8）。

## 通用风格前缀 v2（每条提示词都以它开头）

```text
你是一名顶级产品设计师，为「ZLY AI 视频工作室」的导演台重新设计高保真桌面端 UI 概念稿。设计语言参考 Runway 的电影感暗色编辑部风格（媒体优先、极简界面、戏剧性排版）与即梦工作台的媒体卡片式布局。硬性要求：
- 16:9 横版完整界面设计图；不是插画、不是海报、不要浏览器窗口边框。
- 电影感暗色主题：整体画布 #0b0d12（近黑深炭色），卡片表面两级 #12151c 与 #171b24，边框 1px rgba(255,255,255,.07)；主文本 #f2f4f8，次级文本 #a8b0bd，弱化文本 #6b7280。
- 品牌强调色是「蓝色辉光」：主按钮、进度条、选中描边和关键数字使用 #5b7cff → #8b6aff 的渐变；被强调的元素带柔和外发光（0 0 24px 同色低透明辉光），整张图禁止使用传统灰色重投影，层级靠表面明暗、1px 亮边和辉光表达。
- 媒体优先：视频画面/缩略图区块大而醒目（16:9、圆角 12px、带 1px 亮边），空态与占位用深蓝紫渐变底 + 细线图标；时间码、时长、字数等数字一律等宽字体。
- 排版有戏剧性：区块主标题 20–26px 加粗、字距略收紧；正文 13px；微标签 11px 加宽字距（中英配对，如「生成任务 TASKS」）；每张图有一个明确的视觉主角（大预览、大进度数字或大标题），其余元素为配角。
- 圆角体系：卡片 16px、输入条与任务行胶囊 24px、小按钮 10px；底部浮动输入条用玻璃拟态（半透明 #12151c、backdrop blur、1px 亮边）。
- 功能区块必须与下面列出的完全一致，不可增删；中文文案只使用我给出的原文，清晰锐利无乱码。
- **基线与增强规则**：参考截图是「现状基线」，本设计稿要在同一信息架构上做更合理的设计演进。凡标注**【增强】**的区块是本轮设计的加分项，必须呈现——它们都已获产品数据模型字段支撑（镜头视频/首帧 URL、画风封面图、角色/场景图片、镜头时长等），不是凭空编造；未标注的区块以参考截图的状态为准。除【增强】外不得发明界面上不存在的功能。
- **功能与状态逻辑以参考截图为准**：截图记录的是真实运行状态（任务行数量、按钮可用态、标签文字等），若本文字描述与截图冲突，以截图为准；只允许重新演绎视觉风格与实施【增强】，不允许改动信息架构与交互逻辑。
- 克制：渐变与辉光只用在关键处；留白要大方；不要密密麻麻的灰色表单框、不要浅色背景、不要默认组件库风格。
```
