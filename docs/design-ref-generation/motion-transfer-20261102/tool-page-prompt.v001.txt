桌面端 1536×864 深色 UI 设计稿：AI 视频创作工作台的「动作迁移」专属工具页。

整体风格：与即梦式创作工作台一致的现代深色界面。页面背景 #0f1115，卡片表面 #171a20，抬升面板 #1e2229，主色紫罗兰 #7c5cff，辅助青绿高光，文字近白 #f3f5f7，次要文字 #9ba5b1。圆角 16-20px，细腻 1px 描边 rgba(255,255,255,.10)，柔和投影。全部为简体中文界面，字体清晰现代。

页面结构（自上而下）：
1. 顶部居中大标题区：左侧细线渐变装饰，主标题「动作迁移」28px 半粗，下方一行浅灰说明文字「上传角色形象图与动作参考视频，把参考动作迁移到角色身上」；标题区背景有微妙的紫青双色柔光渐变横幅，右侧点缀一个发光的舞动火柴人骨架线框图形（SDPose 姿态骨架意象，紫色发光线条）。
2. 主创作卡片（占页面主体，宽度约 1200px 居中，表面 #171a20，圆角 20px）：
   - 左列（约 40%）双素材上传区，上下两个槽位卡：
     · 上槽「角色形象图」：虚线框内一张人物半身插画缩略图占位，右下角小字「全身清晰 · 点击上传」；
     · 下槽「动作参考视频」：虚线框内一段舞蹈视频画面缩略图占位，带播放按钮图形与时长角标「5.2 秒」，右下角小字「MP4 / MOV · ≤50 MB」；
     · 槽位下方一排三个浅色描边小按钮：「上传形象图」「从资产选取」「上传动作视频」。
   - 右列（约 60%）参数区，2×2 网格排布四个控件，每个控件上方 11px 浅灰标签：
     · 「动作跟随强度」滑杆，值为 1.00，紫色滑轨；
     · 「画面比例」下拉框，值 16:9；
     · 「生成时长」下拉框，值 5s；
     · 「生成质量」下拉框，值 标准成片。
     下方一行「随机种子」数字输入框，占位 20261102。
3. 参数区下方通栏「提示词（可选）」多行输入框，占位文字「描述角色、场景和氛围；留空将按内置提示词迁移动作」，输入框内已有一行浅色示例文字。
4. 卡片底部右侧主操作按钮「开始生成」，紫罗兰渐变大按钮带星火图标，左侧灰字小注「素材各不超过 50 MB；平台只截取开头片段并对齐到 24fps」。

画面右下角可加一个非常淡的骨架舞者水印发光图形呼应主题。整体布局疏朗、层级清晰、留白充分，是专业级 SaaS 创作工具的质感，不要手机端布局，不要多页面拼贴，只画这一个页面。
