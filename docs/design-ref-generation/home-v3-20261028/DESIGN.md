## 设计决定

1. 创作先行：一行小标题下直接出现统一创建面板，上传、提示词和参数处在同一工具中；不再把主要操作排在作品网格之后。
2. 场景入口有主次：较宽的「导演台」画面入口与右侧两个较轻的「图片生成」「无限画布」入口配对。它们分别连接既有导演台、图片媒介和画布，不承诺新能力。
3. 作品保留比例：横幅、竖幅和上下叠放的小图组成最近创作区，通过不同画面及比例制造节奏。字幕、标题与时间仍有稳定对齐，避免用无序错位牺牲可读性。
4. 控件继续紧凑：首尾帧槽、开关、选择器与生成按钮收紧；文案、主参数及模型名保持完整可读。图中尺寸属于栅格提案，若批准实现再按最终原图测量。
5. 内容与能力核对：最终稿将上传提示修正为「支持粘贴图片，或拖入参考图」，选中的首尾帧工作流不声明视频上传能力；任务状态用图标与颜色共同表达。
