# 生成首页 V3 实现与验收

日期：2026-10-28。依据用户「按设计稿开发」的确认实现，基线为同目录 generation-home-v3-light.png。

## 已实现

- 保留既有悬浮页头、全局导航和任务栏。首页直接展示问候与紧凑输入面板，下方为导演台、图片生成、无限画布入口和最近创作。
- 最近创作复用现有 jobsQuery：按可见任务选取最近有可用产物的轮次，每任务一份代表作品；跳过过期或无产物任务。全部 / 视频 / 图片仅在内存筛选，最多展示 12 项，不追加后台请求。
- 作品标题、时间、媒体类型和时长来自真实数据；无时长时不伪造默认秒数。云端截图失败时回退原始媒体，最终失败显示「预览暂不可用 / 打开任务查看」；媒体 URL 更新时重置失效状态并恢复预览，已额外模拟验证。点击使用原有跨媒介任务路由。
- 图片生成入口保留既有分媒介草稿；导演台与画布链接既有路由。「查看全部」进入资产。灵感建议由原来的独立芯片移入输入区的 Ant Design 菜单。
- 提示词改用 Ant Design Input.TextArea，生成与更多设置使用 Button；工作流、参数层级、默认值与校验继续来自注册表。首尾帧、R2V 标签、提示词优化及原提交流程不变。
- 打开具体任务后不显示首页入口与作品区，仍采用原有轮次结果、底部输入框和收起行为。新增样式限定在 studio-generation-home，不影响其他工作区的布局。
- 浅暗主题沿用根 Provider、Ant Design token 与 --studio-*；暗色下选择器不出现重复边框，传送弹层保持当前主题，任务状态同时显示图标。

- 27 项浏览器检查覆盖作品筛选、图片入口、草稿保留、新对话清空、灵感菜单、注册表工作流切换、首尾帧、带参考图提交与 CSRF、任务详情吸底、跨媒介路由、三个桌面视口溢出、主题刷新记忆、暗色弹层、空列表、请求错误、重试、预览失败与侧栏收展。无未捕获页面异常。完整结果见 [checks.json](implementation/checks.json)。

- 设计图测量与 DOM 采集工具校验了实际 URL、标题、视口、DPR 1、字体和图片加载、横向溢出及入口图片路径 / 原始尺寸。真实元数据见 [capture.json](implementation/capture.json)。该校验不表示像素相同，视觉已通过本次截图复核。

## 与效果图的有意差异

- 真实工作流的主选项多于效果图示意：为保持注册表为唯一来源，默认 H3 的工具行自然分成两行。1586 桌面输入框实际为 x=348、y=142、1206×238；较设计图高约 35px，其下入口和最近创作顺延，未隐藏任何原有选项。
- 入口摄影按批准稿重新生成独立素材；画布入口复用真实界面截图；标题与图标均为可操作代码。素材记录与提示词见 [ASSETS.md](ASSETS.md)。
- 最近创作内容取决于实际任务，媒体比例据参数及元数据确定，与效果图中的示意人物、时间和作品不强行一致。
