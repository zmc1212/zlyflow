## 2026-10-27：小圆点按点击显示，移出视频自动暂停

用户补充即梦交互后，将 Slider 的 `handleSize` 与 `handleSizeHover` 通过局部 Ant Design token 同时设为 6px，去除外扩阴影及色环，仍由组件计算定位。普通悬浮视频或进度条时不显示圆点；鼠标点击/拖动时显示，离开进度条后隐藏。键盘焦点提供同等反馈。

视频容器的原生 `mouseleave` 立即暂停当前媒体，移回后不自动续播。在容器内不同控件间移动不暂停；进入实际位于视频边界外的更多菜单会暂停，但菜单保持可用。原生事件用于准确处理 React portal 边界，正常暂停中止待完成的 `play()` 时不会弹出 `AbortError` 失败信息。

真实 5173 使用受控任务和已有视频，浅暗主题各 6 组、共 12 组检查通过：默认/悬浮隐藏，点击后 6px 圆点及开头/中间/结尾对齐，拖动及移开隐藏，播放中控件内移动/移出暂停/进度停止/移回不续播，边界外菜单仍可使用，以及键盘进度操作。无页面运行时错误、无真实写入。结果见 [交互检查](seek-interaction-checks.json)，截图见[浅色点击](seek-small-click-light.png)、[浅色默认](seek-hidden-light.png)、[暗色点击](seek-small-click-dark.png)和[暗色默认](seek-hidden-dark.png)。
