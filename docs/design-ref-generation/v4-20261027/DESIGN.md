# 生成页 V4 实现基线 · 2026-10-27

依据：用户在「参考即梦设计生成页稿」对话中确认的 `generation-page-v4-compact-hover.png`，并明确保留现有大布局。本目录的 `reference-v4.png` 是该原稿的原样归档，1584×993；它由生图产生，不把其中的近似字体、文字或媒体畸变当作 CSS 几何事实。

实现只调整视频轮次：摘要和有序参考图、参数弹层、中性版本下拉、最多 480px 的视频，以及随悬浮/焦点出现的工具。全局导航、任务栏和输入框继续使用现有布局。真实视频用元数据校正比例，不能为了吻合稿件的近似尺寸拉伸画面；短桌面窗口与竖屏媒体按可用高度收小。

校准取舍：原稿的媒体锚点约为 x380、宽 502px，实际保留既有结果列后为 x410、宽 480px；高度则按真实 1376×768 视频计算为约 267.91px。默认字号与按钮高度沿用工作台，不对全局做图片比例缩放。浅暗结果列使用相同宽度基线。菜单与版本入口的键盘聚焦使用 `preventScroll`，避免门户定位前把生成历史滚走。

用户后续明确的播放细节（2026-10-28 更新）：鼠标移入视频自动播放并显示进度条，普通悬浮于视频或进度条均不显示圆形滑块。点击/拖动进度条后显示 6px 圆点，离开该交互区域后隐藏；键盘焦点提供同等操作反馈。鼠标离开整个视频容器时立即暂停，重新进入时从原位置继续播放，容器内控件之间移动则保持播放；手动暂停后，在当前停留内保持暂停。进入边界外的更多菜单同样暂停，但菜单本身仍可使用。

业务边界：下载、画布、剪映使用所选输出。超分沿用任务级 API，并仅在其真实来源版本上允许提交。删除入口明确写「删除任务」且继续确认，不能把单个版本删除误接成整个任务删除。所有菜单与表单交互直接使用已有 Ant Design。

参数默认只展开创作信息，内部参数在折叠的「运行参数」中保留，更多菜单可以直接展开。生成中的阶段与停止、失败原因和二采确认属于重要状态，不收进悬浮层。

截图和交互验收记录见 [ACCEPTANCE.md](ACCEPTANCE.md)。浏览器截图来自实际 5173 代码，登录和任务使用受控 API，视频使用仓库已有本地文件；图片内容、账号名与任务量属于验收数据，不是用户生产库快照。
