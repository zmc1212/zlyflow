# 生成首页设计提案：电影创作桌面

日期：2026-10-28。状态：供用户评审的设计效果图，尚未实现，也未作为已批准的界面基线。

## 范围与依据

- 目标：改善生成首页过于朴素、问候语与输入面板距离过大、缺少视频创作视觉焦点的问题。
- 交付：一张浅色桌面单屏设计稿 `generation-home-light.png`；采用约 1600×1000 的逻辑视口构图。
- 参考：现有 `frontend/src/App.tsx` 的生成空状态、创建栏与任务栏，以及 `../header-floating-20261028/design-light.png` 和 `before-light.png`。
- 不涉及代码、接口、路由、数据库、生成工作流或实际任务修改；未触发图片或视频生成业务接口。

## 视觉构思

第一眼由左侧两行大标题「让想法，成为画面。」与右侧电影画面组成的横向接触印样建立辨识度。紧随其后的创建面板提供明确操作入口，下方最近创作让作品内容进入首页。保留已有的悬浮 Header、76px 全局导航轨和约 240px 任务栏。

1. 主视觉：大幅山湖画面搭配窄幅建筑与雨夜画面；摄影内容与正文、控件分开容纳，不烘焙成页面背景。
2. 创建面板：从底部上移至主视觉正下方；首帧、可选尾帧、提示词、优化开关与生成按钮形成清晰阅读顺序。
3. 参数：显示生成类型、注册表模型名称、画面比例、时长与更多设置；不显示显存、采样步数和权重等内部参数。
4. 最近创作：三个真实任务入口的视觉提案，后续实现可使用已有任务列表；无任务时省略该区，不能编造用户作品。

## 实现边界

- 图中所有摄影、任务标题、时间及状态均为生成的示意内容，不代表用户现有作品或真实运行状态。
- 文字、图标、表单、菜单和状态必须由代码与真实数据实现；业务控件继续直接使用 Ant Design，画面单独作为媒体资源。
- 大画面若连接作品预览，只能播放其真实来源；使用固定示例时明确标注「示例」。
- 任务标题单行截断，完整内容由 Tooltip 提供；模型名称保持完整可读。较窄桌面可让参数工具行自然换行，但保持生成按钮可达。本提案未设计或验证移动端。
- 打开具体任务后继续沿用现有轮次结果与底部创建栏；本提案仅覆盖未选择任务的首页状态。
- 双主题沿用根级 Provider、Ant Design token 和 `--studio-*`，不建立页面独立主题。浅色画布 `#f8f9fa`、表面 `#ffffff`、主文 `#171a1f`；暗色画布 `#0f1115`、表面 `#171a20`、抬升表面 `#1e2229`、主文 `#f3f5f7`。本次仅生成浅色效果图，未交付暗色视觉验收。
