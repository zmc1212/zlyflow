为 ZLY AI Studio 重新设计一张主导航与品牌图标审批稿，1536×1024。用户明确认为上一次的3D玻璃小物件偏插画、与工作台不搭，希望参考即梦这类成熟AI创作平台，得到有设计感的功能图标。

实际传入两张参考：第一张是即梦的公共导航截图，参考它的20px图形密度、线与面的关系、正负形、克制的选中背景以及图标与文字的比例；不复制即梦品牌、图标路径或产品名称。第二张是ZLY现有工作台的布局参考，保留真实功能、文字、媒体区和深色主题。之前的3D插画方案不是本轮参考，请完全用定制二维矢量图形语言重新设计。

输出是一张正视、清晰的产品UI审批图。左侧约1040px展示改版后的真实暗色工作台情境，右侧约420px展示放大后的原创图标和两个Z品牌候选；底部右侧用窄条展示浅色对应状态。画板以中性石墨色为底，标题小而精致“导航与品牌 · 图形方案”，副题“ZLY AI Studio / 01”。不要做海报式巨型标题、科技仪表盘或外部设备模型。

设计主线：轮廓有章法、线面有变化、图形有独特性。细节放在几何构造、斜切口、错位边缘、连接关系和负空间。主图标在24px时漂亮清楚，放大后能看出定制细节。统一24px网格、1.7—1.9px等效线重、小圆角与45度切角。所有图标都是纯平面、精确的黑白/银灰图形，局部一片淡紫几何面；没有3D厚度、镜面反光、玻璃、金属、铆钉、雕刻、写实纹理、柔光、辉光、透视物件、摄影缩略图或微缩场景。也不要用一个普通字母和一个独立∞符号敷衍。

四个主菜单保持“生成 / 导演台 / 画布 / 资产”，纵向排列。轨道仍宽76px，菜单项约56×62px，图标24px，标签12px，图标与标签间6px。比上一版44px插画图标明显更适合工作台界面。
默认图标用有对比度的#adb5c2，选中的“生成”用#f4f5f7实心/线面混合版本，背景为#242830的柔和圆角面；只有极小的紫色切面或短指示线点出品牌。选中态克制、精确，不要大块紫色发光按钮。深色画布#0f1115、面板#171a20，与现有工作台统一；浅色部分对应白底、深墨图标、轻灰选中背景。

原创图标的形状：
1. 生成：一个带不对称斜切角的开放影格，右上角从影格轮廓中自然延展出一枚小型四角成像光芒。图标主体有一片有节制的实心面，光芒与轮廓间留白讲究，不能是普通山峰图片框加外贴大星星。
2. 导演台：场记板的上盖有三条精确的斜切节奏，前板通过一条短的内部负空间与两个比例不同的区块表达镜头序列。轮廓简洁，但构造和光学比例是定制的，不是默认线库照搬。
3. 无限画布：两块错位的开放画板，前板的右上角与后板的左下角形成一处优雅的交错；用一条短的折弯连线及两个小端口把前后画板连接起来。用清晰的负空间表达可拓展的工作区，最多3个构成层级，既比空方框有设计也保持24px可读。不用∞、不画网格、图片卡片、节点电路或立体托盘。
4. 资产：一个带双页签的收藏夹轮廓，内部的一片错位实心卡与外轮廓形成窄负形；一处斜切开口与“生成”的斜切角呼应。不要普通空文件夹，也不要一摞写实素材。

Z品牌图标给两个原创候选，平面几何而不是字体：
A“叠帧 Z”：由两条错位、互相咬合的折片构成Z骨架，两片共享45度切面但外端有不同长度；中央有一条刻意设计的贯穿负空间，右上与左下各有一小段分离的取景角，整体像影格与Z的融合。使用浅紫与偏蓝紫两个清晰的平面，色差只表达构造，不产生立体深度。紧凑平衡，离开文字也有品牌识别，不是普通无衬线字体Z。
B“流线 Z”：由上下两段具有相反切口的连续带形组成，中央两次转折形成一条独特负形通道，结合一组极短的影像帧刻线。仍是明确Z，圆角曲率和短切口自洽，使用银白+一小片紫色。
两个候选均无外套App图标方底，无胶片孔、播放按钮叠加或光阑。右侧各放大到72px，并标“A 叠帧 Z”“B 流线 Z”；主界面顶栏先采用A，图标28—30px，字标仍为“ZLY AI Studio”，旁边保留“创作工作台”。
