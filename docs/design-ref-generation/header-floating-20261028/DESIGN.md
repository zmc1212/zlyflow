本轮调整工作台 Header。左侧保留品牌及「创作工作台」，右侧保留当前媒介的服务状态、根级主题切换和账号菜单。2026-10-28 补充：导演台（首页 / 项目壳 / 批量 / 复刻 / 剧本诊断）与画布（首页 / 编辑）也改为共用这一 Header，删除各自 64 / 60px 通栏顶栏、画布私有 Header 覆盖以及页面内重复的主题切换；这些工作区的页头高度、悬浮块尺寸和 76px 起始线与本文件一致。

## 冻结尺寸与实现边界

- 桌面基线：1584×993，另验证 1440×900 与 1920×1080。页面画布沿用 `--studio-canvas`。
- Header：距顶 12px、两侧 16px、48px 高。中间透明，不绘制横贯页面的底色和分隔线。
- 左悬浮块：最小宽 312px、圆角 16px；标志 28px；品牌 18px / 600；标题 14px；内边距 16px、间距 12px。保留现有 Sparkles 标志。
- 右悬浮块：最小宽 364px、圆角 16px；服务文字 12px；主题按钮 32px；账号头像 28px、名称 13px，较长名称省略并可在菜单查看全文。
- 浅色表面 `#ffffff`，阴影 `0 4px 20px rgba(22,31,44,.07)`；暗色表面 `#171a20`，阴影 `0 4px 24px rgba(0,0,0,.24)`。文字、分隔、状态与头像沿用成对 `--studio-*` token。
- 桌面工作区及两条左栏从 y=76 起始；底部输入框位置与列宽不变。滚动页面时悬浮块固定，中央空白区域不拦截指针。
- 状态包含「连接中 / 已连接 / 未连接」，同时显示文字与圆点，不能只以颜色表达。账号菜单直接使用 Ant Design Dropdown，保留主题、MCP、管理设置（按权限）与退出登录。

生图中的文字及阴影属于近似栅格表现；字体使用现有应用字体，真实名称与服务状态来自既有登录、健康检查和主题 Provider，不烘焙图片作为页面。
