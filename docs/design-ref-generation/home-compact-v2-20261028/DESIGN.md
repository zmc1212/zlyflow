# 生成首页 V2：紧凑创作工作台

日期：2026-10-28。状态：待用户评审的浅色桌面设计稿，未实现。

## 用户反馈与方向

用户反馈上一版「元素大了一点，设计紧凑点类似即梦」。本轮取消大幅宣传主视觉，采用小标题、四列作品预览和底部悬浮输入栏，让首屏更接近日常生成工具的使用密度。

沿用 draw-ui 与 ImageGen 工作流，实际传入上一版设计稿作为产品结构与品牌参考。即梦官网本轮抓取超时，未取得新的官方界面截图，因此仅借鉴用户指定的紧凑布局方向，不声称逐像素复刻即梦。

## 与 V1 的主要变化

- 删除两行大标题及三张巨幅主视觉；改为单行「今天想创作什么？」与简短说明。
- 最近创作改为四列、两行，共八个较小预览，直接展示作品。
- 创建栏移到页面底部，缩小上传槽、表单与按钮，并集中生成参数。
- 左侧历史任务缩小缩略图与行间距，同屏展示更多记录。
- 保留 ZLY 品牌、生成 / 导演台 / 画布 / 资产导航、悬浮顶栏、账号及服务状态。
- 保留首帧、可选尾帧、提示词优化、模型、比例、时长、更多设置与开始生成。

## 使用边界

设计稿为栅格图片，尺寸比例为视觉提案，具体字号和控件高度需在后续实现时量化校准。生成结果的输入面板仍比提示词中的约 200px 目标略高；本轮优先交付整体密度与四列作品布局供评审，不将提示词中的意图写作实际测量值。

所有摄影、任务、时间与状态均为生成示意。实现时采用真实任务数据；最近创作筛选与任务入口需连接既有数据，不能以静态示例代替真实历史。业务控件继续直接使用 Ant Design；主题由根 Provider 及 --studio-* 驱动，暗色继续沿用项目成对 token。本轮仅交付浅色桌面效果图，未实现交互、未验证暗色或移动端。
