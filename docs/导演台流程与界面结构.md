## 1. 路由与页面地图

| 路由 | 组件 | 说明 |
| --- | --- | --- |
| `/director` | `DirectorHome` | 导演台首页：创作入口 + 最近工程 |
| `/director/:projectId` | `DirectorRecipeStudio` | **导演创作**（Recipe）：九阶段流程 + 剪辑 |
| `/director/batch/:projectId` | `DirectorBatchStudio` | **短视频批量**：主题裂变多条短视频 |
| `/director/replication/:projectId` | `DirectorReplicationStudio` | **参考片复刻**：拉片 + VACE 批量转绘 |
| `/director?design=1` | `DirectorDesignMockup` | 内置设计稿样例页（静态 mockup） |

工程按 `owner_user_id` 隔离，账号只见自己的工程。全局左侧图标导航（工作台框架）：生成 / 导演台 / 导台2 / 资产。

主模块装配：`frontend/src/director/DirectorStudioModule.tsx`；路由与路径常量：`frontend/src/paths.ts`。

## 2. 导演台首页（DirectorHome）

- **顶栏**：左「导演台」，右主题切换（ThemeToggle）；移动端另有返回创作工作台、新建按钮。
- **Hero 区**：大标题「今天，想拍点什么？」，副题「用 AI 将你的创意变成精彩的影视作品。」
- **三个创作入口**（横向卡片）：
  1. **导演创作**（主卡，浅蓝渐变，右侧拍立得装饰插画）：「一句话开始，完成剧本与分镜」；步骤指示 `1 故事 → 2 角色 → 3 分镜`；CTA「+ 新建导演工程」。
  2. **短视频批量**：「一个主题，生成多条短视频」，右箭头。
  3. **参考片复刻**：「分析参考片，批量转绘」，右箭头。
- **最近工程**：卡片网格（默认显示 6 个，超出出现「查看全部/收起」）。每卡：类型图标封面（导演创作=蓝/批量=紫/复刻=绿）、标题、梗概（无则「暂无梗概」）、类型 chip（导演创作/短视频批量/参考片复刻）+ 状态 chip（待生成/部分完成/已完成）、元信息（`N 个镜头`、更新时间），操作「打开 / 复制 / 删除（Popconfirm：工程文档会从服务器移除，已生成的视频任务仍保留在任务列表）」。
- 空态：「还没有导演工程」+「从上方选择一种创作方式，开始你的第一部片。」+ CTA「新建导演工程」。

## 3. 导演创作（Recipe）：九阶段流程

核心页面 `DirectorRecipeStudio.tsx`。左侧阶段导航（`DirectorStageNav`）分 5 组 9 阶段，每阶段带就绪标签：

| 分组 | 阶段（id） | 就绪标签 |
| --- | --- | --- |
| 故事与风格 | 剧本 `script`、画风 `art_style` | 未开始 / 草稿 / 部分完成 / 已就绪 |
| 分镜设计 | 分镜设计 `storyboard` | 同上 |
| 视觉素材 | 角色定妆 `characters`、场景定妆 `locations` | 同上 |
| 镜头制作 | 镜头制作 `shots` | 同上 |
| 声音与交付 | 配音 `voice`、配乐 `music`、成片 `export` | 同上 |

组标题右侧显示 `已准备/总数` 计数；阶段名左侧圆点表示就绪级别，右侧 Tag 显示标签文字。URL 参数 `?stage=<id>` 直达阶段，`?view=timeline` 进入剪辑视图。

### 3.1 剧本阶段 —— 对话创作室（chat room）

布局：`director-script-room`，无阶段导航（全宽对话式），底部停靠 Prompt Bar。

- **空态 hero**：魔杖图标 +「从一句创意开始」+ 说明「在下方输入你的故事创意，点击发送，AI 导演会先和你确认创作方向，再逐步写出片名、梗概和完整故事。」+ 3 个可点击示例创意 chip（程序猿与 AI 编程 / 镖师忠义与爱情 / 外卖骑手暴雨夜订单）。
- **Prompt Bar**（`DirectorPromptBar`，复刻 beautifului Prompt Bar 模式）：圆角 22px 白色胶囊输入条，placeholder「例如：雨夜里侦探穿过霓虹暗巷，追上一个撑红伞的女人。」，右上圆形发送按钮（↑，armed 时主色）；hint「Enter 发送，Shift+Enter 换行；生成方案只整理创意，不会自动消耗定妆、视频或配音额度。」
- **澄清问题卡**（`DirectorScriptStreamPanel`）：标题「AI 导演正在规划你的创意」，hint「回答或跳过下面的问题，剧本会按你选择的方向写。」，进度「创作方向 N/M」；每题选项卡片（可标「推荐」），支持「自己写…」自定义输入；操作「跳过这题 / 跳过全部，直接生成 / 按这个方向开拍」。逐环节确认（画风/角色/场景/分镜/配音/配乐）各有对应标题与 hint（`STAGE_CLARIFY_TITLES/HINTS`），回答后按环节定向注入。
- **流式写作**：状态头「AI 导演正在创作」+ 脉冲圆点动画（`director-stream-pulse-ring`）；分段标签「正在写：片名 / 一句话梗概 / 完整故事」；用户创意以「你的创意」气泡置顶；「回到底部」悬浮；生成任务行（`生成任务`，胶囊行 + 环形进度 + 成功/失败徽标 + 重试）。
- **完成态**：完成卡「创作方案已完成」（部分失败列出「部分步骤未完成：…」）；下方接「剧本成稿文档」（`DirectorScriptDocument`：片名/梗概/完整故事，按钮「编辑剧本 ↔ 完成编辑」「进入分镜设计」，hint「分镜将严格按「完整故事」拆解，改完记得继续。」）；再接「继续生成：<环节>」引导按钮（guided chain 断点续跑）。
- 运行中 Prompt Bar 切换为状态条：「AI 导演正在创作…」+「取消生成」按钮；提示词发送按钮变「生成创作方案」。

### 3.2 画风阶段

- 顶部 Tab：剧本 / 画风。
- 主按钮「生成创作方案」、次按钮「继续：分镜设计」。
- 画风目录（`ArtStyleCatalogPicker`）：「推荐 6 种常用画风。其余可按分类搜索，或浏览全部 34 款。」+「浏览全部」；卡片=缩略图 + 中文名 + 英文标签（如 Epic Narrative Cinema / Hyperreal Manga Fusion）+ 一句描述；点击即选中（弹窗「选择美术风格」为更换入口，提示「画风已更新，后续生成会按新画风进行。」）。

### 3.3 分镜设计阶段

- 任务头：「分镜设计 / 生成或导入分镜，即可开始制作」；空态两 CTA：「根据剧本生成全部分镜」（主）+「导入手动分镜（粘贴 Markdown）」。
- **镜头 bin**（左列表）：复选框 + `#序号` + 时长（`6s`）+ 16:9 缩略图（视频/静帧/占位图标）+ 镜头标题 + 状态标签（如「视频待生成 · 未采用版本」「有可用版本」「已采用版本」，附加 Tag：静帧 / 预览档 / 终稿档 / 已批准）。顶部工具条：「重新导入分镜」+「全选（共 N 镜）/ 已选 N / M 镜」+「清空」。
- **生成中骨架屏**：`正在生成分镜` + 计时、Progress 条、说明「大模型正在流式写分镜，字数增加就说明没卡住……」。
- **镜头检查器**（`RecipeShotInspector`，design focus）：Tab「文案 / 镜头」；字段：标题（`镜头 1｜00:00–00:06`）、描述（中文卡片）、英文镜头正文（提示「MiniMax H3 官方要求英文镜头正文；中文只应出现在对白 `<d>` 里。」）、对白；底部「前往镜头制作」。
- 批量条：「导入分镜 / 重试失败镜头（N）/ 生成选中（N）/ 停止选中 / 清空选择 / 更多操作（按剧本重新生成分镜、重新生成全部镜头）」。
- 重操作走确认弹窗（`director-heavy-confirm`：标题 + 影响说明 + 预计消耗，如「预计消耗：N 个本机 MiniMax H3 任务（预览档）」）。

### 3.4 角色定妆 / 场景定妆（视觉素材）

- Tab：角色 / 场景 / 道具（道具 Tab 在角色定妆内）。
- 角色定妆：工具条「人物与道具 · N」+ 汇总（已定妆/待定妆计数）+ 主操作「全部定妆（N）/ 生成 N 个角色」+「批准全部定妆（N）」；更多菜单「从库插入 / 存入资产库」。
- 场景定妆：「场景清单 · N」+「全部场景（N）/ 批准全部场景（N）」；道具 Tab：「道具转面 · N」+「生成 N 件道具 / 重新生成道具 / 批准全部道具（N）」。
- 资产卡片网格（`CharacterAssetCard` / `SimpleRenditionAssetCard`）：图 + 名称 + 版本状态；操作：生成定妆/转面、批准这一版、存入资产库。空态：「生成创作方案或从资产库插入人物、道具」。
- 「从资产库插入」抽屉（`DirectorAssetLibrary` picker 模式）。

### 3.5 镜头制作阶段

- 顶部「生成设置 · 16:9 · 预览」折叠面板（`DirectorProductionSettings`）：画质/输出比例/时长、生成模式（静帧 / 预览 / 终稿 / 自定义）、润色提示词开关、工作流族选择。
- 三栏工作区（`12-shots-populated.png`）：镜头 bin｜预览台（16:9 深色预览框 + 状态行 + 主 CTA「生成这一镜」）｜检查器（Tab：文案 / 镜头 / 生成；底部操作「生成静帧 / 静帧设为首帧 / 截取尾帧 / 前往配音 / 生成这一镜」）。
- 高级能力：首尾相接**连贯生成**（提示「开始首尾相接连贯生成...」）、**衔接修复**（`第 N → M 镜`）、上传首/尾帧、停止选中、仅重试失败项。

### 3.6 配音 / 配乐 / 成片（声音与交付）

- 配音：Tab 配音/配乐/成片；「角色音色」卡 +「生成全部配音（N）」；说明「有对白的镜头 N 条，已生成配音 N 条。男声默认 Onyx，女声默认 Nova。」；TTS 未配置时警示条「语音合成尚未启用……管理设置 → LLM 配置独立 TTS」；角色行可试听/换声线。
- 配乐：上传 BGM（「配乐可选，可上传音频或直接进入成片」）。
- 成片：「工作台内成片」卡（右上状态「未导出」）：「可进入成片的镜头 N / M」；按钮排「导出成片 / 下载 MP4 / FCPXML / EDL / 串播 / 剪映草稿」；「字幕」卡（开关「叠加关」+「串播预览按此样式叠对白。勾选字幕后，成片 MP4 会把字幕写进画面。」）；「运行详情 · 导出服务可用」折叠条。

### 3.7 剪辑视图（timeline）

- 顶栏 Segmented「创作流程 / 剪辑」（shots/export 阶段也显示）。
- `DirectorTimelineView`（移植 OpenCut 交互）：左「定妆素材」栏（提示「点击中镜头后加入角色或场景，装帧仍走现有参考图规则」）、中央深色**镜头预览台**（安全框 + 时间码 `00:00:00:00` + 走带控制 ⏮ ◀ ▶ ▶| ⏭ + `SAFE` 角标）、右提示「选中一镜后编辑：提示词、首尾帧、Takes 和生成一镜都在这里」；下方镜头缩略条与时间轴面板（`TimelineRuler` / `TimelineTrackMain` / `TimelineTrackSubjects`、播放头、吸附 chip）。

### 3.8 顶栏与全局状态

- 左：「← 工程库」+ 可编辑标题（placeholder「未命名导演工程」）+ 副行 `N 镜 · 18 秒 · 16:9` + 保存状态 Tag（自动保存 / 保存中 / 已保存 / 保存失败，重试 / 存在冲突）。
- 右：「任务活动（· 进行中）」、主题切换、「串播」（无完成镜头时禁用）、「更多 ▾（返回创作工作台 / 查看成片与交付 / 剪映导出）」、「取消生成」（运行中）。
- 「任务活动」抽屉：「AI 运行详情 · <阶段>」+ 总进度条 + agent 列表（Tag 状态 + 生成/重跑按钮 + 阶段消息 + 错误卡）+「最近一次分镜：<消息>」。
- 冲突弹窗「检测到其他窗口的修改」：「加载云端版本 / 用本窗口内容覆盖云端」。
- 移动端：`DirectorMobileChrome` 顶部栏（返回/标题/菜单：任务活动、创作工作台、串播、查看成片与交付、剪映）+ 底部主操作条（随阶段变化的单个主按钮，如「生成待处理镜头（N）」「继续：配音」「无需配音，前往配乐」）。

## 4. 短视频批量（DirectorBatchStudio）

- 顶栏：「← 返回」+ 居中标题「短视频批量」+ 主题切换 +「创作工作台」。
- 左卡「生成参数」：条数（默认 3）、比例（9:16 竖屏）、时长（秒，默认 8）、工作流（官方 MiniMax…）、模型体积（完整 32 GB）、可选画风。
- 右卡说明：「在下方输入主题并发送，会按所选工作流并行裂变多条脚本并提交文生视频。」
- 底部 Prompt Bar：placeholder「输入短视频主题，例如：办公室久坐的人如何用 60 秒学会肩颈拉伸」，发送按钮「裂变并生成」。
- 结果区：逐条脚本任务行（「任务 <jobId> / 尚未入队」+ 视频/状态 + 重试）。

## 5. 参考片复刻（DirectorReplicationStudio）

- 顶栏：「← 返回」+「参考片复刻」+ 主题切换 +「创作工作台」。
- 左栏卡「参考片」：上传区「点击或拖入参考片，支持 mp4 / mov / webm，最大 2GB。仅用于分镜学习与参考复刻，发布合规责任由使用者承担。」
- 左栏卡「拉片设置」：模式 Segmented「智能分镜 / 固定分段」、切镜灵敏度滑杆（0.35）、「目标风格（可选）」输入（placeholder「例如：吉卜力动画 / 赛博朋克 / 水墨」）、深度控制强度（1.00）、采样步数（30）、「开始拉片 / 重新拉片」；底部说明「拉片会把参考片按镜头切分，逐镜反推英文提示词并提取深度视频；随后可用 Wan VACE 保留原片运镜与构图，重塑画面内容。」；无视觉模型时警示「未检测到视觉模型……提示词需要手动填写」。
- 右侧结果：「拉片完成后这里会展示逐镜结果」空态 →「N 镜 · M 镜可转绘」逐镜列表（缩略图 + 深度视频 + 英文提示词 textarea「镜头提示词（英文 H3 散文；拉片后可人工修改）」+ 重新提交转绘 Popconfirm）+ 顶部「批量转绘（N）」。
- 底部状态条：「本地 Wan2.1 VACE 1.3B 深度复刻 · 任务与创作台共用同一执行队列」。
