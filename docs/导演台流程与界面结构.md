## 1. 路由与页面地图

| 路由 | 组件 | 说明 |
| --- | --- | --- |
| `/director` | `Director2StudioHome` | 导演台首页：四个创作入口 + 最近工程 |
| `/director/projects/:projectId/{content\|assets\|workshop\|jobs}` | `Director2ProjectDetail` | **导演创作**：内容库 / 资产库 / 剧集工坊 / 全部任务。内容库可用 `?doc=` 选中文档、`?tab=episodes` 打开「分集与镜头」。工坊分集页 Tabs 为镜头 / 剧本 / 配音 / 合成。`?mode=manual\|agent` 切换创作模式。 |
| `/director/projects/:projectId/workshop/:episodeId` | 同上 | 剧集工坊某一集 |
| `/director/batch/:projectId` | `DirectorBatchStudio` | **短视频批量**：主题裂变多条短视频 |
| `/director/replication/:projectId` | `DirectorReplicationStudio` | **参考片复刻**：拉片 + VACE 批量转绘 |
| `/director/hypit/:projectId` | `DirectorHypitStudio` | **Hypit 复刻**：拆结构、WhisperX 拉片、本机编译 SVML |
| `/director2` 与 `/director2/*` | `Navigate` | 等价跳到 `/director` 对应路径（含 query / hash） |
| `/director/:旧recipeId` | `Navigate` | 第一段不是 `projects` / `batch` / `replication` / `hypit` 时回首页，不再打开九阶段 Recipe |

工程按 `owner_user_id` 隔离，账号只见自己的工程。全局左侧图标导航：生成 / 导演台 / 资产。侧栏不再出现「导演台2」。

主模块装配：导演创作项目壳 `frontend/src/director2/Director2App.tsx`；三项工作室 `frontend/src/director/DirectorStudioModule.tsx`；路由与路径常量 `frontend/src/paths.ts`、`frontend/src/director2/paths.ts`（`DIRECTOR2_PREFIX = "/director"`）。`/api/jobs` 轮询只在生成页和三条工作室开启，内容库 / 工坊页不轮询创作台任务列表。

## 2. 导演台首页（Director2StudioHome）

- **顶栏**：左「导演台」，右主题切换（ThemeToggle）；移动端另有返回创作工作台、新建按钮。
- **Hero 区**：大标题「今天，想拍点什么？」，副题「用 AI 将你的创意变成精彩的影视作品。」
- **四个创作入口**（横向卡片，主卡 `grid-row: 1 / 4` 对齐右侧三张小卡）：
  1. **导演创作**（主卡，浅蓝渐变，右侧拍立得装饰插画）：「一句话开始，完成剧本与分镜」；步骤指示 `1 故事 → 2 角色 → 3 分镜`；CTA「+ 新建导演工程」。先弹出 Ant Design Modal 从 `GET /api/skill-packs` 选制作配方：两列动态封面卡（半解说包热链 Hub 官方 mp4，未绑定用渐变占位；默认「半解说真人短剧」），再 `POST /api/projects` 写入 `extra.skill_pack_id`，进入 `/director/projects/:id/content`。内容库「骨架模板」不是这一项。
  2. **短视频批量**：「一个主题，生成多条短视频」，右箭头。创建后进入 `/director/batch/:id`。
  3. **参考片复刻**：「分析参考片，批量转绘」，右箭头。创建后进入 `/director/replication/:id`。
  4. **Hypit 复刻**：「拆结构、换内容、合字幕图形」，右箭头；不得写成锁运镜转绘。浅色卡底 `--dh-hypit-bg: #fff4e5`，暗色 `#2a2218`。创建后进入 `/director/hypit/:id`。
- **最近工程**：并行拉取 `/api/projects`（导演创作）与 `/api/director/projects`（只保留 `batch_run` / `shot_replication` / `hypit_replication`，**过滤 recipe / timeline**），按更新时间合并。标题行用 antd Segmented 筛选 **导演创作 / 短视频批量 / 参考片复刻 / Hypit 复刻 / 全部**，**默认「导演创作」**，不把复刻、批量与导演台项目混在同一网格。筛选后默认仍只显示 6 个，超出出现「查看全部/收起」；切换筛选项会收起。每卡：类型封面（导演创作=蓝/批量=紫/VACE 复刻=绿/Hypit 复刻=橙 `--dh-cover-d`）、标题、梗概（无则「暂无简介」）、类型 chip、元信息（更新时间），操作「打开 / 复制（仅三项工作室）/ 删除」。打开按 kind 走 `director2ProjectPath` 或 `directorBatchPath` / `directorReplicationPath` / `directorHypitPath`。
- 空态随筛选项变化：默认「还没有导演创作项目」+ CTA「新建导演工程」；其它类型对应「还没有…工程」与各自新建按钮。

## 3. 导演创作（项目壳）

核心页面 `Director2ProjectDetail.tsx`。顶栏：返回「全部项目」、项目名、「进行中」徽标、制作配方 Select（`GET /api/skill-packs`，写入 `extra.skill_pack_id`；空为未绑定）、`DirectorCreationModeSwitch`（AI 生成 / 手动编辑，URL `?mode=` + 项目级 localStorage）、项目 ID。左侧四菜单（手动模式可见，AI 生成模式隐藏侧栏）：

| 菜单 | 路由段 | 面板 |
| --- | --- | --- |
| 内容库 | `content` | `ContentLibraryPane`：导入/粘贴剧本、分集与镜头、同步工坊；`?doc=` / `?tab=episodes` |
| 资产库 | `assets` | `AssetsLibraryPane`：角色设定板 / 场景 / 道具 / 参考音 |
| 剧集工坊 | `workshop` | `EpisodeWorkshopPane`：分集列表或某一集（镜头 / 剧本 / 配音 / 合成） |
| 全部任务 | `jobs` | `JobsCenterPane`：按任务类型 Tabs（镜头规划、配音、视频生成等，无「全部」混排） |

`/api/jobs` 创作台轮询不在这些页开启。

### 3.0 创作模式（AI 生成 / 手动编辑）

顶栏右侧常驻 antd Segmented「创作模式」切换（`DirectorCreationModeSwitch`）。模式真源为 URL `?mode=manual|agent`，缺省读 `director2-creation-mode:<projectId>`。AI 进行中禁用切换。

- **AI 生成**：全屏对话创作室 `Director2AiStudioPane`。四步卡点：`script → assets → episodes → storyboard`。每步确认后采纳进入下一步；不满意可修订并只重跑当前步。结果写入内容库、资产库、剧集工坊。
- **手动编辑**：左侧四菜单 + 对应面板，沿用逐项导入、资产生图、工坊出片与配音。

### 3.1 AI 生成 —— 对话创作室

视觉复刻 beautifului（`--director-*` / `guided-flow.css`）。共用组件：`DirectorPromptBar`、`DirectorTaskRows`、`DirectorClarificationCard`、`DirectorLiveStepFeed`、`DirectorStoryboardLiveBody`、`DirectorAssetSummaryCard`、`DirectorEpisodeCapsule`。

- **Prompt Bar**：圆角 22px 胶囊输入条，右上圆形发送；Enter 发送，Shift+Enter 换行。
- **澄清问题卡**：标题「AI 导演正在规划你的创意」，进度「创作方向 N/M」；逐行展示全部预置选项并保留「输入你的想法」，不能压成三选项。预置项单击高亮，480ms 后自动下一题。操作「跳过这题 / 跳过全部，直接生成 / 按这个方向开拍」。开机题含集数与每集默认镜数。
- **共享直播卡与取消**：`DirectorLiveStepFeed` 完成步骤行 + 当前展开直播块。点击「取消生成」后按钮立即 loading，事件流保持到后端 `cancelled`。
- **资产直播卡**：角色 / 场景 / 道具分组网格，与内容库共用 `DirectorAssetSummaryCard`。
- **分集大纲卡**：标题 `第 N 集 · {title}`、两行梗概、`约 N 镜`（`normalizeEpisodeLiveCard`）。
- **分镜集胶囊**：`DirectorStoryboardLiveBody` 每集一行胶囊，运行中展开、完成后收起。
- **剧本标准台本**：`Director2ScriptLiveBody` 渲染 `.director-stream-article`；定位/人物常驻，集层用 `DirectorEpisodeCapsule`。
- **Task Rows 行内手风琴只用在「集」层**：不得用到外层 `DirectorLiveBlock`、资产摘要卡、分集大纲卡、左侧任务栏 rail。测试锁在 `frontend/src/director/director-live-card-scope.test.tsx`。

### 3.2 内容库 / 资产库 / 剧集工坊 / 全部任务（手动模式）

细节见文末同日增补章节；此处只锁用户可见结构：

- **内容库**：居中导入卡片（TXT/Markdown/Word 或粘贴）；导入后切集落库并入队 `shot_plan`。标题下按集瘦进度；当前集镜头卡就地长出。可「同步至剧集工坊」（覆盖或只补新集）。规划中不能同步。
- **资产库**：角色只出 16:9 设定板；可上传原片截图锁五官服装；角色参考音可上传或从成片框选提取；可选用内置短剧声线。
- **剧集工坊**：分集页 Tabs 镜头 / 剧本 / 配音 / 合成。生成设置含比例、分辨率、模型体积、质量与「出片后 2x 超分」。配音走 IndexTTS-2.5 旁路。外壳锁视口，左右栏各自滚动。镜头检视器「文案 / 草图 / 素材组」Tabs 直接接在顶栏下、占满剩余高度；已出片时多一个「成片」Tab（按真实比例 contain 播放，可放大），不占编辑 Tab 的高度。素材组点「生成 H3 提示词」时若本镜还没有三联关键帧，先确认再自动入队三联；用户查看画面后手动再点生成。生成/重新生成只在提示词栏，不与分区标题重复。参考图片在三联完成后追加起幅/中格/结果三张 9:16 裁切，不放入 16:9 母图。
- **全部任务**：按类型切换（镜头规划、配音、视频生成等）。镜头规划可跳回 `?doc=`；已成功成片可点「超分」。

## 4. 短视频批量（DirectorBatchStudio）

- 顶栏：「← 返回」+ 居中标题「短视频批量」+ 主题切换 +「创作工作台」。
- 左卡「生成参数」：条数（默认 3）、比例（9:16 竖屏）、时长（秒，默认 8）、工作流（官方 MiniMax…）、模型体积（完整 32 GB）、可选画风。

- 结果区：逐条脚本任务行（「任务 <jobId> / 尚未入队」+ 视频/状态 + 重试）。

## 5. 参考片复刻（DirectorReplicationStudio）

- 左栏卡「拉片设置」：模式 Segmented「智能分镜 / 固定分段」、切镜灵敏度滑杆（0.35）、「目标风格（可选）」输入（placeholder「例如：吉卜力动画 / 赛博朋克 / 水墨」）、深度控制强度（1.00）、采样步数（30）、「开始拉片 / 重新拉片」；底部说明「拉片会把参考片按镜头切分，逐镜反推英文提示词并提取深度视频；随后可用 Wan VACE 保留原片运镜与构图，重塑画面内容。」；VLM 未启用时警示「未检测到视觉模型……请到管理设置 → VLM 视觉模型 配置」。

## 5.1 Hypit 复刻（DirectorHypitStudio）

与第 5 节 VACE「参考片复刻」**并列，不混 payload**。路由 `/director/hypit/:projectId`，kind `hypit_replication`。不要把 Hypit Studio 嵌进 beautifului 对话创作室。H3 画面走局域网 ComfyUI `http://192.168.10.54:8188`（`hypit.runtime.json` `comfy.h3`），不占用本机工作台 8188、不新开实例。写 SVML 仍需 Coding Agent（工作台对话不能代替）。

- 顶栏：「← 返回」+「Hypit 复刻」+ 主题切换 +「创作工作台」。
- 提示条「与参考片复刻并列」：拆爆款结构（台词、字幕、B-roll、图形），不是锁运镜转绘。拉片走本机 WhisperX；写 SVML 仍需 Coding Agent；编译走本机 Hypit CLI。H3 画面走局域网 `http://192.168.10.54:8188`，不占用本机 8188。
- 左栏卡「参考片」：上传区「点击或拖入参考片」+「支持 mp4 / mov / webm，最大 2GB。用于拆结构，不是 VACE 深度转绘。」；已上传后预览 +「更换参考片」。
- 左栏卡「改什么」：多行说明（placeholder「例如：保留口播节奏，把产品和字幕换成我们的新品；不要锁原片运镜去转绘。」）、转写语言 Segmented「中文 / 英文」、H3 画质 Select「16GB 稳妥 · 608×1056 / 均衡 · 640×1152 / 官方 768P · 768×1344」（默认稳妥）、「开始拉片 / 编译成片 / 打开项目目录」。

### 流程

导演台2 AI 创作室（`/director2/projects/:id`，`Director2AiStudioPane`）在创意确认（集数 + 每集默认镜头数）之后按四个真实卡点推进，不再一次性跑完整条流水：

### 接口与状态

| 动作 | 接口 | 结果状态 |
| --- | --- | --- |
| 采纳当前步 | `POST /api/projects/{id}/ai/operations/{op}/advance` | 下一 leg `queued` / `running`，或最后一步 `succeeded` |
| 提交调整说明 | `POST …/revise` body `{feedback}` | `revising`，流式出该阶段问题 |
| 重试当前失败/取消步 | `POST …/retry` | 从 `current_stage` 续跑，保留已完成步骤 |
| 重新生成已完成阶段 | `POST …/retry` body `{stage}` | 截断 `completed_stages`，从该步入队，跑完 `awaiting_review` |
| 重新生成创意确认 | `POST …/retry` body `{stage:"clarify"}` | 同一 pipeline 上重开场问题（`revising`）；答完 `rerun` 从剧本开跑 |
