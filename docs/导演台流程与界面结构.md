## 2026-10-24 二采先预览一采（工坊单镜/选中镜）

## 2. 导演台首页（Director2StudioHome）

**2026-10-25 当前结构**：欢迎大标题与横向功能卡已替换为两个工作区。左侧 358px「开始创作 / 选择创作模式，开启你的故事。」面板使用 Ant Design Menu 选择「导演创作 / 短视频批量 / 参考片复刻」，展示对应说明、蓝青 SVG 镜头核心和三步清单；底部唯一主按钮随模式变为「新建导演工程 / 新建短视频批量 / 新建参考片复刻」。选择模式只更新当前页面，不创建空工程。导演创作先弹原制作配方 Modal，另两项点击创建后进入原路由。左下为「剧本诊断 / 查看评估与修改建议」，不再横贯页面。右侧「我的工程 (数量) / 继续创作，或开始一个新故事。」上方提供刷新，下方为类型 Segmented 与搜索 Input，再下为 Ant Design Table 宽列表：工程（真实封面或无封面图标、名称、简介）、创作类型、最近编辑、打开与更多菜单。复制 / 删除位于更多菜单，删除用 Modal 二次确认。列表底部显示当前项数、查看全部 / 收起与「按最近编辑排序」。浅暗主题继承根 Provider；两列独立滚动；<1400px 桌面启动台为 300px。下述三卡布局为 2026-10-23/25 的历史基线，创建协议、合并筛选与空态规则继续生效。

- **顶栏**：64px 单层顶栏，左场记板图标和「导演台」，右主题切换（ThemeToggle）；首页不再套整页圆角卡片。全局图标轨仍为 76px。
- **Hero 区**：大标题「今天，想拍点什么？」，副题「用 AI 将你的创意变成精彩的影视作品。」
- **三个创作入口**（横向卡片，主卡 `grid-row: 1 / 3` 对齐右侧两张小卡，下方为整行的剧本诊断入口）：
  1. **导演创作**（324px 主卡，浅靛蓝表面，右侧 CSS 电影格几何图形）：「一句话开始，完成剧本与分镜」；步骤指示 `1 故事 → 2 角色 → 3 分镜`；CTA「+ 新建导演工程」。先弹出 Ant Design Modal 从 `GET /api/skill-packs` 选制作配方：两列动态封面卡（半解说包热链 Hub 官方 mp4，未绑定用渐变占位；默认「半解说真人短剧」），再 `POST /api/projects` 写入 `extra.skill_pack_id`，进入 `/director/projects/:id/content`。内容库「骨架模板」不是这一项。
  2. **短视频批量**：「一个主题，生成多条短视频」，右箭头。创建后进入 `/director/batch/:id`。

- **智能剪辑助手**：右栏自动显示当前工程/分集，欢迎区「剪辑工具」紧凑显示「智能铺轨 / 智能成片 / 字幕」三项入口：铺轨直接预览清单，智能成片下拉保留对白精剪 / 成片速剪 / 高光合集 / 引流剪辑，引流的五策略位于下级菜单；字幕下拉保留自动字幕 / 音轨字幕。有消息后可展开同一「剪辑工具」。按钮由`EDITING_TOOL_GROUPS`配置扩展，保持Skill/专家/知识库/模型工具栏。按钮或自然语言生成「需要你的授权」弹窗：铺轨列出完整视频清单、数量、追加位置和时长；剪辑类列出逐镜截取/保留时长与理由；引流剪辑另显示策略名和原则；音轨字幕列出条数、时长、引用的转写段数与音频秒数、替换与跳过数量。确认后写入时间线、自动保存，整次可撤销/重做。铺轨跳过已铺分镜与重复视频，缺视频不拿图片代替；剪辑类保留手工文字。版本冲突要求重新预览。普通会话及各集剪辑会话分别恢复。小于 1560px 时助手 360px、素材 272px、属性 224px；1560–1799px 时助手 400px、素材 328px、属性 256px；1800px 以上助手 440px，素材 / 属性仍为 328px / 256px，预览弹性。剪辑会话欢迎区与对话区另有「视频理解」和「音频转写」两张依据卡片：显式开始后显示进度、模型、完成时间和可展开的逐镜画面依据 / 逐段语音依据；每条素材内部镜头经 FFmpeg 边界检测后分别列出时间范围、描述、机位与主体（每素材最多 4 镜、全时间线最多 40 镜），每条有声素材的转写段落列出起止秒与文本（单次最多 40 条素材、600 秒音频）。完成后的引流/高光清单逐镜理由带「画面理解：…」，授权弹窗顶部显示「镜头边界检测后采样的 N 个镜头关键帧描述」；音轨字幕授权弹窗显示「音轨转写：… 段真实语音」。未开始、失败或素材变化时不影响原有文本评分。

### 3.0 创作模式（AI 生成 / 手动编辑）

**2026-10-19 V2 当前基线**：默认全局侧边助手，AI生成打开右侧480px非模态面板，手动编辑或关闭面板收起；四个业务菜单始终可用。保留mode参数与项目偏好，首页可先独立创作，关联工程不随页面变化。以下旧卡点流程仅在`ZLY_AI_VIDEO_STUDIO_DIRECTOR_ASSISTANT_V2=false`时作为回退入口，旧任务可从「继续旧任务」恢复。

- **AI 生成**：全屏对话创作室 `Director2AiStudioPane`。四步卡点：`script → assets → episodes → storyboard`。每步确认后采纳进入下一步；不满意可修订并只重跑当前步。结果写入内容库、资产库、剧集工坊。

### 3.1 AI 生成 —— 对话创作室

**2026-10-25 自然语言创作与恢复**：可直接在底部输入框用普通文字回答当前澄清问题，再要求完整剧本和修改。正文先形成会话草稿，通过「查看并采纳 → 预览写入变更 → 采纳到工程」进入内容库；采纳不自动生成媒体。点击历史列表中的当前会话保留现有内容并重新加载；运行已结束但详情读取失败时，解除输入锁并在错误提示中提供「重新加载」，成功恢复后清除旧提示。原有浅暗 token、布局与草稿采纳控件保持不变。

内容库兼容常见粗体 Markdown 字段，动作、运镜、音效、对白和旁白分别解析；`## 主要人物` 下的简短人物设定也可识别。照片、留言等动作描述中的引号文字不会自动变成人物对白。普通讨论、否定写稿及剪辑操作不强制生成剧本；新写下一集与修改上一版使用独立的草稿关系。

2026-10-26 补充：镜头中的「同上 / 同前」在同一集继承前镜场景，场景库按名称去重，完整光线和环境说明保留在正文；标题中的秒数范围可补齐镜头时长，显式时长优先。

终验基线为 2026-10-26：`智能创作验收 · 明日照片 · 20261025` 工程完成首稿与两次普通文字改稿，草稿版本 1/2/3 均经预览采纳，最终同一份文档为 1 集、6 镜、2 角色、1 场景、60 秒，刷新可恢复。内容库镜头卡的底色、正文、标签、对白及音效区域统一使用已有 `--studio-*` 变量，浅暗均已自查；不改变对话创作室 token、布局和控件尺寸。截图见上方 `language-flow-20261025/` 索引。

## 2026-09-16 导演台2 AI 逐步卡点确认

### 流程

导演台2 AI 创作室（`/director2/projects/:id`，`Director2AiStudioPane`）在创意确认（集数 + 每集默认镜头数）之后按四个真实卡点推进，不再一次性跑完整条流水：

1. **剧本** `script`
2. **角色 / 场景 / 道具** `assets`
3. **分集** `episodes`
4. **分镜** `storyboard`

每步跑完进入 `awaiting_review`（暂停、无 worker）。用户可「采纳」进入下一步，或「不满意」用对话反馈只重跑当前步。已完成的更早阶段可单独「重新生成」：该阶段之后不再算完成，确认后需再次生成；底部「从当前阶段重试」仍只续跑停住的那一步。创意确认重开时在同一条 pipeline 上重新出开场问题，答完从剧本重跑。最后一步采纳后任务 `succeeded`。同一项目同时只允许一个占用中的 AI 任务（含待确认 `awaiting_review` 与调整中 `revising`）；刷新后由 `GET …/ai/operations/active` 接管。进程重启不会把待确认任务标失败。

### 界面结构

- **页头**：待确认显示「第 N 步已生成，请确认」（剧本=1 … 分镜=4）；调整中显示「正在按你的反馈重新规划…」。副文案用该阶段直播/确认消息（如「剧本已生成，请确认或提出调整」）。
- **左侧任务栏**（`DirectorTaskRows`）：`awaiting_stage` 之前的步骤为已完成，当前步胶囊「待确认」，后续为未开始。状态胶囊（已完成 / 失败 / 待确认）全部右对齐：行尾固定预留重生成按钮槽位，按钮绝对定位，不把「已完成」挤离右缘。已完成行 hover 出「重新生成」；失败行仍是「失败」pill 重试当前步。窄栏只做进度，不塞问答。

### 接口与状态

| 动作 | 接口 | 结果状态 |
| --- | --- | --- |
| 采纳当前步 | `POST /api/projects/{id}/ai/operations/{op}/advance` | 下一 leg `queued` / `running`，或最后一步 `succeeded` |
| 提交调整说明 | `POST …/revise` body `{feedback}` | `revising`，流式出该阶段问题 |
| 重试当前失败/取消步 | `POST …/retry` | 从 `current_stage` 续跑，保留已完成步骤 |
| 重新生成已完成阶段 | `POST …/retry` body `{stage}` | 截断 `completed_stages`，从该步入队，跑完 `awaiting_review` |
| 重新生成创意确认 | `POST …/retry` body `{stage:"clarify"}` | 同一 pipeline 上重开场问题（`revising`）；答完 `rerun` 从剧本开跑 |
