### 3.0 创作模式（AI 生成 / 手动编辑）

顶栏右侧常驻 antd Segmented「创作模式」切换（`DirectorCreationModeSwitch`）。模式真源为 URL `?mode=manual|agent`，缺省读 `director2-creation-mode:<projectId>`。AI 进行中禁用切换。

- **AI 生成**：全屏对话创作室 `Director2AiStudioPane`。四步卡点：`script → assets → episodes → storyboard`。每步确认后采纳进入下一步；不满意可修订并只重跑当前步。结果写入内容库、资产库、剧集工坊。
- **手动编辑**：左侧四菜单 + 对应面板，沿用逐项导入、资产生图、工坊出片与配音。

### 3.1 AI 生成 —— 对话创作室

视觉复刻 beautifului（`--director-*` / `guided-flow.css`）。共用组件：`DirectorPromptBar`、`DirectorTaskRows`、`DirectorClarificationCard`、`DirectorLiveStepFeed`、`DirectorStoryboardLiveBody`、`DirectorAssetSummaryCard`、`DirectorEpisodeCapsule`。

- **Prompt Bar**：圆角 22px 胶囊输入条，右上圆形发送；Enter 发送，Shift+Enter 换行。
- **澄清问题卡**：标题「AI 导演正在规划你的创意」，进度「创作方向 N/M」；逐行展示全部预置选项并保留「输入你的想法」，不能压成三选项。预置项单击高亮，480ms 后自动下一题。操作「跳过这题 / 跳过全部，直接生成 / 按这个方向开拍」。开机题含集数与每集默认镜数。
- **共享直播卡与取消**：`DirectorLiveStepFeed` 完成步骤行 + 当前展开直播块。点击「取消生成」后按钮立即 loading，事件流保持到后端 `cancelled`。
- **资产直播卡**：角色 / 场景 / 道具分组网格，与内容库共用 `DirectorAssetSummaryCard`。
- **分集大纲卡**：标题 `第 N 集 · {title}`、两行梗概、`约 N 镜`（`normalizeEpisodeLiveCard`）。
- **分镜集胶囊**：`DirectorStoryboardLiveBody` 每集一行胶囊，运行中展开、完成后收起。
- **剧本标准台本**：`Director2ScriptLiveBody` 渲染 `.director-stream-article`；定位/人物常驻，集层用 `DirectorEpisodeCapsule`。
- **Task Rows 行内手风琴只用在「集」层**：不得用到外层 `DirectorLiveBlock`、资产摘要卡、分集大纲卡、左侧任务栏 rail。测试锁在 `frontend/src/director/director-live-card-scope.test.tsx`。

### 3.2 内容库 / 资产库 / 剧集工坊 / 全部任务（手动模式）

细节见文末同日增补章节；此处只锁用户可见结构：

- **内容库**：居中导入卡片（TXT/Markdown/Word 或粘贴）；导入后切集落库，若工程仍叫「未命名导演工程」则顶栏改成剧本文件名或文内主标题；先弹出成片画幅确认（扫描原文 9:16/16:9/竖屏/横屏等作建议），确认写入 `extra.workshop_aspect_ratio` 后再入队 `shot_plan`。未确认前文档为「待确认画幅」，标题下没有规划进度。确认后按集瘦进度；当前集镜头卡就地长出。已规划文档操作区显示「重新规划镜头」，Popconfirm 说明会覆盖本集出片镜、工坊 Take 不自动删除，需再同步工坊。可「同步至剧集工坊」（覆盖或只补新集）。规划中不能同步。
- **资产库**：角色工作区自上而下为身份与造型设定板、角色定义、角色参考音。角色只出 16:9 设定板；道具工作区同样是一张 16:9 设定板（左三视、右上材质、右下细节），批量「一键生成所有设定板」；可上传原片截图锁五官服装或道具外形；角色参考音可上传或从成片框选提取；可选用内置短剧声线。一键生成（角色/道具设定板 / 场景正面·背面·360）时左侧列表每条立刻出现进度条：排队中为空轨，当前生成中为动画条+百分比，完成后缩略图替换进度；失败条保持到本轮结束。
- **剧集工坊**：分集页 Tabs 镜头 / 剧本 / 配音 / 合成。生成设置含比例、分辨率、模型体积、质量与「出片后超分」（关闭 / 2x / 4x）；改比例会写入 `extra.workshop_aspect_ratio`，与导入确认共用。生成设置所选工作流的 `prompt_profile` 决定页头下方提示词面板：`full_reference` 显示当前 Beat 的「Minimax 六段式提示词」，`director_segments` 显示整集「Director 出片方案」。两者都有语言、严格/扩写模式、参考资产多选与排序、生成预览、确认保存；Director 另有目标段数、公共设定、Part 折叠、段内 `[Shot N]` 与同一 Part 连续段局部生成。Director 模式不显示原 Beat 勾选出片入口，顶栏按钮为「生成 Director 全集」。过期稿/方案显示警告且禁止出片。配音走 IndexTTS-2.5 旁路。桌面端分集内容区统一纵向滚动，镜头工作区保留稳定高度，左右栏仍各自滚动；镜头检视器的旧素材组仍可查看和手写提示词，但不再提供旧自动写稿按钮。

## 2026-09-16 导演台2 AI 逐步卡点确认

### 流程

导演台2 AI 创作室（`/director2/projects/:id`，`Director2AiStudioPane`）在创意确认（集数 + 每集默认镜头数）之后按四个真实卡点推进，不再一次性跑完整条流水：

1. **剧本** `script`
2. **角色 / 场景 / 道具** `assets`
3. **分集** `episodes`
4. **分镜** `storyboard`

每步跑完进入 `awaiting_review`（暂停、无 worker）。用户可「采纳」进入下一步，或「不满意」用对话反馈只重跑当前步。已完成的更早阶段可单独「重新生成」：该阶段之后不再算完成，确认后需再次生成；底部「从当前阶段重试」仍只续跑停住的那一步。创意确认重开时在同一条 pipeline 上重新出开场问题，答完从剧本重跑。最后一步采纳后任务 `succeeded`。同一项目同时只允许一个占用中的 AI 任务（含待确认 `awaiting_review` 与调整中 `revising`）；刷新后由 `GET …/ai/operations/active` 接管。进程重启不会把待确认任务标失败。

### 界面结构

- **页头**：待确认显示「第 N 步已生成，请确认」（剧本=1 … 分镜=4）；调整中显示「正在按你的反馈重新规划…」。副文案用该阶段直播/确认消息（如「剧本已生成，请确认或提出调整」）。
- **左侧任务栏**（`DirectorTaskRows`）：`awaiting_stage` 之前的步骤为已完成，当前步胶囊「待确认」，后续为未开始。状态胶囊（已完成 / 失败 / 待确认）全部右对齐：行尾固定预留重生成按钮槽位，按钮绝对定位，不把「已完成」挤离右缘。已完成行 hover 出「重新生成」；失败行仍是「失败」pill 重试当前步。窄栏只做进度，不塞问答。
- **创作路径 Tool Chips**（记录流、用户创意气泡下方）：`DirectorPathChips` 复用 `.director-direction-chips.is-path`。标题单独一行，其下按阶段分行（阶段名固定列宽，选项 chip 跟在右侧）。开机确认题按题意挂到真正受影响的步骤（结局/基调→剧本，主角/角色→角色·场景·道具，集数→分集，镜头数→分镜），chip 文案写选项 **label**（如「1 集 · 单集成片」）而不是 Agent 用的 value「1」。`title` 为完整 `问题 → 答案`。跳过未作答的题；直接「采纳」且没有可继承选项的阶段不出现在路径条，也不再显示「已采纳本次生成」。390 宽阶段名与 chip 上下堆叠。对照 beautifului Tool Chips 的紧凑胶囊，不新装库。
- **记录流确认卡**（`DirectorLiveStepFeed` 的 `director-block` / `director-completion-card`，复用导演台视觉）：展示该步直播/产出内容。文案「这一步可以进入下一步吗？」；最后一步为「分镜已经生成，确认后完成本次创作」。按钮「不满意，调整」+「采纳，继续下一步」（最后一步「采纳，完成创作」）。
- **完成步骤行选项回显**（`DirectorLiveStepRow` 卡片行下只读问答列表，非手风琴、非换行 chip）：询问卡提交后立刻变成收起态。每条为「问题（弱化）| 答案（主文案）」两列；创意确认行展示全部开机选项；剧本 / 角色 / 分集 / 分镜行展示该步继承到的开机选项，以及该步「不满意」后再答的选项（后者覆盖同题）。整张卡「跳过全部」且无答案显示「已跳过，沿用默认」；直接「采纳」不再用假选项「已采纳本次生成」占位。创意确认完成行摘要优先用集数题 label。点步骤行打开抽屉时，抽屉顶部同样列出该步选项，下面才是产出。提交询问卡时写入 `label`，并在 pipeline `request.clarify_questions` 保留题面以便刷新后把 value 还原成 label。
- **记录流排版**：页头标题 16px、说明最多两行；用户创意为右对齐软色块；步骤行是 inset 卡片，阶段名 14px，右侧摘要不再拉满成矮 chip 条。

- **阶段澄清卡**：出题后复用 `DirectorClarificationCard`（选项自动翻页、自定义输入、跳过本题/全部）。作答调用 `rerun` 只重跑当前步，完成后回到同一阶段确认卡。创意确认重开时同一张卡答完从剧本重跑。

- **底部终态按钮**：取消后「从当前阶段重试」、失败后「重试本阶段」仍不带 `stage`，只续跑停住的那一步。重试会清掉上次取消留下的 `cancel_requested`，不会刚入队就再次停止。页头「正在停止当前生成」只在取消尚未落定、任务仍进行中时显示。

### 接口与状态

| 动作 | 接口 | 结果状态 |
| --- | --- | --- |
| 采纳当前步 | `POST /api/projects/{id}/ai/operations/{op}/advance` | 下一 leg `queued` / `running`，或最后一步 `succeeded` |
| 提交调整说明 | `POST …/revise` body `{feedback}` | `revising`，流式出该阶段问题 |
| 重试当前失败/取消步 | `POST …/retry` | 从 `current_stage` 续跑，保留已完成步骤 |
| 重新生成已完成阶段 | `POST …/retry` body `{stage}` | 截断 `completed_stages`，从该步入队，跑完 `awaiting_review` |
