# 内容库右侧阅读工作区验收

日期：2026-09-27。目标：优化既有内容库右侧的信息顺序与实际阅读动线，不改变生成协议或项目数据。

## 设计与实现

以现有工作台的 Ant Design 和 --studio-* 为视觉依据；按 impeccable 的 Operate／layout 方法将阅读置于主任务，减少常驻表单和嵌套卡片。没有重做左侧导航或对话创作室。

原界面先显示策划表单、完整稿折叠、绿色成功提示，随后才出现文档标题和默认全折叠的分集；1440×1000 首屏看不到正文。现界面为一个右侧工作区：文档信息置顶，紧接分集剧本／剧本发展／导入原文三项页签，已有分集直接显示第一集。

分集工具栏有可搜索选择器、当前位置、上一集／下一集和复制。本集、场景、加粗字段与正文按层级排版，复制仍使用未变换的原文。正文内部滚动，标题与操作不随长文消失。原导入文本逐字保留，旧解析摘要仍可展开查看。缺少正文但有 summary 时明确标为梗概。

## 文件和兼容性

- frontend/src/director2/panes/UnifiedContentLibraryPane.tsx：重排右侧、局部页签状态、加载及错误反馈、文档请求竞态保护、原文和解析摘要。
- frontend/src/director2/panes/ContentLibraryReader.tsx：分集阅读与安全文本排版，不执行 HTML，不重新解析或写入后端剧情。
- frontend/src/director2/panes/unified-content-library.css：独立作用域、双主题语义色、桌面高度与 Ant Design 6 页签滚动。
- frontend/src/director2/panes/ContentLibraryReader.test.tsx：初始正文、非连续编号、边界按钮、来源优先级、空数据、梗概标记、HTML 转义。

既有 ScriptDevelopmentPanel 不修改；forceRender 保留既有轮询，切换页签不丢策划输入，采纳后刷新文档并回到阅读。保留 doc 深链及其他查询参数。无新依赖、数据库迁移、后端 API、端口、ComfyUI 地址或节点变更。没有删除或覆盖用户剧本、镜头、提示词、视频。
