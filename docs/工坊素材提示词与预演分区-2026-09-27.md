# 工坊素材、提示词与动作预演分区（2026-09-27）

## 设计决策

本轮解决「素材与提示词」页将人物、场景、道具、参考准备与动作预演塞进窄侧栏的问题。按三种任务拆开，不替换全局设计语言：

| 页签 | 首要任务 | 空间与交互 |
| --- | --- | --- |
| 素材（默认） | 确认出镜资产与参考用途 | 全宽图廊；人物／场景并列、道具整行；图片完整显示，名称与造型分层 |
| 提示词 | 写稿、审阅、保存与提交视频 | 全宽正文；固定操作栏；候选仍在原 Drawer 审阅 |
| 动作预演 | 可选的动作与机位验证 | 直接展开编排工作区，长方案独立滚动，不再嵌套折叠 |

保留「镜头内容」「视频版本」，形成五个检视器页签。草图与三联关键帧属于素材准备，在素材页直接展示；动作预演不是每镜必经步骤，不把它包装成强制流程。照片使用真实素材或明确空态，不为设计补造资产。

Impeccable 的 Operate／layout 指南用于任务分区、稳定密度和沿用现有视觉；React 指南用于派生素材列表、删除不再需要的宽度状态及按镜头 key 隔离预演状态。本轮由同一执行上下文完成产品、UI 与前端自审，不宣称经过独立用户可用性测试。
