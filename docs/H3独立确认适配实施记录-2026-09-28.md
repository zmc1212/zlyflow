## 本次实现

- `comfyui_nodes/zly_h3_confirmation/{__init__,node,protocol}.py`：新增 `ZlyH3ConfirmedDirector` 类。使用每次调用的私有函数全局命名空间复用作者执行器，不修改作者模块全局函数；旧类继续注册。
- `preview_only` 的执行缓存读取强制不升级二采，二采调用守卫直接报错；保存一采后再加载验证 latent，不能把上游吞掉的保存错误当成功。
- `refine_only` 在实际执行点加载原缓存，缺失立即报错；任何一采调用、回写一采均被守卫阻止。已加载的 latent 留在执行上下文中，后续磁盘文件丢失不能使其回退一采。
- 同一源 cache_key 使用系统文件锁；实例标识持久化；冻结 graph 的上游祖先（含模型、参考路径、seed）生成 source_revision，只允许阶段字段、1/2 MP 变化。源预览完成后不可覆写，新预览必须用新 cache_key。
- 专用目录为 `output/zly_h3_confirmation` 和 `output/minimax_seg_cache/zly_confirm_<cache_key>`，不触碰作者数字节点缓存。报告包含阶段、实际采样次数、缓存/复用段、源修订和实例身份。
- 固定作者关键源码文件哈希，遇到不兼容版本拒绝新流程，不影响旧类。支持作者 R2V 完整分组配方；不支持外部组、选择性运行、SelfLift、Semantic Bridge、FaceRefine。
- `backend/app/minimax_h3_confirm_workflow.py`：独立配方 `director-confirm-accel@1`，副本改节点 12 的 class_type，保留其它作者模型与采样链；确认 graph 从原冻结 graph 和有效报告派生，禁止以视频或 ComfyUI success 代替阶段证明。
- `backend/workflows/director_confirm_accel/preview.api.json`：可审查 API 模板，参考文件/cache_key 是显式占位符，提交前须填写；旧 `director_refine_accel` 文件未改。
- `backend/tests/acceptance_h3_confirmation.py`：显式提交 preview/refine 或读取 status 的远端验收工具，读取实际 comfy_row，仅在远端队列空闲时提交专用任务，产物在已忽略 `test-results/h3-confirmation`。

任务权限、确认 API、幂等子任务、分组恢复、候选采用和桌面界面尚未接入；本次不把“节点就绪”描述为完整工作台功能完成。原 `director-refine-accel@1` 及 hidden_from_catalog 保持原样。
