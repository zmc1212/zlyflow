# 无限画布首页 · 实现与桌面验收

设计日期：2026-10-28。实现完成日期：2026-10-29。

入口：[5173 无限画布首页](http://127.0.0.1:5173/canvas)。原设计为本目录 `01-home-light.png` / `02-home-dark.png`，实现截图保存在 `implementation-20261029/`。

## 已实现

- 悬浮品牌 / 账号工具区、首页业务导航、标题、最近创作大卡、独立新建入口和四列画布库。
- 最近项目按真实草稿保存时间选取；搜索、收藏和库排序不改变最近项目的定义。全部计数、标签、节点数、保存时间和管理操作继续来自原接口。
- SVG 缩略图展示真实节点、图片 / 视频封面、标题 / 文字、连接端口和曲线；密集画布聚焦实际相连节点并标注局部预览。不改变草稿中节点的坐标或排列。
- 新建、继续 / 打开、编辑标签、收藏、复制、回收站、恢复和永久删除确认均接通。标签候选在选中后收起，修复下拉层遮住保存按钮的情况。
- 浅暗主题沿用根 Provider 和 Ant Design；新建图形为独立 SVG，页面不使用整张设计稿背景。
- 加载、错误重试、暂无画布、暂无收藏、无筛选结果、旧摘要、失效图片、无视频封面和长标题均有可操作的状态。

## 数据兼容

仅在既有 `preview_json.items` 增加可选 `label`（48 字符）与 `text`（160 字符），前后端均归一化空白并忽略非法类型。48 KB 摘要预算和原媒体 / 封面约束保持；超预算优先删可选文字，再走原降级策略。

旧数据可直接打开，下次保存才补齐文字摘要，不逐条读取完整草稿或批量迁移。没有改动 API 路径、数据库表列、草稿 schemaVersion、工作流、任务提交或 ComfyUI 配置。首页样式由 `studio-canvas-home-shell` 限定，离开首页后交还当前共用页头与编辑器布局。

- `actual-light.png` / `actual-dark.png` 为 1586×992 的真实页面截图；另保留 1440 / 1920 的桌面图和菜单 / 弹窗状态。

- 后端功能通过临时 SQLite 验证；没有向远端生产数据库写入测试画布，也未触发生成、收费调用或变更 ComfyUI 实例。没有执行移动端检查。
- 当前 7865 进程由既有 `backend.dev_reloader` 管理，代码变更自动生效；本轮没有另起工作台或 ComfyUI。
- 前端构建仍提示既有大型 chunk；构建成功，没有增加依赖或为此扩大拆包范围。
