## 布局与控件

- 画布工作区使用 60px 全局顶栏、86px 导航和 64px 命令栏。品牌用代码绘制，标题、编辑入口、保存反馈与操作按钮按参考布局；这些覆盖限定在画布工作区。
- 工具轨 58×481px，主要按钮 42px，撤销/重做/快捷键按钮 38px；添加菜单 226×327px。图标、双行说明、快捷键键帽、分组缩进和分隔线均单独核对，保留生成、文字、图片、画板和作品库入口。
- 右侧面板 360px，标签、概览、三项读数、视图开关、连线分段、生成结果分段、80px 全局提示词及固定素材入口按参考定位。打开画布设置时保留选中节点与浮动工具条；点击节点后回到节点属性。
- 75% 相机下核对四个节点及 262×38px 浮动工具条。生成节点内联工作流、提示词、来源标签与底部操作。关闭来源标签会断开对应连线，可撤销；切换工作流复用检查器的参数重置逻辑，保留提示词与历史运行快照。
- 连线按来源着色，连接点在精简模式下与可见连线一起显示。图片卡片的连接点可完整越出边框；媒体内容仍在独立容器内裁切。缩放手柄和边线在悬停时显现。
- 新生成节点默认 356×446；已有节点的尺寸保持原值。旧版 316×240 节点实测内容区可滚动，操作按钮保持可见。底部视图栏 375×49px，小地图 174×101px，使用原生 React Flow 平移、缩放与节点定位。
- 菜单、Select、Modal、Popover、Tooltip、Drawer、分段控件、表单与反馈均复用 Ant Design。图片地址弹窗覆盖默认、聚焦、错误和禁用提交；弹窗内输入不会触发底层画布快捷键。
- 素材 Drawer 顶部与 60px 顶栏对齐；搜索和分页留在面板内，只有素材网格滚动，消除正文与网格的双重滚动。保留当前版本的服务端检索、加载更多和视频封面能力；PNG 导出弹窗的普通、透明背景与桌面边界一并回归；说明文案只解释可用图片、视频封面和占位卡对输出的影响。
- 浅暗主题仍由根 Provider 和浏览器偏好驱动。菜单选中文字使用语义强调色，实测浅色对比度 4.60、暗色 7.07；暗色的紫色、琥珀色节点图标使用深色前景，避免白色图形落在浅色底上。

## 自动采集与复核

使用 `draw-ui` 的 `measure_reference.py → prepare_capture.py → collect.js → verify_capture.py`。采集前核对真实 URL、标题、1586×992 视口、DPR 1、字体和图片完成状态，等待保存及弹层动效稳定。同一轮采集 DOM 元数据和截图，按原尺寸比较，保留逐区几何报告、像素差异、原图摘要及截图摘要。

21 个区域均成功定位，外框最大偏差 2 CSS px；主要容器、添加菜单、四个节点、缩放栏与小地图的外框已经对齐。面板标签区的 DOM 内框与参考外缘存在 1px 边界计量差，宽度差为 2px。该数字只说明外框几何，不代表还原率。另对顶栏按钮、面板标签、关闭图标、设置标题、菜单标题和节点标题共 22 处可见文字/图标做固定 ROI 墨迹比较，使用同一亮度阈值提取边界，见 [墨迹记录](fidelity-micro-ink.json)；保留字体轮廓与抗锯齿差异。

已逐张复核完整浅色画面、叠加图、局部控件和暗色画面。自动采集器的“身份与渲染前提通过”只作为采集证据；视觉判断另结合字体、换行、图标、素材裁切和实际交互。[机器验收记录](fidelity-report.json)、[采集元数据](fidelity-capture.json) 与 [逐区几何](fidelity-geometry.md) 可独立检查。

基础回归覆盖浅暗两套的 30 个弹层与面板状态、77 项交互断言；当前版本另补导出文件菜单、PNG 普通/透明预览、素材卡片、分页和搜索空结果共 12 张截图，校验 40→45 项分页及搜索反馈。桌面 1440×900、1586×992、1920×1080 检查布局；未做移动端验证。旧尺寸节点、主题对比度和字体实际命中另有记录。Chromium 实际命中的字体为中文 `Microsoft YaHei`、品牌 `Arial`。

验证命令：`pnpm --dir frontend build`（测试、类型检查、清理和构建）；`python -X utf8 -m unittest backend.tests.test_canvas_store -q`。当前工作区为 60 个前端测试文件、397 项和 18 项后端画布测试通过，构建通过；保留既有分块体积提示。

## 原图示意内容与业务状态

原图中的照片只裁取纯摄影区域，用于隔离测试画布；裁切避开连接点、边框和说明文字，图片预览中不保留界面符号。未把整张设计图或含控件的裁图充当界面。工作流示例通过验收浏览器的测试响应提供，业务仍读取 `/api/modes`，没有在源码添加 FLUX 固定选项。未调用生成接口、切换供应商或修改真实用户数据。

验收保留以下可解释差异，并在差异图中完整呈现：

| 原图 | 可运行界面 |
| --- | --- |
| 主画布画出三条连线，概览写“2” | 概览按实际三条连线计数 |
| 画布大小示意为 2 KB | 按测试草稿实际字节数显示 |
| 字符限制示意为 800，字数与文字并不一致 | 保留真实 4000/2000 上限及实际字数 |
| 生成节点显示与已连接文字不相同的示意提示词 | 按真实文字连线读取提示词，断开后恢复手动输入 |
| 头像及缩略小地图是绘制的示意内容 | 账号显示当前用户缩写，小地图按真实节点位置、比例与类型绘制 |
| 字形来自 AI 位图，没有原字体文件 | 用实际命中的字体重建文字，保留浏览器抗锯齿和重采样差异 |

因此不宣称整幅位图逐像素相同，也不把像素差异换算成“99% 还原率”。布局、组件视觉和交互的验收结论与这些数据、字形差异分开记录。

## 文件与兼容性

本轮主要涉及 `App.tsx` 的画布外壳、`ThemeToggle.tsx` 的可选当前主题图标，以及 `frontend/src/canvas/` 的工作区、编辑器、节点、侧栏、生成检查器、PNG 导出说明、共享工作流切换函数、节点默认尺寸与 `canvas-fidelity.css`。新增样式继承 `--studio-*`，补充成对的 `--canvas-*`。没有新增 UI 依赖。

`schemaVersion 2`、草稿、版本历史、运行快照与当前 V4.5–V4.7 能力保持兼容。本轮不新增后端 API 或数据库迁移。新增前端文字端口 `prompt`，原 `in` 继续保留，旧草稿无需改写；这与 ComfyUI graph 的节点 ID 无关。

回滚只撤回本轮对应增量，保留用户已有和后续 V4.5–V4.7 改动，不执行整目录恢复或清理未跟踪文件。若回退到没有 `prompt` 端口的旧渲染器，新文字连线的数据仍在，需要将该端口恢复到 `in` 才能在旧界面显示。默认尺寸只影响新建节点，不回写旧节点。

临时脚本、SQLite 和过程日志位于已忽略的 `test-results/canvas-fidelity-20261023/`；正式截图与报告位于本目录。此前自动审批以 `blocked by policy` 拒绝递归删除验收目录，因此过程文件保留并继续忽略；不使用其他方式绕过拒绝。验收使用的浏览器和 7866 服务在交付前停止，5173 开发服务与 7865 业务服务保留。
