# 无限画布自动化验收 · 2026-10-24

本轮发现的问题已修复并复测通过。最终结果：前端 **61 个文件 / 422 项**、相关后端 **163 项**、浏览器 **95 项断言**全部通过；生产构建通过。当前配置的远端 ComfyUI 已完成一条真实视频任务，画布播放与下载通过。

## 修复内容

| 问题 | 修复后的行为 |
| --- | --- |
| 保存尚未结束就返回，最后编辑遗漏 | 保存请求串行执行，补存期间的新修改后才返回；失败保留当前页面与草稿 |
| 侧栏切换、重新聚焦或网络恢复时草稿丢失 | 编辑器保持稳定挂载，同标签页恢复未保存草稿；旧请求不能覆盖新编辑器的备份 |
| 冲突无法保全本页内容，重复提交误报冲突 | 真正冲突保留本页并提供草稿导出；内容已与服务器一致时接纳最新版本 |
| 标题不能改回原名、恢复历史时遗漏当前内容 | 重命名按最新已保存标题比较；恢复历史前先保存当前内容 |
| 设置未随撤销恢复、相机/封面污染撤销栈 | 设置与节点一同撤销，相机与封面变化不创建历史步骤；导入撤销同步恢复设置 |
| 隐藏连线时删除节点留下关联边 | 始终从完整边集合清理，撤销能恢复节点和边 |
| 一采预览状态没有确认/保留操作 | 画布节点和检查器支持确认二采、保留一采、停止，复用原任务与现有接口 |
| 历史版本切换后仍播放最新结果 | 节点与检查器展示同一个选中版本；最终输出优先于预览，过期输出不采用 |
| 立即成功未插入、重复轮询重复插入、共享任务仅更新一个节点 | 正式成功统一落盘，独立结果按任务去重，所有引用节点同步；已删除任务结束轮询并显示原因 |
| 部分文字来源为空时仍可提交 | 任何空文字来源都会阻断，节点与检查器给出一致原因 |
| 异常导入/旧草稿的对象型文本导致 React 崩溃 | 导入拒绝异常文本字段，旧数据归一化后安全展示 |
| 新节点被工具栏遮挡、长标题裁断、收藏空态无效、加载按钮名称不稳定 | 按可用舞台揭示新节点，长标题省略且保留提示，空态可返回全部，保存/取帧操作保持稳定无障碍名称 |

修复集中在 `frontend/src/canvas/`；原有 V4.8/V4.9、自定义封面与裁切保留。工作区已有的其他模块改动保留。
