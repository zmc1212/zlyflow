### 每类节点的入口与操作

| 类型 | 端口与正文 | 选中工具条 | 空态 / 异常处理 |
| --- | --- | --- | --- |
| 文字 | 右侧输出；正文为可编辑 Ant Design TextArea | 以此生成、属性、复制、删除；没有素材下载 | 空态「输入文字…」；长文本在固定高度内滚动 |
| 图片 | 左输入、右输出；大图 + 可选说明 | 以此生成、属性、复制、下载、删除 | 从作品库选择 / 在属性中填地址；待上游「等待生成」；失效「素材无法加载 / 地址可能已过期」 |
| 视频 | 左输入、右输出；封面 + 播放入口 | 属性、复制、下载、删除；当前不提供「以此生成」 | 作品库或生成结果进入；待上游与加载失败沿用图片语义；播放打开预览弹层 |
| 生成 | 左侧提示词与参考图语义分离、右输出；媒体与任务状态 | 以此生成、插入结果、属性、复制、下载、删除；无结果时下载禁用 | 根据当前工作流能力展示输入与验证；状态见下一节 |
| 画板 | 没有生成端口；可编辑标题与可缩放区域 | 属性、复制、删除 | 只是视觉分区，不暗示分组 / 解组、层级绑定或移动时自动携带内部节点 |
| 未知类型兼容 | 保留原始类型与内容，不参与新建菜单 | 沿用可用基础操作，避免误表示可编辑未知内容 | 「未识别节点」「节点内容已保留，升级工作台后可继续编辑。」 |

当前添加菜单只有生成节点、文字、图片、画板及从作品库插入；没有直接新建视频入口，设计不得添加假按钮。视频节点可由作品库及生成结果创建。普通图片 / 视频的空态入口是对已有属性与作品库操作的视觉提案，不新增本地媒体上传 API。

### 任务状态与生成区规则

| 真实状态 | 展示 | 行为 |
| --- | --- | --- |
| 无任务 | 待提交 | 提示词或必需参考不完整时主按钮禁用，并给出一条具体原因 |
| `queued` | 排队中 | 显示等待状态；生成参数锁定，保留停止入口，不编造排队位置与预计耗时 |
| `running` | 生成中 | 有真实进度时显示百分比；没有进度则显示不定进度。可停止，不伪造已生成的预览 |
| `awaiting_refine` | 一采预览待确认 | 可播放预览；「确认二采」「保留一采」并列，用户必须能明确选择，不自动确认 |
| `succeeded` | 已完成 | 可预览、下载、插入、切换已有结果版本、再次生成 |
| `partial` | 部分完成 | 已成功结果保留并可用；样例严格显示 2/4 与两个成功 / 两个失败项，不增加尚无 API 的逐项补跑 |
| `failed` | 生成失败 | 提示词 / 参考图不丢失；简短原因与展开详情、重试。长错误不撑开整个节点 |
| `cancelled` | 已停止 | 保留输入及已有结果，可重新生成；不伪装为完成 |
| `interrupted` | 已中断 | 说明任务中断，保留输入及已有结果，可重新生成；不展示不存在的断点续跑按钮 |

首次生成没有输出时使用真实占位；再次生成若仍有历史输出，可保留旧图但必须标明历史版本与当前任务状态，不能把旧输出冒充本次完成。版本切换复用 `resultHistory` / `resultIndex` 与对应运行快照，不因编辑表单改写历史。

生成节点的选项仍以 `/api/modes` / `workflow_registry.py` 为准。图中模型、比例、时长、数量仅为示例：`primary` 不超过约 4 项；`advanced` 用「更多设置」展开；`internal` 不出现在创作面板。随机种子、二采精修等只在当前工作流确实支持并开放时展示，不能凭图硬编码。完整快照通过折叠的「运行参数」读取。

视频生成三种输入布局按实际能力切换：文生视频无必填图片；首尾帧首帧必填 / 尾帧可选；多参考图顺序与 `<Picture n>` 对应。参考数量上限、按钮验证和可用项必须继续服从工作流注册表，不为了统一外观更改协议。

### 连线与公共面板

- 连线拖出空白处的菜单必须复用 `canvas-connections.ts` 的实际分支：文字 → 生成的提示词；图片 → 生成的参考图；图片生成 → 生成 / 图片；视频生成 → 视频。没有普通视频 → 生成、画板 → 生成等虚构分支。生成端无成片也可创建等待上游的图片 / 视频节点。
- 连线显示：关闭 / 精简 / 完全；生成节点展示：独立 / 聚合。两个配置分别保存，图中勾选仅是视觉示例，不替用户改真实默认值。
- 节点属性优先创作信息和媒体；来源保留可追溯入口；运行参数、位置与节点信息折叠。画布未选中时使用画布设置，而非空白无提示。
- 图层只呈现当前已有的搜索、定位、复制、删除；不增加锁定 / 隐藏等未实现开关。历史区区分本次编辑撤销与服务器版本，恢复保留确认层。
- 视频封面包括自动取帧、指定秒数取帧、上传后裁切；封面随草稿保存，不进入撤销栈。不把封面裁切画成视频剪辑功能。
- 作品库选择沿用图片 / 视频分类、搜索、分页加载与选中插入，不增加发布、上传或收费生成入口。
