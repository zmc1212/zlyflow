# 智能剪辑桌面 UI · 2026-10-24

## 顺序与范围

先检查当前 `SmartEditPane`、导演台流程快照与真实桌面截图，再使用内置 imagegen 生成 `01-design-light.png`，随后进入测量、React / Ant Design 还原和真实 5173 浏览器验收。设计图保留原始像素，不以实现截图替换参考图。

目标：更大的成片预览、可扫描的素材库、按需打开的片段属性、常驻且易读的三轨时间线。保持现有自动保存、剪辑/字幕/特效、导出、AI 助手以及工程导航能力。仅覆盖桌面，检查浅色 / 暗色；不触发模型生成或音轨外发。

## 原图与实现边界

- 内置 imagegen 输出：1672 × 941 px。主对照使用相同 CSS 视口、DPR 1、视口截图。另回归 1440 × 900 和 1920 × 1080。
- 原始参考：`test-results/director-ui-details-20261024/light-edit.png`；布局与功能以 `docs/导演台流程与界面结构.md` 智能剪辑章节及当前代码为准。
- 图中媒体和数量为示例，生产页面只显示真实素材、真实时间和保存状态。摄影差异与字体抗锯齿不计算成虚构的“还原度百分比”。
- 业务控件全部使用现有 Ant Design，图标使用 lucide-react。文字、表单、时间线均由代码实现，禁止整图背景替代界面。
- 全局导航、根级主题 Provider 保持现有规范；剪辑页工程图标栏整合为可操作的工程菜单，增加预览宽度。助手继续沿用官方 beautifului 的 token / 控件语法，改动前拉取官方 `globals.css`、`chat.tsx`、`prompt-bar.tsx` 作为对照。

## 视觉规格

浅色画布 `--studio-canvas`、白色面板、语义边框、深色主文本；紫色为主要动作，琥珀 / 紫蓝 / 绿色区分文字 / 画面 / 音频轨，并保留文字与图标。暗色配对读取根级 `--studio-*`，媒体预览保持近黑。

原图测量后的实现规格：46px 命令栏、12px 面板间距、10px 面板圆角、6px 业务控件圆角。素材库包含 60px 工具轨，标题和真实数量、搜索、四段筛选、并列本机引用/上传、16:9 缩略图。属性面板带关闭按钮，未选中时默认收起，选中片段自动展开，顶部可再次切换；画面片段按图分为「画面 / 声音 / 变速」三个标签，原有淡入淡出、时间与入点设置保留。播放器底部为圆形播放键与等宽时间码。276px 时间线包含标题 / 真实片段数、分组工具、三轨语义色和红色播放头。

编辑器主要色彩从根级 `--studio-*` 读取；选中态文字从强调色和正文色混合派生，使两套主题的小字都满足 AA。实际沿用工作台的浅色 #435ce8 / 暗色 #5b65e6 主色。助手配对 token 和圆角 / 阴影沿用已读取的[官方源码](https://github.com/TurboKach/ai-native-react-components)，仅组织本项目真实状态，不引入 demo 运行逻辑或其他 UI 库。
