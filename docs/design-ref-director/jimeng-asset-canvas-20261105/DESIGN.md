# 即梦通用无限画布：设计与实现基线

日期：2026-11-05（Asia/Shanghai）。状态：**用户于 2026-11-05 确认按 v006 开发；业务实现与回归已完成。**

本次目标是把「制作资产画布」完善成通用无限创作画布。文本、图片、视频、音频、角色、场景和剪辑工程可在同一空间组合；导演资产是其中一种可引用对象。项目内画布与独立无限画布应最终共用节点协议和编辑能力，导演项目只增加资产来源与回到制作流程的上下文。

用户已明确要求先充分调研，再结合本平台能实现的部分复刻，先提供 UI 稿确认。本目录 `asset-canvas-dark-v001.png` 是范围澄清前以角色资产为中心的首稿，仅留作版本记录；最终评审应使用通用画布稿，不把首稿视为已确认方案。

**当前实现依据：v006，[完整设计评审页](ui-v006/index.html)。** 主画布更新三处操作按钮，补充与导演台首页同款的风格浮层、角色设计六个 Tab、五官滚动下半部及地区细分联动，并提供浅暗两版和按钮状态。共 22 张原尺寸 JPG / SVG；[暗色主画布](ui-v006/canvas-dark.jpg)、[风格浮层](ui-v006/style-picker-dark.jpg)、[角色设计](ui-v006/character-basic-dark.jpg)、[按钮状态](ui-v006/action-buttons-dark.jpg)。此前为设计评审阶段；现已按用户确认进入实现，最新业务状态以 [导演台流程快照](../../导演台流程与界面结构.md) 与 [实页验收](implementation-20261105/design-qa.md) 为准。

| 生成历史 | 图片/视频/音频分类、生成状态筛选；点击记录可定位画布节点 | 复用任务与结果版本，历史记录应能返回其原节点 |
| 输入端口 `+` | 视频输入菜单为「添加上下文」：文本、图片、视频、音频、角色、场景 | 按工作流接受的类型过滤，空源/不支持类型明确说明；不能只画出线却忽略输入 |
| 输出端口 `+` | 视频输出菜单为「引用该节点生成」：视频、多轨编辑器、文本 | 从源节点继续创作；支持创建下游节点并自动连线，按源媒体和执行器能力筛选 |
| 引用菜单 | `@` 可选图片、视频、音频、角色、场景、全景图，以及片段续接、首尾帧、运镜、添加时间等工具 | 显示来源、顺序和缺失态。H3 图片引用编译为 `<Picture n>`，不能直接照搬即梦引用协议 |
| 单节点右键 | 复制、创建副本、标签、上游引用、下游引用、添加到角色素材集、删除；不同类型略有差异 | 必须区分节点、副本、原资产和源文件，删除画布引用不能误删导演资产 |
| 空白右键 | 新建、上传、从资产库选择、粘贴、撤销/重做 | 同一新建能力同时服务工具栏、Tab、空白右键和端口创建 |
| 多选 | 切换为排列、整组执行、打组、合成、加入工具箱；排列有宫格/水平/垂直；右键另有优化工作流布局 | 选择态决定工具条内容；单节点生成与整组执行需要不同任务语义 |
| 连线显示 | 默认、合并显示、绕开节点、隐藏 | 选择相关边高亮，提供避让与显示选项；区分引用边与真正执行依赖 |
| 视口工具 | 整理、显示角色场景、小地图、网格吸附、触控板/鼠标模式、缩放与适应画布 | 统一两处画布的操作、保存和快捷键，保持用户布局 |
| 工具箱 | 预设/个人，列表/宫格，搜索；角色多视图、场景多机位、换装、重拍、氛围、超分等预设；明确应用后不自动生成 | 模板可创建节点/分组，执行需用户显式触发；模板中的模型与节点能力必须校验 |

## 设计结构与关键交互约定

主稿展示一条通用创作链：**文字/角色/场景图片 → 视频 → 剪辑工程；音频 → 剪辑工程**。其中角色资产、图片版本、独立音频、视频预览和编辑输出同时存在，用户可在留白处继续添加任意支持的节点。界面保留导演项目上下文；独立画布入口不强制出现「进入分镜」。

1. 主舞台占满工作区：56px 阶段轨道，单层轻标题，点阵画布；移除资产页的重复大页头和大片分组底板。
2. 单击选节点：显示与类型匹配的工具条，打开或聚焦其创作面板；双击媒体预览、双击文本编辑。面板内的输入/播放/菜单不能触发节点拖动。
3. 媒体空态提供上传、素材库、AI 创作；生成中显示真实排队/进度/取消；失败保留提示词、参考与上次成功版本；完成后支持预览、下载、版本和继续创作。
4. `+` 新建、右键、Tab 和端口创建共用一份能力定义。源节点类型、目标工作流输入类型、参考数量与顺序均校验；连接本身不触发生成。
5. 连线和 `@` 引用回显同一来源关系；上游有变化时标记下游「参考已更新」，不悄悄覆盖已生成作品或历史快照。
6. 参数遵循 registry 的 primary/advanced/internal；主面板只放模型/创作预设、比例、时长/数量等必要项，高级项渐进展开，技术参数留在运行快照。即梦音频的采样率不能原样搬成普通创作选项。
7. 多选显示组级工具；编组是布局归属，执行依赖是边，二者分离。整组执行先校验能力和依赖，空输入与循环依赖前置定位到具体节点。
8. 保存、冲突、离线恢复、撤销/重做沿用既有保护；手动拖拽不会因资产刷新重新排列；保留源资产 ID、媒体位置、历史版本和旧草稿。
9. 观察到原站在靠近视口边缘时，工具条/960px 创作面板可能超出可见区域。本平台需计算可用区域并避让抽屉、底部工具与右边界，避免一并复制这些缺陷。
10. 控件继续使用 Ant Design，颜色来自根级主题与 `--studio-*`。不安装即梦内部组件，不加入 shadcn/Tailwind，不给本页独立维护主题状态。

对照页已在 1920×863 桌面浏览器验证三类切换、角色拖线、场景信息/输出菜单、普通图片下游创建等截图选择，显示图片均加载成功，无横向溢出；验证记录见 [gallery-verification.json](states-v004/gallery-verification.json)。临时预览服务已关闭，HTML 和相邻 PNG 可直接在本地打开。

### 节点交互状态

| 状态 | 实页观察 | 实现约束 |
| --- | --- | --- |
| 未连接、未选中、鼠标在外 | 低对比节点面；标题偏灰；无外侧 `+`、外轮廓、浮动工具条和创作面板 | 默认画布保持安静；不能给所有节点常亮主色边框和端口 |
| 只悬浮节点本体 | 标题提亮、右上标签图标出现；卡片外约 4px 处出现细轮廓；两侧小圆 `+` 显现 | 悬浮与选中分开；仅悬浮不打开生成参数 |
| 悬浮右侧 `+` | 圆环和加号提亮，鼠标 pointer；节点仍未选中 | 单独维护端口悬浮样式，命中区域不能使端口在卡边到端口之间闪退 |
| 按住 `+` 拖向空白 | 源端转为白色实心圆、深色加号；临时蓝色曲线跟随鼠标，源端水平切出；沿线有蓝/黄亮段移动 | 记录持有鼠标按钮的真实中间态；不能只画最终静态灰边。亮段的准确周期未测量 |
| 在空白松手 | 临时线保留，线末端打开「引用该节点生成」；菜单按视口边缘避让 | 创建类型由源节点决定；菜单未确认前不新增下游或触发生成 |
| 从菜单选择视频 | 新空视频节点创建并自动接线，目标选中；出现目标类型工具条与创作面板，相关边蓝色 | 创建、定位、连接、选中应是一个可撤销操作；引用来源一致 |
| 已连接但取消选中 | 连线降为细灰线，端口与工具条收起 | 保留关系可见性，强调色用于相关/活动关系 |
| Escape 取消 | 菜单和临时线一起消失；悬浮退出后轮廓和端口也收起；节点数不变 | 清理拖线状态，不能留下幽灵边、空节点或全局持有鼠标 |
| 点击选中媒体区 | 轮廓更亮，显示类型专属工具条和下方创作面板 | 选中、悬浮、端口交互、信息弹层是独立状态，不由一个 selected 布尔值混用 |
