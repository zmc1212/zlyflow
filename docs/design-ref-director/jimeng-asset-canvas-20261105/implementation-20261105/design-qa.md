## 发现与修正历史

1. [已修复 P1] 通用节点刷新后只恢复数据，未恢复宽度，卡片被内容撑窄。修正：合并旧 / 新草稿时恢复按类型定义的标准宽度，并将样式宽度纳入渲染相等判断。复验：硬刷新后视频 / 生成节点均为 380px 基准宽度，提示词、MiniMax H3 模式与「图1 李强」连线均恢复；自动化测试断言 text / image / video 的 320 / 360 / 380。
2. [已修复 P2] 浅色「进入分镜」子元素沿用旧静音色，长 Label 换行把基础页后半部挤下。修正：主按钮内容继承对比色，文化与可选地区 Label 使用两行 / 30px 行几何，并校准选择控件。复验：最终 `character-basic-comparison.jpg` 与两套主题截图，长标签不再三行挤压；浅色按钮文字为浅色、底为深色。
3. [已修复 P1] 剪辑服务拒收画布的相对预览地址，第一次真实保存返回 400。修正：优先解析对应任务 / 版本的云端原片地址，必要时用已有上传服务导入，并按最终 URL 去重。复验：现有成片真实进入独立 `canvas-…` 剪辑序列，素材 1 项、时间线 1 段 / 5.17 秒，随后返回画布；见 `smart-edit-handoff.jpg`。多输出时选中版本地址的回归用例通过。
