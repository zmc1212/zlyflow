# 导演台子页面设计与还原 · 2026-10-24

## 范围与依据

依据当前 `docs/导演台流程与界面结构.md`、现有 5173 页面及 `ui-20261023` / `smart-edit-ui-20261024` 基线。延续中性浅暗表面与靛蓝主操作，不替换业务流程。桌面逻辑视口 1600×1000、DPR 1；另验证 1440×900 与 1920×1080。

先制作设计图，再改业务源码。生成图用于整体视觉探索；实现前在浏览器中用仅作用于本次页面的临时样式制作逐页、可测量的排版设计图，保存为 `design-*.png`。这些图是冻结的实现基准，生成图不作为字体或精确坐标的事实来源。

## 共同规格

- 保留 76px 全局导航。项目顶栏 72px、工程导航 200px；内容区桌面左右 28px，上下 28px。智能剪辑独立布局保留当前已验收基线。
- 页面标题 26px / 36px / 650，说明 13px / 22px；区块标题 15–18px；表单正文 13–14px，辅助文字 12px。系统中文无衬线字体。
- 页头横向对齐，标题和说明为一组，主操作为一组；40px 常规按钮，36px 紧凑控件，8px 控件圆角，12px 面板圆角。
- 画布、表面、抬升表面、边框、文字、主色均从根级 `--studio-*` 取值。浅色 `#f8f9fa/#ffffff/#171a1f`；暗色 `#0f1115/#171a20/#f3f5f7`。列表选中用主题主色淡底与文字，键盘焦点用轮廓；状态同时有文字。
- 静态面板用边框区分，弹层继承根级 Ant Design 主题。重复项不堆叠多重阴影。列表与长表单分别滚动，主操作不被横向挤出。

## 实现与验收约束

业务控件直接使用 Ant Design，图标使用现有 lucide-react。不新增依赖、后端协议、生成参数、任务执行或持久化。仅新增任务筛选的挂载期视图状态。对话创作室、Prompt Bar 和助手的官方 beautifului token 不在本轮重绘范围；批量页只调整其外层布局，不覆盖内部样式。

界面样例由临时 QA 账号和人工内容创建，不提交任何 LLM、出片、转写或视觉理解任务。设计图与实现用相同数据、同一视口、同一字体、同一根主题截图，测量页头、导航、工具栏、列表和主面板的外框。差异报告不换算“还原度百分比”。真实操作另验，不能用像素对照代替业务验证。

长期证据保存在本目录；临时脚本、原始日志、认证状态和调试截图只在已忽略的 `test-results/director-subpages-20261024/`，交付前清理认证与临时工程。

## 2026-10-25 校准记录

用户确认沿用现有风格精修。原设计和源码保留在当前仓库；继续验收时重新读取了当前工作树、路由与真实 5173 状态，未恢复已下线的 Hypit 模块。后续临时验证目录为 `test-results/director-subpages-20261025/`。

资产库首版独立滚动意图在 Ant Design 6 的实际 DOM 下未成立：当前 Spin 根为 `.ant-spin`，旧 `.ant-spin-nested-loading` 选择器没有约束住高度。先在浏览器制作并冻结 v2 设计，再修改源码，同时兼容两种包装结构。1600×1000 下工作区为 `(304,242,1268,730)`，左栏 248px，右栏 1004px；整个工作区止于 y=972，长详情在右栏内部滚动。原 `design-assets-*.png` 保留为首版历史，不覆盖原图。

任务页首版排版稿中的空态图标与占位字段仅为视觉说明；实现使用真实 Ant Design Input / Select 与 lucide ListChecks。无任务时默认「图片生成」，有记录时按最新任务类型初始化；用户主动选择后保留其选择。搜索、下拉、表格和空态的真实状态单独截图并记录，不能将原稿的示意控件或「镜头规划」占位文案视为产品状态。

交付时的工坊概览由同期[多集短剧设计](../series-ui-20261025/DESIGN.md)进一步精修：28px 标题、制作概览、状态筛选、搜索排序、分集阶段卡与新增 / 编辑表单。当前代码与该设计保留，不回退为本目录首轮紧凑统计方案。本目录的 `design-workshop-*`、`actual-workshop-*` 和对应差分均保留为首轮证据；交付复核以 `current-workshop-*` 为当前实拍，未将旧原稿与新版混作同一基线。
