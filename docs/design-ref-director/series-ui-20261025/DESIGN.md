# 多集短剧 / 剧集管理设计 · 2026-10-25

## 范围和依据

用户确认“系列”指导演台的多集短剧 / 剧集管理。本轮沿用工程 → 分集 → 镜头的数据关系，在 `/director/projects/:id/workshop?mode=manual` 设计并实现概览、搜索筛选排序、分集卡片、新增 / 编辑表单、删除确认、加载 / 空态 / 错误反馈。单集镜头、配音、合成、智能剪辑和 AI 对话仍走现有真实流程。

依据：当前 `EpisodeWorkshopPane.tsx`、`api.ts`、`docs/导演台流程与界面结构.md` 的 3.2 节，以及隔离 SQLite 验收工程在真实 Vite 5173 上的改前截图。根级双主题、Ant Design、lucide-react 均继续复用，不新增依赖。

## 视觉构思

将整部短剧呈现为按顺序展开的制作板。第一眼是剧集标题与新增操作，其次是一条紧凑的制作概览，再按集数浏览卡片。卡片用明确的大号集序、正文标题和单一状态标签建立秩序，四阶段轨迹表达草稿 → 脚本 → 出图 → 分镜的状态位置，不把它伪装成出片进度百分比。

- 生图目标 1600 × 1000；实际原图 1586 × 992，冻结后的还原基线为 **1586 × 992 CSS px / DPR 1**，不拉伸原图；补验 1440 × 900 和 1920 × 1080 桌面。
- 外壳：保留现有 76px 全局导航、200px 工程导航和 72px 项目条；主体左右 28px。
- 双主题：浅色画布 `#f8f9fa` / 白色表面 / 主文 `#171a1f`；暗色画布 `#0f1115` / 表面 `#171a20` / 抬升表面 `#1e2229` / 主文 `#f3f5f7`。颜色落到 `--studio-*` 和 Ant Design token。
- 页头：30px 标题、14px 说明，40px 按钮；概览条、工具栏与卡片间距 18px。
- 卡片：三列、16px 列间距；12px 圆角、1px 语义边框、20px 内边距；阶段线、两行简介、镜头数量、更新时间、底部进入入口和 32px 更多操作。
- 控件：36–40px 高、8px 圆角；清楚的 hover / focus-visible / disabled / loading；状态文字与图标同时出现。弹层继承根主题，表单错误就地呈现，保存失败保留输入，保存中防止重复提交和误关闭。

## 数据与操作边界

示例工程“雾城来信”，六集，镜头数 12 / 10 / 8 / 9 / 0 / 0，共 39；状态分别为分镜完成 / 出图中 / 脚本就绪 / 脚本就绪 / 草稿 / 草稿。所有样例只写入忽略目录中的隔离 SQLite，不进入用户数据库或业务源码。

真实统计必须来自当前列表和项目资产；不得再向每集填入固定“2 身份 / 1 场景”。没有依据的集内角色数量与成片进度不展示。搜索和筛选组合，默认按集数升序，数量随真实数据变化；未知状态保留文字。新集序号从现有最大序号递增，避免删除中间集后撞号；编辑时序号只读，因现有更新接口不写该字段。

原始设计图先生成并冻结，再测量关键区域、实现、采集真实页面并逐区对照。还原验收同时覆盖文字、图标、控件和弹窗，不能仅凭外框或构建通过下结论。
