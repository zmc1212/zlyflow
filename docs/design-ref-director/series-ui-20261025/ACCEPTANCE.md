## 功能与状态结果

- **95 项检查通过**：核心操作 48 项、最终样式状态回归 47 项。记录见 [interaction-checks.json](interaction-checks.json)。两个批次均无 JavaScript 运行异常；错误测试中的 HTTP 503 为主动注入，不能视作业务正常请求。其他既有区域的 Ant Design 弃用提示未纳入本轮样式改造。
- 32 张视口状态截图用于两批次回归；最后一次概览字形 / 对齐调整后重新执行 47 项检查并复采 14 张状态与桌面尺寸截图。最终主图采用第二轮独立采集，组件另有 12 张原始尺寸裁切及 [裁切元数据](component-captures.json)。
- 搜索按集号、标题和剧本组合筛选，忽略首尾空格；草稿、就绪、制作中、完成数量来自列表；升降序为数字排序。未知中文状态保留原文，非法日期显示可读回退，54 集列表可滚动与准确搜索，长标题省略但保留全文 Tooltip。
- 新增真实经过接口，序号从最大值递增，重复集号和空标题被阻止；空分集为 0 镜头。编辑回显正确，序号只读且原镜头数保留；保存失败保留输入。保存中按钮禁用、禁止重复提交和 Escape 关闭，实际仅发出一次创建请求。
- 更多菜单可用键盘打开。删除默认焦点在取消；取消保留原分集。删除失败在受控弹窗内显示错误且可重试，成功后刷新列表，无未处理 Promise 异常。
- 空态可到内容库，分集卡片可进入真实镜头工作区并返回；首次加载、列表失败、刷新失败保留旧卡片、资产失败不伪报零数量均有覆盖。浅色主题刷新后保持用户选择。
- 只验证桌面 **1440×900 / 1586×992 / 1920×1080，DPR 1**；未发现横向溢出，末集菜单滚动到视口后可实际命中。概览页助手入口停靠在项目导航底部，避免覆盖卡片操作。

## 视觉对照结果与边界

原稿实际为 **1586×992**，没有拉伸到生图提示的 1600×1000。两轮采集使用同一原图、同一 [区域清单](regions.json) 与测量摘要；最终实际 URL、页面标题、视口、DPR、截图选项、字体 / 图片就绪条件均通过核对。[采集记录](capture.json) 还通过浏览器 CDP 确认中文正文实际使用 Microsoft YaHei、标题使用其 Bold 字形。

共 20 个参考区域：13 个 DOM 几何区域、6 个字形 / 细节区域、1 个背景色采样。最终 13 个几何区域均可测量，最大绝对偏差 **4 CSS px**；主要来自生成稿第二排卡片高度 286px 与实现统一 290px 的差异。状态标签从首轮 5px 偏差降到约 2.34px。完整结果见 [最终几何表](geometry.md)、[首轮记录](geometry-round-01.md) 和 [原始验证结果](fidelity-report.json)。

按固定中性亮色阈值核对两个标题的可见笔画：页面标题的 x / y / 宽 / 高差为 `+1 / 0 / -1 / +1` px，第一集标题为 `-1 / -1 / -2 / 0` px。方法与原始数据见 [字形检查](micro-ink-check.json)。其余六类局部逐一通过 [原始像素对照图](comparison-micro.png) 核对，包含状态图标、标签、节点与文字、镜头与日期、进入入口和更多按钮。

验证工具的“截图身份与渲染前提通过”只证明采集条件成立。本轮视觉结论还依据人工查看完整主图、浅暗组件实拍、标注范围、局部笔画和真实操作。**没有把像素差异换算成还原率，也不声称每个像素完全相同。**

保留的差异与理由：

1. 继续使用根级语义颜色和 lucide / Ant Design 图标；完成状态为成对主题的青绿色，节点勾选保持可读对比。生成稿的纹理、辉光、手绘字形和局部图标笔画不作为图片嵌入。
2. 分集卡片统一高度、间距和交互尺寸，修正原稿中小幅不一致；保留真实集数，不生成中文大写集号。
3. 助手入口移入空闲项目导航底部，修正原稿里对末集菜单的遮挡。
4. 剧本不新增原接口没有的 2000 字上限，使用真实计数；新增 / 编辑 / 删除报错是根据真实状态展示的额外画面。
5. 浅色由同一结构和根 Provider 的成对 token 实现；不是另起一套主题状态。样例仅为验收内容，生产页面继续读取当前用户数据。

## 验证环境纠正与数据清理

首次测试仅设置了通用 SQLite 开关，而 `media_studio.db` 使用独立 MySQL 连接池，导致本轮样例工程 1 个、分集 6 个写入了 MySQL。发现后立即停止该测试服务，按明确工程 / 分集 ID、名称、创建时间和无其他关联内容的条件校验后，在事务中清理；核对余量为 **0**，其他记录未修改。[清理结果](sample-cleanup-result.json) 已保存。这是本轮验证环境判断的错误，不能把后续隔离测试结果倒推成从未访问 MySQL。

随后在忽略的测试目录中使用独立启动器，将通用存储与导演台数据层都指向测试 SQLite，同时直接拒绝 `pymysql.connect`；后续检查没有触发 MySQL 连接。截图和 CRUD 验收均在该修正环境完成。未提交产品生成 / 转写任务，未切换 ComfyUI 地址、节点或模型，也未新建 ComfyUI 实例。
