# 批量与参考片复刻 · 创作设置精修

2026-10-25，延续上一轮子页面设计。先生成 [补充设计图](01-concept-board.png)，再以真实 Ant Design 控件制作 1600×1000 / DPR 1 的逐页冻结稿，之后修改业务源码。浅暗主题、导航、顶栏、320px 设置栏、结果区与 Prompt Bar 设计保持既有基线。

本轮为 Operate 界面的精修：创作者先决定数量、画幅、时长、工作流与画风；复刻先上传参考片，选择分镜方式，再开始拉片。日常表单不直接展示模型体积、采样步数与深度控制强度。

- 批量卡片改为「创作设置」。第一行「视频数量 / 画面比例」，之后依次为「单条时长（秒）」「视频工作流」「画风（可选）」。使用 Ant Design Form、InputNumber 和 Select，明确标签及可访问名称。工作流仍由现有注册表目录生成。
- 复刻「拉片设置」保留「分镜方式」「目标风格（可选）」与开始操作。智能分镜的「切镜灵敏度」收在 Ant Design「更多设置」中；固定分段时显示「每段秒数」。使用原有取值与自动保存逻辑。
- 旧工程的 `weightProfile`、`renderSettings.steps`、`renderSettings.vaceStrength` 继续保留；本轮不改默认值、映射、生成请求或后端协议，也不在展开区重新暴露内部参数。
- 控件 40px，标签 13px / 20px、下距 8px，字段间距 16px。面板圆角 12px、边框 1px，颜色来自 `--studio-*` 和根级 Ant Design 主题。
- 复刻底栏使用「参考片复刻 · 拉片后可逐镜编辑，再生成新画面。」，移除与当前远端连接环境不符的「本地」及内部执行队列说明。

设计总览的输出原图为 2112×744；它负责表达两页的设置层级，不作为整个 1600px 页面的坐标来源。精确比较使用后续保存的 `design-{batch,replication}-{light,dark}.png`，不改写上一轮设计与差分文件。

验证只覆盖桌面。在真实 Vite 5173 页面通过浏览器隔离 API fixture 验证默认、展开、固定分段、筛选选项及保存请求；内置工作流元数据来自当前 `workflow_registry.py`，艺术风格来自当前静态目录。fixture 不触达用户数据库或模型服务。后端归一化和参数兼容另通过既有测试验证。
