# 导演台桌面 UI · 2026-10-23

先生成并检查 `home-design.png`、`project-design.png`，再实现真实 React 界面。两张设计图原始尺寸均为 1505 × 1045；按相同 CSS 视口、DPR 1 截图对照，不拉伸截图或用整张设计图覆盖页面。

目标是让创作入口、工程和项目内导航有明确层级。延续工作台冷白 / 靛蓝配色，浅色默认；暗色由根 Provider、Ant Design 与现有 `--studio-*` 成对 token 推导。对话创作室保留 beautifului 官方 `globals.css` 与对应组件设计，不更改其样式。

首页：一层 64px 顶栏；36px 主标题；主次创作入口与独立剧本诊断入口；工程使用三列缩略图卡片，支持类型筛选、名称 / 简介搜索、数量、查看更多、打开、复制和删除。工程数量、时间、标题取真实数据，设计图的示例数据不作为业务值。

项目：资产库、工坊与任务页沿用内容库设计语言，标题、表面、边框和状态文字统一接入语义主题。去掉重复的 AI Media Studio 顶栏，改为一层 80px 项目条；返回导演台、项目名称、编辑基本信息、制作配方、创作模式与主题；五项工程导航；内容库使用实色导入按钮、标准规范入口与可读的空态。长项目名省略并提供完整 title，技术项目 ID 不占头部空间；移除没有对应任务依据的固定「进行中」标记。

实现约束：保留全局 76px 图标轨（生成图约 88px，是生图偏差）；项目内侧栏相应调整到 226px，使内容区左边缘与设计稿 302px 一致。字体使用真实系统字体，文字抗锯齿、字形及动态文案不以逐像素相同为要求。电影格是 CSS 几何元素；真实封面仍使用原 URL，不生成虚构项目封面。

验收标准在截图前固定：

- 相同 1505 × 1045、DPR 1、CSS 像素截图，确认页面身份、主题、字体与图片就绪。
- 首页主入口、次入口、诊断、首张工程卡与项目内容卡的外框位置 / 尺寸与设计图逐区报告。除全局图标轨等上述明确约束外，关键锚点最大绝对偏差 ≤ 20 CSS px；偏差只定位问题，不换算「还原度百分比」。
- 两种主题均检查，额外覆盖 1440 × 1000 与 1920 × 1080 桌面宽度；不做移动端验收。
- 自动操作验证搜索、空搜索恢复、类型筛选、查看更多、打开工程、键盘导航、制作配方下拉、导入 / 规范 / 基本信息弹层、AI 助手开关与主题刷新持久化；截图不触发模型任务。
- 自动检查页面溢出、关键控件裁切、正文对比度与浏览器运行错误；截图人工复核必须通过。
- 前端测试、类型检查、`pnpm --dir frontend build` 与导演台相关后端测试通过。

最终截图及验收结果见本目录 `ACCEPTANCE.md`；临时测量、差异图、日志在已忽略的 `test-results/director-ui-20261023/` 中，结束后清理临时脚本与认证资料。最终设计图和代表性截图作为长期基线保留。
