# 导演台首页局部设计 · 2026-10-25

## Overview

仅约束 `/director` 首页，采用 Operate 模式。以「创作启动台＋工程工作区」替换旧的 1＋2 宣传卡、横向诊断条和三列工程卡；科技感来自工程秩序、精密镜头与清晰层级，不能退回只加蓝光的旧布局。

## Colors

双主题继承根 Provider、Ant Design token 与 `--studio-*`，浅色默认。画布／表面为浅色 `#f8f9fa`／`#ffffff`、暗色 `#0f1115`／`#171a20`；边框和抬升表面区分区域。蓝紫用于选中与行动，青色集中在镜头。

## Typography

沿用全局无衬线字体；工程区标题 30px、启动台 26px、顶栏 20px，字重 650；工程名与步骤 16px，辅助文 13–14px。名称单行省略，日期使用等宽数字。

## Layout

保留 76px 导航与 64px 顶栏。主体左列 358px、间距 29px，右列弹性；内边距为上 31、右 24、下 24、左 42px。低于 1400px 的桌面左列缩为 300px。左下独立诊断；右侧 Table 表头 55px、行高 102px，默认六项。面板圆角 14px，主按钮高 56px。

## Components

Menu 切换模式，仅更新说明、三步和唯一 CTA；点击 CTA 才进入创建，导演创作先选配方。Segmented、搜索和刷新驱动真实工程；保留打开、复制及删除确认。具备 Skeleton、加载失败重试、空态与清空搜索，长列表独立滚动。

## Do's and Don'ts

镜头仅用 SVG／CSS 与既有图标，无新增运行时摄影或位图；素材生成记录见 `PROMPT.md`。冻结原图 `01-design-dark.png` 为 1505×1045；其外壳约 92／69px，与产品 76／64px 不同。主体 19 个锚点误差≤2px；镜头内外圈径向明暗、反射与青边经独立复核修复，结论为 resolved／ship，不宣称全图 100% 一致。验收含前端 429、后端 55 项测试、71 项 UI 检查及三种桌面尺寸双主题，DPR 1；未验证手机。
