# 剧集工坊当前镜头工作台验收（2026-09-26）

## 结论与审查方式

本轮在第一轮布局整理上，继续解决「入口多但主线不清楚」的问题。采用当前镜头工作台：选镜头 → 检查素材／正式提示词 → 审阅候选或保存 → 按明确范围生成。视觉沿用 Ant Design、`--studio-*` 与项目双主题，不更换全局壳。

按用户要求由同一执行上下文完成产品、设计、前端三种视角的顺序自审，未启动子代理；这不是三位独立专家或真实用户可用性认证。Impeccable 用于任务顺序、层级、间距和有界验收，React 指南用于派生状态及接口职责分离；不能用 detector 或构建通过替代体验判断。

## 两个主要问题及处理

1. **P1：作用范围和下一步不直观。** 原本本镜／整组／整集入口重复，提示词藏在素材组，候选长文又抢占编辑区。现在当前镜头、组号、镜数、组时长常显；分集操作与提示词操作分开；候选在 720px Drawer 审阅，底栏随保存／规划／审阅／写词／生成状态切换主动作。
2. **P1：空间及编辑安全。** 小桌面固定素材栏、工具栏和嵌套滚动挤压正文；未保存生成阻断不完整。现在使用实际检视器 920px 断点、最小 240px 编辑器和独立底栏；生成入口有 UI 与调用函数双重 dirty 防线。实页发现静态确认层未显示后，改为 `Modal.useModal` 和 context holder，切镜及返回确认实测可取消且保留草稿。

## 最终界面行为

- 镜头列表宽 280–320px，紧凑镜头条目支持搜索镜号／剧情／对白；独立状态行不与描述或缩略图重叠。已有缩略图显示原图，无图使用真实镜号。
- 检视器默认打开「素材与提示词」，另有「镜头内容」「视频版本」；前后镜导航和专注模式不重置稿件。镜头内容保留完整原标题，不猜测拆分字段。
- 窄检视器使用 360px 素材 Drawer；宽检视器使用 280px 侧栏。素材两列等宽、96×96 contain，名称与造型分层；参考准备默认折叠，动作预演独立成组。
- 任务入口常显数量／失败状态，详情、失败原因与重试保留。候选计数仅包含仍在规划中、完整、可采纳的候选；已采纳／旧版／过期／未通过证据不删除。
- 正文不会被候选顶走；历史默认折叠。底部显示整组就绪检查和阻断原因，视频按组提交、单镜返修范围不变，旧 revision／fingerprint 合同保留。
- 未保存时禁用生成与批量菜单，切镜／返回需确认；刷新页面仍有 beforeunload。保存、采纳、重试、生成的真实写操作不在本轮端到端验收内。
