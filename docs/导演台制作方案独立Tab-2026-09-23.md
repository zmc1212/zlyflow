# 导演台制作方案独立 Tab（2026-09-23）

## 结果与原因

整集操作不再放进单镜检视器，避免选中一个镜头却改动整集的范围误解。当前主导航为「剧本 / 镜头 / 制作方案 / 声音 / 合成」。

「制作方案」集中整集提示词扩写、公共设定、有序参考图、预览与保存、返修审稿、关联生成段选择及本集生成入口。明确显示「作用范围：本集全部 N 个镜头」。所有源镜头共同使用同一份方案，没有新增第二份方案数据。

Director 镜头检视器的「提示词与视频」只显示该镜头关联的已保存提示词、生成结果和「前往制作方案」。多镜共享段显示关联镜号，提示修改或重做会影响全部关联镜头。方案页可从生成段跳回对应镜头。旧逐镜工作流仍在镜头内扩写单镜提示词。

## 实现与兼容性

- 新增 URL `?tab=plan`，保留 `script/shots/dubbing/compose`；刷新恢复制作方案页。
- 整集与单镜各自解析选中的生成段，整集面板传 `selectedBeat=null`，避免受当前镜头过滤。
- 新增只读 `ShotPromptSummary`，复用提示词章节渲染，不挂载整集扩写表单。
- 不改后端 API、数据库、任务协议、模型参数、ComfyUI 地址或生成逻辑，不创建真实推理任务。
- 文件：`EpisodeWorkshopPane.tsx`、`PromptAuthoringPanel.tsx`、`ProductionPanes.tsx`、`dubbing-track.ts`，以及对应 `PromptAuthoringPanel.test.ts`、`dubbing-track.test.ts`。同步 README、架构与导演台流程文档。
