# 正交错觉（perspective illusion）短片工具 v2

用「2° 超长焦移轴」拍一条 10 秒、无缝循环的雨夜十字路口：画面先是一张完全平整的城市立面海报（2° 视角、等效 1300 m 外压缩整条大街），随后 dolly zoom 突然拉开纵深，转向斜角时先读作平面再展开成 3D，并在画面接近平面时把隔离桩从「一横排」偷偷换成「一斜列」，错觉反复兑现。

方法遵循 simcraft（github.com/dotslashsimran/simcraft，MIT）的 perspective-illusion 技能：镜头参数表（焦段、取景宽度、地平线位置全是确定的数）、相机永不俯仰（靠移轴代替低头）、逐帧无头浏览器渲染 + ffmpeg、闪烁检查脚本。

- 成片：`交付视频/正交错觉_雨夜十字路口_10s.mp4`（1920×1080 / 60fps / H.264 / 首尾同帧）
- 预览：`tmp/perspective-illusion/preview.mp4`（960×540 / 30fps）
- 运行时：Node + three 0.170 + playwright-core（Chromium 真实 GPU: ANGLE/D3D11）+ ffmpeg

本目录是独立工具，不参与工作台前后端构建，也不需要后端服务。

## 一、错觉是怎么成立的

1. **平面态是 2° 超长焦**：`src/rig.js` 的 `flat` 镜头 fov 2°，取景宽 46 m，反推距离 ≈1300 m，整条街被压成一张立面图；20°/200 m 那种「伪长焦」仍看得出透视收敛，海报感不成立。
2. **dolly zoom 用取景宽度 W 驱动**：镜头定义为 `{x, y, zf, W, fov, H, el, yaw, lay, cs}`，距离由 `D = (W/2)/tan(fov/2)` 反推。fov 变化时 W 不变 → 主体大小不动、背景纵深拉伸，这正是「看着是平面插画，镜头一动突然变成 3D」的那一下。W 与 fov 在对数空间插值。
3. **相机永远水平**：`H`（地平线在画面中的位置）用投影矩阵镜头偏移实现；`el`（俯视）靠把相机升高 `D·tan(el)` 再把镜头偏移补回来，焦点始终居中，全程无俯仰，竖线永远竖直。`yaw` 绕焦点摆轴拍斜角，主体不偏。
4. **换位道具**：五个红白隔离桩在平面态排成一排，立体态换成沿纵深错开的斜列（`updateSwap(lay)`）。换位只发生在平面停留段（长焦下深度不可见），观众看到的是「同一排东西突然有了前后关系」。
5. **镜头词汇**：平面 → 虫视（膝高 90°）→ 斜角 1（先 4° 长焦读作平面再开到 30°）→ 平面（换位）→ 高位斜线 → 斜角 2（另一侧，el 24°）→ 低位斜线 → 平面收尾。错觉在每次运镜结尾兑现。
6. **两遍几何 + 墨线合成**：`src/post.js` 渲染 beauty / 法线 / 深度 / 平面色四张 2× 超采样缓冲，合成着色器画墨线（深度二阶差分 + 法线差 + 颜色边界）、双色调、世界坐标排线、按视线方向绘制的夜空、泛光与夜色分级。

## 二、渲染管线（v2 核心升级）

- **页面契约**：`window.render(ms)` / `window.probe(ms)`（街道采样点的屏幕坐标）/ `window.setJitter(x, y)`（亚像素镜头偏移）/ `window.renderMany(list)`（GPU 累积平均，一帧只出一张图）。
- **速度自适应运动模糊**：`render_fast.mjs` 用 `probe` 测一帧 shutter 内屏幕位移，快动作最多 32 个子帧（间隔 ≤2 px，无缝拖影），静止帧至少 4 个子帧（旋转网格亚像素抖动 = 抗锯齿）。360° 快门：一帧的拖影正好接上下一帧。
- **确定性**：一切动画是 `ms` 的纯函数；人群一个整往返/循环、雨丝整数个体积高度/循环、腿部摆动整数个步态周期/循环 → 循环接缝严格无跳变。
- **合批**：所有静态网格按材质 `mergeGeometries` 合并，人群/雨/换位桩/发光体除外。

## 三、目录

| 文件 | 作用 |
| --- | --- |
| `src/main.js` | 渲染入口，实现页面契约；`?raw=1&noaux=1&scale=.5&w=&h=` 为调试开关 |
| `src/rig.js` | 镜头参数表、dolly zoom 反推距离、移轴投影、绕焦点摆轴、探针点 |
| `src/curve.js` | 单调三次（Fritsch–Carlson）插值，支持对数通道 |
| `src/scene.js` | 场景：路口/斑马线、楼体与橱窗、霓虹招牌、LED 屏、路灯、信号灯、电线杆、56 个撑伞行人、雨、湿地反光、换位隔离桩 |
| `src/textures.js` | 全部程序化 canvas 贴图 |
| `src/post.js` | 四遍渲染 + 泛光 + 合成（墨线/双色调/排线/天空/分级/暗角/颗粒） |
| `src/scene.html` | 页面，importmap 指向 `node_modules/three` |
| `serve.mjs` | 静态服务（`node serve.mjs` 后可本地开页面看实时效果） |
| `render_fast.mjs` | 速度自适应逐帧抓图 + ffmpeg 编码（--preview / --stills / --from / --to） |
| `render.mjs` | 旧版逐帧渲染器（无运动模糊），保留作对照 |
| `check_flicker.mjs` | 旧版亮度突变检查 |
| `scripts/blink_map.py` | 近静止帧逐像素符号翻转闪烁热图（仿 simcraft blink_map） |

## 四、运行

```bash
cd tools/perspective-illusion
npm install

# 关键帧静帧（质检最快路径）
npm run stills
node render_fast.mjs --preview --stills 0.3 --raw      # 只看 beauty
node render_fast.mjs --preview --stills 0.3 --noaux    # 隐藏雨/光晕/反光

# 整条预览 / 终版
npm run preview    # 960×540 30fps → tmp/perspective-illusion/preview.mp4（约 1-2 分钟）
npm run final      # 1920×1080 60fps → 交付视频/正交错觉_雨夜十字路口_10s.mp4（约 20-40 分钟）

# 成片闪烁校验
npm run check      # python scripts/blink_map.py ffmpeg <preview> blink.png

# 实时预览页面
node serve.mjs     # 打开 http://127.0.0.1:<port>/scene.html?w=1280&h=720
```

`--stills` 输出到 `tmp/perspective-illusion/stills[-preview]/`；渲染是确定性的：同一 `ms` 永远出同一帧，可只重渲某几帧再拼。`--from=2 --to=4` 可渲染区间。

## 五、时间线（10 s，首尾同帧）

| 时间 | 状态 | 说明 |
| --- | --- | --- |
| 0.00–0.60 | 平面海报 | 2° / W46，地平线压低，整条街是一张立面图 |
| 0.60–1.15 | 虫视俯冲 | 膝高 90°，dolly zoom 猛然拉开纵深 |
| 1.15–1.76 | 虫视停留 | 伞群、霓虹、湿地反光（drift 呼吸） |
| 1.76–2.73 | 斜角 1 长焦 | 绕焦点摆到 -15°，4° 压缩读作另一张平面 |
| 2.73–3.37 | 斜角 1 展开 | 30° 打开，纵深被证明存在 |
| 3.37–3.78 | 收回海报 | 拉回 2° 平面态 |
| 3.78–4.87 | 平面停留 | 隔离桩排→斜列换位在此完成，画面看不出 |
| 4.87–5.33 | 高位斜线 | 80° 俯视路口，斜列的前后关系被揭穿 |
| 5.33–6.10 | 高位停留 | 斜列桩纵深感（drift） |
| 6.10–7.85 | 斜角 2 | 另一侧 4°→46°，el 24° 高位俯拍再落地 |
| 7.85–9.30 | 低位斜线 | 75° 贴着人群看斜列桩 |
| 9.30–10.0 | 收回海报 | 回到与 0 s 完全同帧的平面态，无缝循环 |

## 六、可调项

- **镜头/时间线**：`src/rig.js` 的 `SHOTS` + `TIMELINE`。字段 `x, y, zf, W, fov, H, el, yaw, lay, cs`；`W` 是焦点平面取景宽度（dolly zoom 的锚），`H` 是地平线 NDC 位置，`el` 俯视靠升相机+移轴，`lay` 换位布局。改完先 `npm run stills` 看关键帧。
- **配色/墨线**：`src/post.js` 的 `skyColor()`、各行 lineDepth/lineNormal/lineFlat 阈值、夜色分级。
- **场景内容**：`src/scene.js`（建筑块表 `rightBlocks/leftBlocks`、招牌槽位 `signSlots`、人群分布）。
- **画幅/帧率**：`render_fast.mjs --fps=30 --from --to`；分辨率固定预览 960×540 / 终版 1920×1080。

## 七、已修过的坑（改场景前先读）

- **长焦下相距几厘米的面会打架**：橱窗发光条、LED 屏、竖招牌一律离立面 ≥0.45 m；楼宇体积重叠 ≥1 m 封死天空缝，否则远景楼缝会透出一条贯穿画面的粉色地平线辉光带。
- **转角镜头前不能有高楼**：路口两个近角楼压到 7 m（广场亭），否则 corner view 被近角立面挡掉半幅。
- **泛光渗透**：bloom 半径内直接加色，阈值 0.52/增益 0.52；招牌 emissive 1.9，防止霓虹色染到斑马线。
- **屏幕空间噪声会闪**：排线/影调全部世界坐标锚定；颗粒幅度 0.012。
- **接缝**：所有周期（人群、雨、步态、漂移镜头）都是循环时长的整数分之一；首尾镜头相同且端点斜率为零。
- **快速变焦段 ≥0.5 s**：快于这个 32 个运动模糊子帧也采样不足，会糊成重影。
- 预览（JPEG、k≤16）按设计会有 shimmer，闪烁判定以终版 blink_map 结果为准。

## 八、已知取舍

- 相机全程水平是错觉成立的前提，高位镜头靠 el 升相机+移轴完成，无法像航拍那样绕轴俯视。
- 场景程序化生成，无外部贴图/模型依赖，整个目录可独立拷贝运行。
- 终版 60fps 全片渲染约 20-40 分钟（速度自适应子帧，静止段很便宜）。
